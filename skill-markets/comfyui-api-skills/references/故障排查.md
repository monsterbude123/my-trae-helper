# 故障排查手册

> 错误库与解决方案全集。配合 `skills/comfyui-troubleshooter/` 使用。

## 错误分类

| 类别 | 占比 | 典型症状 |
|------|------|----------|
| **服务类** | 15% | 连接失败、500 错误 |
| **工作流类** | 25% | 节点缺失、连线错误 |
| **质量类** | 35% | 人脸崩坏、变形、过饱和 |
| **性能类** | 20% | OOM、卡顿、运行缓慢 |
| **其它** | 5% | 权限、路径、版本 |

## 类别 1：服务类错误

### 错误 S1：连接被拒

**症状**：

```
curl: (7) Failed to connect to {{COMFYUI_URL}} port 8188: Connection refused
```

**诊断**：

```bash
# 1. 检查 ComfyUI 是否运行
ps aux | grep -i comfyui

# 2. 检查端口
netstat -ano | findstr :8188
# 或
lsof -i :8188

# 3. 检查防火墙
```

**修复**：

```bash
# 启动 ComfyUI
cd {{COMFYUI_INSTALL_DIR}}
python main.py {{COMFYUI_LAUNCH_FLAGS}}

# 或用 launcher
{ComfyUI}/run_nvidia_gpu.bat
```

### 错误 S2：500 内部错误

**症状**：

```json
{"error": "Internal Server Error", "details": "..."}
```

**诊断**：
- 查看 ComfyUI 控制台完整堆栈
- 检查 `~/.cache/comfyui/` 日志

**修复**：
- 重启 ComfyUI
- 检查是否有节点包更新后未重启
- 升级到最新 ComfyUI

### 错误 S3：服务过载 / 长时间无响应

**症状**：
- 接口 `{{COMFYUI_API_TIMEOUT}}` 秒无响应
- 历史查询返回 `{}` 超过 `{{COMFYUI_POLL_TIMEOUT}}` 秒

**修复**：
- 等待 `{{COMFYUI_API_TIMEOUT}}` 秒重试
- 长时间无响应则中断当前任务：`POST {{COMFYUI_URL}}/interrupt`
- 重启 ComfyUI

## 类别 2：工作流错误

### 错误 W1：节点类未找到

**症状**：

```
<class_type> not found: ApplyInstantID
```

**修复**：

```bash
# 方案 1：ComfyUI-Manager
# 在界面打开 Manager → Install Missing Custom Nodes

# 方案 2：手动安装
cd {ComfyUI}/custom_nodes
git clone https://github.com/cubiq/ComfyUI_InstantID.git
cd ComfyUI_InstantID
pip install -r requirements.txt

# 重启 ComfyUI
```

### 错误 W2：模型文件未找到

**症状**：

```
FileNotFoundError: flux1-dev.safetensors not found in checkpoints
```

**修复**：
- 从 `references/模型清单.md` 查下载链接
- 放到正确目录：
  - `models/checkpoints/`
  - `models/loras/`
  - `models/vae/`
  - `models/controlnet/`
  - `models/clip/`
  - `models/clip_vision/`
  - `models/diffusion_models/`
  - `models/instantid/`
  - `models/insightface/`
  - `models/facerestore_models/`
  - `models/upscale_models/`
- 重启 ComfyUI

### 错误 W3：节点连线错误

**症状**：

```
Inputs failed validation:
  Node ID 5, input "model" requires ["MODEL"] but got ["CLIP"]
```

**修复**：
- 检查连线：`[节点ID, 输出下标]`
- 节点 0 输出是 MODEL，1 输出是 CLIP，2 输出是 VAE
- 修复连线（如 `["1", 0]` 应是模型而非 clip）

### 错误 W4：参数非法

**症状**：
- 步数为 0、CFG 为负数
- 分辨率超出范围

**修复**：
- 步数：1-1000
- CFG：0-30
- 分辨率：64-8192 像素（按显存）
- 批量：1-64

### 错误 W5：自定义节点版本过旧

**症状**：

```
ImportError: cannot import name 'X' from 'nodes'
```

**修复**：

```bash
cd {ComfyUI}/custom_nodes/{节点包}
git pull
pip install -r requirements.txt
```

## 类别 3：质量错误

### 错误 Q1：人脸崩坏

**症状**：
- 脸部变形
- 眼睛错位
- 皮肤糊状

**修复**：

| 方法 | 强度 |
|------|------|
| 负面提示词 | `(deformed face:1.3), (cross-eyed:1.2), (poor facial details:1.2)` |
| 提升 CFG | FLUX 3.0 → 4.0；SDXL 7 → 8 |
| 增加步数 | FLUX 28 → 35；SDXL 30 → 40 |
| 换身份保持 | 提升 InstantID/PuLID 强度 |
| 用人脸修复 | `FaceDetailer` + `codeformer.pth` |
| 调整提示词 | 移除"abstract, surreal"等冲突词 |

### 错误 Q2：手部畸形

**症状**：
- 多余手指
- 手指粘连
- 手部消失

**修复**：
- 负面提示词：`(extra fingers, mutated hands:1.4), (extra limbs:1.3)`
- 用手部修复 LoRA（如 `hands-fix`）
- 提升分辨率（手部需要细节）
- 用 ControlNet（深度图控制手部姿态）

### 错误 Q3：过饱和 / 偏色

**症状**：
- 颜色不自然
- 整体偏橙/偏蓝

**修复**：
- 降低 CFG（FLUX 3.5 → 2.5；SDXL 7 → 5）
- 换采样器（dpmpp_2m + karras 通常稳定）
- 调整提示词（移除"vivid, saturated"等）
- 用 `ImageColorCorrect` 节点后处理

### 错误 Q4：过拟合 / 模式崩坏

**症状**：
- 所有图风格雷同
- 训练图被完美复刻（LoRA）

**修复**：
- LoRA 训练：降低 epoch、增加数据集多样性、提高 caption_dropout
- 推理：降低 LoRA 强度（0.9 → 0.6）
- 换不同种子
- 调整提示词避免重复

### 错误 Q5：构图不当

**症状**：
- 主体不在画面中心
- 主体被截断

**修复**：
- 提示词加入"centered, full body, looking at camera"
- 提升分辨率
- 用 ControlNet 控制构图（深度图、姿态）

### 错误 Q6：风格不符

**症状**：
- 期望写实得到卡通
- 期望现代得到复古

**修复**：
- 提示词加入明确风格词
- 降低 CFG（让模型更自由）
- 换 LoRA 或 IP-Adapter

## 类别 4：性能错误

### 错误 P1：显存不足（OOM）

**症状**：

```
torch.cuda.OutOfMemoryError: CUDA out of memory.
Tried to allocate 2.00 GiB (GPU 0; 24.00 GiB total capacity; 22.50 GiB already allocated)
```

**修复方案**：

| 显存 | 建议 |
|------|------|
| < 12GB | SD1.5 / FLUX FP8 / FramePack |
| 12-16GB | SDXL / FLUX FP8 / HunyuanVideo 1.5（小批量） |
| 16-24GB | FLUX FP16 / Wan 2.2 14B（小批量） |
| 24GB+ | 全模型原生 |
| 32GB+ | 无限制 |

**操作**：

```bash
# 减小批量
# 在工作流中降低 batch_size

# 降低分辨率
# 1024 → 768

# 用 FP8 量化
python main.py --fp8_e4m3fn-unet

# 启用 --lowvram / --novram
python main.py --lowvram

# 关闭并行模型（卸载 LoRA、ControlNet 等）
```

### 错误 P2：生成缓慢

**症状**：
- 单图生成 > 5 分钟
- 视频帧率 < 1 fps

**优化**：

| 方案 | 加速 | 备注 |
|------|------|------|
| TeaCache | 30% | 节点安装 |
| WaveSpeed（FBCache） | 最高 2x | 节点安装 |
| Nunchaku（SVDQuant） | 2-3x | INT4 量化 |
| NVFP4（RTX 50） | 3x | 需 PyTorch cu130 |
| NVFP8（任意英伟达） | 2x | 通用 |
| AnimateDiff Lightning | 4-8 步 | 视频 |
| SageAttn（FramePack） | 30% | 视频 |

### 错误 P3：启动缓慢

**症状**：
- ComfyUI 启动 > 60 秒

**原因**：
- 加载过多节点包
- 启动时扫描所有模型

**修复**：
- 关闭不用的自定义节点
- 移除 `custom_nodes/` 下不用的包
- 启动参数 `--preview-method auto`

### 错误 P4：UI 卡顿

**症状**：
- 浏览器响应慢
- 工作流操作延迟

**修复**：
- 关闭浏览器硬件加速
- 用 `--listen 0.0.0.0` 暴露服务
- 用 `ComfyUI-Manager` 清理无依赖

## 类别 5：其它错误

### 错误 O1：权限拒绝

**症状**：

```
PermissionError: [Errno 13] Permission denied: 'models/...'
```

**修复**：

```bash
# Linux/macOS
chmod -R 755 {ComfyUI}/models/
chown -R $USER:$USER {ComfyUI}/

# Windows（PowerShell）
icacls "{ComfyUI}\models" /grant "$($env:USERNAME):(OI)(CI)F" /T
```

### 错误 O2：路径含中文/特殊字符

**症状**：
- 路径解析失败
- 模型加载报错

**修复**：
- ComfyUI 路径避免中文
- 模型文件名仅用英文/数字/连字符
- 用符号链接指向实际目录

### 错误 O3：版本不匹配

**症状**：
- 节点导入失败
- API 字段不存在

**修复**：

```bash
# 更新 ComfyUI
cd {ComfyUI}
git pull
pip install -r requirements.txt

# 更新所有自定义节点
# 用 ComfyUI-Manager 的 "Update All"
```

### 错误 O4：磁盘空间不足

**症状**：

```
OSError: [Errno 28] No space left on device
```

**修复**：
- 清理 ComfyUI 输出目录
- 删除不需要的检查点
- 清理 pip 缓存：`pip cache purge`
- 清理 huggingface 缓存：`~/.cache/huggingface/`

## 视频生成专项错误

### 错误 V1：视频帧缺失

**症状**：
- 输出视频只有部分帧
- 时间不连续

**修复**：
- 检查 VAE 版本（Wan / HunyuanVideo / LTX 各自专用）
- 用 `VHS_VideoCombine` 而非 `SaveImage`
- 检查 fps 与总帧数匹配
- 长视频拆分为多段

### 错误 V2：视频时间不一致

**症状**：
- 帧间跳变
- 时间漂移

**修复**：
- 启用 `WanVideoSampler` 的 consistency 设置
- 用 FramePack 处理长视频
- 后期用 RIFE 帧插值平滑

### 错误 V3：黑屏 / 绿屏

**症状**：
- 视频全黑或全绿
- 仅首帧正常

**修复**：
- 检查 VAE（必须用对应模型的 VAE）
- 检查输入图像（不能全黑/全白）
- 减少 CFG（避免饱和）
- 更换采样器

### 错误 V4：口型不同步

**症状**：
- 嘴部动作不匹配音频
- 提前/滞后

**修复**：
- 检查音频采样率（16k / 24k Hz）
- 视频 fps 与音频时长匹配
- 换 LatentSync 1.6（Wav2Lip 备用）
- Wan 2.6 用内置口型同步

## LoRA 训练专项错误

### 错误 T1：训练不收敛

**修复**：
- 提升 learning_rate（1e-4 → 2e-4）
- 增加 epoch
- 检查数据集质量
- 换 AdamW8bit → Lion（可能更稳定）

### 错误 T2：过拟合

**修复**：
- 降低 epoch
- 降低 learning_rate
- 增加数据集多样性
- 提高 caption_dropout_rate（0.1 → 0.2）

### 错误 T3：训练时显存不足

**修复**：
- 启用 gradient_checkpointing
- 用 FP8 / NF4 量化
- 降低 batch_size
- 用 FluxGym / SimpleTuner
- 启用 8bit Adam

### 错误 T4：推理不像

**修复**：
- 调整 LoRA 强度
- 换更近的训练检查点
- 检查提示词是否包含触发词
- 评估参考图质量

## 排查流程

```
1. 抓取错误信息
   ├─ 接口响应
   ├─ 控制台日志
   └─ 用户描述

2. 归类（服务/工作流/质量/性能/其它）

3. 匹配模式（参考上文）

4. 给出修复方案

5. 验证
   ├─ 重启 ComfyUI
   ├─ 重新生成
   └─ 对比前后

6. 记录
   └─ 写入项目笔记
```
