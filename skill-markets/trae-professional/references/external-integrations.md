# 外部应用授权（GitHub + 飞书）

## 1. GitHub

> 将 GitHub 集成至 TRAE Work，可在 AI 辅助编码后快速发起 PR，或让 AI 检查代码变更。
> **仅 Code 模式支持。**

### 集成步骤

1. 头像 → **设置** → **外部应用授权**
2. GitHub 应用处 → **连接** → 登录 GitHub → 授权 **TRAE-AI CN**
3. 完成后集成方显示 **Web** 和 **Desktop**

### 创建 PR

**前置：选择仓库 + 分支**

| 客户端 | 操作 |
|--------|------|
| 网页版 | 对话框左下 **选择仓库** |
| 桌面版 | 打开 GitHub 拉取的项目 → 对话框左下选 **云端** 模式 → 选分支 |

**两种方式：**

#### AI 创建 PR
1. AI 完成任务后，对话框上方显示 `remote-agent` 开头的 PR 信息
2. 点击 **AI 创建 PR** → AI 比较分支差异 → 生成摘要
3. 点击摘要旁箭头 → **DiffView** 查看每个文件具体变更
4. 确认无误 → "接下来您想做什么？" → **创建 PR** → GitHub 窗口展示 PR 信息 → 合并

#### 手动创建 PR
`···` → **手动创建 PR** → GitHub 窗口展示 PR 信息 → 合并

### AI 检查 PR
创建 PR 后 → **AI 检查 PR** → AI 查看变更内容 + 执行 `git diff` 获取详细信息。

## 2. 飞书

> TRAE Work 与飞书 CLI 建立授权连接后，可直接访问飞书功能：云文档 / 多维表格 / 日历 / 消息 / 邮箱 / 会议 等。
> 免手动配置 MCP Server。

### 使用场景

- **需求文档驱动的代码开发**：引用飞书 PRD/技术方案/接口文档 → AI 解析 → 生成代码
- **多维表格驱动的任务管理**：作为任务看板或数据源 → AI 自动读取/更新记录
- **团队协作与信息同步自动化**：评审/联调创建日程 → 妙记纪要同步至云文档

### 授权步骤

1. 左栏 → **插件市场** → 右上 **管理**
2. **管理** 面板 → **应用授权** 页签
3. 飞书应用右侧 → **链接** → 跳转飞书权限授权页
4. 选择授权的飞书权限 → **确认授权** → 二次确认账号与权限 → **授权**
5. TRAE Work 自动安装本地 CLI 及相关技能以启用飞书功能

### 权限清单（飞书 12 大功能）

| 功能 | 核心操作 |
|------|----------|
| **幻灯片** | 更新 / 创建 / 查看 / 编辑 |
| **知识库** | 查看 / 更新节点 / 复制 / 创建节点 / 管理成员 / 获取空间 |
| **任务** | 查看 / 管理任务、清单、评论、附件、自定义字段、分组 |
| **会议** | 查看录制 / 妙记 / 纪要 / 搜索会议 / 上传妙记 / 更新妙记 |
| **邮箱** | 查看 / 发送 / 邮件联系人 / 主题 / 正文 / 订阅事件 / 修改邮件 |
| **即时通讯** | 发送/撤回/查看/搜索消息、群信息/成员管理、表情回复、标记管理 |
| **审批** | 管理/查看任务、实例 |
| **多维表格** | 数据表/记录/字段/视图/表单/工作流/角色/仪表盘的全套增删改查 |
| **日历** | 创建/更新/删除/查看日历与日程，忙闲状态 |
| **通讯录** | 查看/搜索用户基础信息 |
| **云文档** | 访问/查看/创建/编辑/搜索/评论/权限/历史/媒体/协作者 |
| **云空间** | 元数据 / 文件夹 / 上传 / 移动 / 下载 / 容量 / 浏览记录 |
| **电子表格** | 创建 / 编辑 / 查看 + 元数据 |
| **获取用户身份标识** | open_id 等身份标识 |
