# 工作树（Worktree）

> 让不同任务在相互隔离的 Git 环境中执行。适合同一项目并行处理多个任务（开发新功能 + 修复紧急漏洞）并避免代码冲突。
> **仅本地任务适用**。

## 前置条件

- 已安装 Git
- 本地环境运行

## 名词解释

| 名词 | 描述 |
|------|------|
| **工作树** | Git 原生机制，单个仓库同时拥有多个独立工作目录，每个目录可检出不同分支 |
| **工作树分支** | 当前工作树检出的 Git 分支（如 `feat-pet-shop-1sfbnt`） |
| **工作树目录** | 工作树关联的本地文件夹路径（`/{worktree_branch_name}`） |

## 创建工作树

发起任务前，对话输入框左下角 → 将模式设为 **工作树**。
任务启动后智能体自动创建专属工作树分支和目录；对话输入框顶部显示带工作树标记的新分支。

## 合并代码

智能体在工作树中完成编码后：

### AI 自动合并
对话框顶部工作树分支栏 → **AI 合并** → AI 自动分析变更、解决冲突、合并。

### 手动合并
工作树分支栏 → `···` → **手动合并** → 按指引操作；冲突时点 **AI 解决冲突**。

> 代码合并后，对话流底部显示"代码已合并"分割线。分割线上方的对话**无法回退**。

## 磁盘占用查看

**设置 → 工作树 → 工作树磁盘占用**：查看所有项目下各工作树占用空间。

## 清理工作树

清理会彻底删除本地工作树目录（释放磁盘空间），但**任务对话历史与代码变更记录保留**；可选是否保留 Git 分支。

| 方式 | 步骤 |
|------|------|
| **任务列表** | 左侧任务栏 → 悬停目标 → `···` → **删除工作树** → 勾选保留分支 → 删除 |
| **设置中心** | 设置 → 工作树 → 选中工作树 → 清理 → 勾选保留分支 → 删除 |
| **工作树分支栏** | 对话框顶部工作树分支栏 → `···` → **删除工作树**（已完成合并则直接显示该按钮） |

## 清理相关设置

**设置 → 工作树 → 工作树清理**：

| 设置 | 描述 |
|------|------|
| **清理工作树时默认保留分支** | 删除时默认勾选"保留工作树分支" |
| **工作树磁盘空间占用提醒** | 阈值提醒，达到阈值后通知清理 |
