## 工作流步骤

### Step 1: 伏笔回收审计

```
统计:
  已埋未收: N 个
  已回收: M 个
  回收率 = M / (N+M) × 100%

要求:
  回收率 ≥ 90%
  < 90% → 列出未回收伏笔 → 计划补回收章

特殊处理:
  "故意不回收"的伏笔 → 标注原因(卷五回收/系列续作)
  "无法回收"的伏笔 → 删除或重写到可回收
```

### Step 2: 节奏热力图

```
逐章绘制:
  X 轴: 章号
  Y 轴: 六维总分 + 情感温度

识别:
  塌陷区: 连续 ≥3 章总分 < 70
  过度区: 连续 ≥4 章总分 > 85 (读者疲劳)
  情感断层: 相邻两章温度差 > 40

修正:
  塌陷区 → 重写或补充亮点
  过度区 → 插入过渡章/放缓节奏
  情感断层 → 插入缓冲章
```

### Step 3: 涟漪终审

```
运行: ripple.py --full-project
要求:
  零 BLOCKER
  零 CRITICAL
  HIGH ≤ 3
  MEDIUM ≤ 10

处理:
  每个 HIGH → 修复计划
  每个 MEDIUM → 评估是否值得修复
```

### Step 4: 宪法终审

```
运行: check.py --mode score --min-score 0.95
要求:
  宪法合规: 100% (零违规)
  术语合规: 零废弃术语残留
  概念一致性: 零概念漂移

任何违规 → 修复
```

### Step 5: 创意终审

```
Creative Director 进行全局审查:
  1. 读完整个故事，读者得到了什么？
  2. 核心主题是否贯穿全书？
  3. 主角的弧线是否完整？
  4. 有没有"为写而写"的章节？
  5. 结局是否有分量？（值得读者投入的时间）
```

### Step 6: 审美终审

```
Creative Director 进行审美审查:
  1. 这部小说的"气味"是否一致？
  2. 武戏是否至少留下 3 个关键帧？
  3. 文戏是否有至少 3 个让读者心头发热的瞬间？
  4. 有没有"模板化"的描写？（"他的眼中闪过一丝精光"——删除）
  5. 语言风格是否统一？（不能前半部文言后半部口语）
```
