# 一、基础语法规范

> ⚠️ **角色对话 vs 旁白（关键区分，经验 §5.1）**：
> - 角色对话 → `角色名:内容;`（如 `邱苏晚:你好。;`）
> - 旁白 → `{旁白}:内容;` 或 `:内容;`
> - **绝对禁止用 `{旁白}` 代替角色名写对话**。错误后果：TTS 配音时该角色为 0 句配音，无法分辨说话者
> - 主角内心独白同样使用主角名而非 `{旁白}`：
>   ```webgal
>   ; ✅ 正确
>   林之一:我该怎么办？;
>   
>   ; ❌ 错误（导致 TTS 丢失）
>   {旁白}:我该怎么办？;
>   ```
> - 已踩坑：6 个文件 33 处旁白转述修复后才解决

## 1.1 语句结构

每条 WebGAL 脚本语句以英文分号 `;` 结尾。命令与参数之间以英文冒号 `:` 分隔，参数之间以 `-参数名=参数值` 形式指定。

```
命令:语句内容 -参数1=值1 -参数2=值2;
```

入口脚本为 `scene/start.txt`（必须存在，不可重命名）。

## 1.2 注释

- 以英文分号 `;` 开头的整行被视为注释
- 任何命令语句中第一个 `;`（`\;` 除外）后的内容视为**行内注释**
- 行内注释不会改变该行的命令类型

```webgal
; 这是一个注释
changeFigure:1/open_eyes.png -id=aaa;
setTransform:{"position":{"x":-500}} -target=aaa -duration=500; 给立绘 B 让位置
```

## 1.3 特殊符号转义

如果需要在文本中显示 `:` `;` `|` `,` `.` 等特殊符号，前面加反斜杠 `\` 转义：

| 原符号 | 写法 |
|:---|:---|
| `:` | `\:` |
| `;` | `\;` |
| `\|` | `\\|` |
| `,` | `\,` |
| `.` | `\.` |

在文本拓展语法中写 CSS 时，分号同样需写成 `\;`，否则会被当作注释开始。

## 1.4 通用参数

以下参数可应用于**任何** WebGAL 命令：

| 参数 | 类型 | 说明 |
|:---|:---|:---|
| `-next` | 布尔 | 执行当前语句的同时，同步执行接下来的语句，直至遇到 `next` 为 `false` 的语句 |
| `-when` | 字符串 | 书写条件表达式，仅当条件为 `true` 时执行当前语句 |
| `-continue` | 布尔 | 当前句演出结束后，自动执行下一句（即使玩家未开启自动播放） |

自带 `-next` 的命令：`bgm`、`pixiPerform`、`pixiInit`、`miniAvatar`、`label`、`setVar`、`unlockCg`、`unlockBgm`、`filmMode`、`playEffect`、`setTransition`、`applyStyle`。

自带 `-continue` 的命令：`wait`、`intro`（`hold` 与 `userForward` 均为 `false` 时）、`playVideo`。
