# W_INIT · 系统初始化

> 场景: skill-novel-engine 首次接入项目，或项目发生大规模变更后重建基线
> 耗时: 3-5 分钟（取决于项目规模）
> 产出: 初始化报告（基线分数 + 已知问题 + 索引地图）

---

## 触发条件

| 信号 | 示例 |
|------|------|
| 首次安装 skill | "做系统初始化" / "初始化引擎" |
| 大规模重构后 | "重建基线" / "重新索引项目" |
| 项目迁移后 | "接入新项目" / "切换项目" |

## 七阶段初始化流水线

`
Phase 1 · 项目发现 → Phase 2 · 世界观索引 → Phase 3 · 人物索引
→ Phase 4 · 剧情索引 → Phase 5 · 章节索引 → Phase 6 · 状态索引
→ Phase 7 · 交叉验证 + 初始化报告
`

### Phase 1 · 项目发现 (World Architect)

**目标**: 绘制完整文件地图，确定各层文件数量和路径。

**操作**:
1. 运行 scripts/discover.py 扫描项目目录结构
2. 识别各层文件清单（世界观/人物/剧情/章节/状态）
3. 估算总文件数和索引时间

**产出**: 文件清单 JSON

### Phase 1.5 · 悲观结构检查 (Consistency Auditor)

**目标**: 验证项目结构完整性——逐项检查必需文件是否存在。

**操作**:
`powershell
cd skill-novel-engine/scripts
python discover.py --mode check
`

**产出**: 缺失文件清单（阻塞级/建议级/可选级）+ 结构健康报告

**门禁**: 阻塞级 0 缺失 → 可进入下一阶段。否则停止，提示用户创建缺失文件。

### Phase 2 · 世界观索引 (World Architect)

**目标**: 提取全部世界观概念，建立四层索引。

**阅读清单**:
- 创作正文/世界观/亚文化建设宪法.md — 7 条公理
- 创作正文/世界观/亚文化四层索引.md — 导航中枢
- 创作正文/世界观/底层设计.md — 物理/法则
- 创作正文/世界观/修真物理学.md — L场/灵子模型
- 创作正文/世界观/势力版图.md — 势力关系
- 创作正文/世界观/赛博修真科技树.md — 科技节点
- 其余世界观文件 — 补充概念

**产出**: 世界概念索引（概念名 → 定义 → 来源文件 → 关联概念）

### Phase 3 · 人物索引 (Plot Orchestrator)

**目标**: 提取全部角色档案，建立关系图。

**阅读清单**:
- 创作正文/人物/ 全部文件（主角 + 配角 + 关系图）
- 提取: 角色名 / 身份 / 弧线 / 关键章节 / 与其他角色关系

**产出**: 角色索引（角色名 → 档案路径 → 状态 → 关系列表）

### Phase 4 · 剧情索引 (Plot Orchestrator)

**目标**: 提取全卷骨架和伏笔网络。

**阅读清单**:
- 创作正文/剧情/全卷骨架_卷一~五.md — 各卷阶段划分
- 创作正文/剧情/伏笔追踪.md — 伏笔投放与回收
- 创作正文/剧情/ 其余文件 — 叙事扩散/失忆线/奇遇线

**产出**: 剧情索引（卷 → 阶段 → 关键事件 → 伏笔ID → 回收章节）

### Phase 5 · 章节索引 (Scene Composer)

**目标**: 逐章提取关键快照（时间/地点/人物/科技状态/伏笔）。

**阅读清单**:
- 创作正文/章节规划/卷一/ 全部 86 个章节索引文件

**提取字段**:
| 字段 | 说明 |
|------|------|
| chapter_num | 章节号 |
| title | 章节标题 |
| timeline | 时间节点 |
| location | 地点 |
| characters_present | 出场角色 |
| tech_nodes | 科技树进展 |
| foreshadow_ids | 投放/回收的伏笔 |
| key_events | 关键事件摘要 |
| next_chapter_hook | 衔接钩子 |

**产出**: 章节快照索引（86 条记录）

### Phase 6 · 状态索引 (Consistency Auditor)

**目标**: 加载注册表、审计报告、术语表，建立验证基线。

**阅读清单**:
- 创作正文/状态/S00_项目工作台.md — 当前优先级
- 创作正文/状态/S01_会话上下文.md — 上轮状态
- 创作正文/状态/S10_概念注册表.yaml — 概念 canonical 定义
- 创作正文/状态/S11_概念注册表.md — Markdown 版注册表
- 创作正文/状态/S12_术语注册表.md — 废弃术语清单
- 创作正文/状态/S20-S24_审计报告_卷一~五.md — 已知问题

**产出**: 验证基线（废弃术语数 / 已知审计问题 / 概念数）

### Phase 7 · 交叉验证 + 初始化报告 (Consistency Auditor + Creative Director)

**目标**: 运行全套工具链，生成初始化报告。

**执行**:
`powershell
cd skill-novel-engine/scripts
python check.py --mode score          # 一致性基线
`

**报告生成**:
1. 汇总 Phase 1-6 的所有索引数据
2. 标注不一致/缺失/冲突
3. 按优先级排序问题
4. 输出 创作正文/状态/S60_初始化报告_YYYYMMDD.md

## Agent 分配（并行策略）

初始化可大量使用并行 Agent 加速：

`
Phase 1 (串行, 1 agent) → discover.py
Phase 2-4 (并行) → 3 个 explorer 同时读世界观/人物/剧情
Phase 5 (并行) → 2-3 个 explorer 各读 30 章
Phase 6 (串行) → 1 个 explorer 读状态文件
Phase 7 (串行) → 1 个 worker 汇总 + 运行脚本
`

总耗时: ~3-5 分钟（并行后）

### Phase 7.5 · 数据库初始化 (Consistency Auditor)

**目标**: 初始化 SQLite 知识库——从 YAML + Markdown 填充结构化数据。

**操作**:
`powershell
cd skill-novel-engine/scripts
python init_db.py --force
`

**产出**: 创作正文/状态/project.db — 21 表 · 13 概念 · 86 章 · 398 场景 · 5 卷

**验证**: 运行后确认 concept > 0 AND chapter > 0 AND volume > 0
