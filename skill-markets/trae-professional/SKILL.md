## 核心概念速查

### 产品定位
TRAE IDE 是深度融合 AI 的开发工具，覆盖「代码编写 → 项目理解 → 调试运行 → 变更管理」全流程。支持传统 IDE 模式（精细控制）和 SOLO 模式（AI 主导）。

### 双重开发模式

| 模式 | 描述 | 推荐场景 |
|------|------|----------|
| **IDE 模式** | 保留编辑器、终端、调试、插件、Git 等传统工作流 | 需要精细控制代码改动 |
| **SOLO 模式** | AI 主导，自然语言 → 自动规划 → 代码生成 → 预览 | 快速构建、复杂任务自动化 |

切换方式：界面左上角按钮。

### TRAE Work 客户端
独立 AI 工作台，三端形态：
- **网页版** (work.trae.ai)：无需安装、云端环境、开箱即用
- **桌面版**：文字/语音/附件/技能多元输入、实时进度、深度性能优化
- **移动版**：按住说话、跨设备管理、离线自动切云端、三端实时同步

设有 Work（面向非开发者）和 Code（面向开发者）双模式。同一账号体系，任务数据三端全量同步。

### AI 编程能力

- **模型**：内置多种先进模型，支持 API Key 接入自定义模型
- **智能体 (Agent)**：自然语言定义任务，AI 检索代码库、制定计划、调用工具完成开发
- **CUE**：仓库级智能代码补全（代码补全、多行修改、修改点预测与跳转、智能导入、智能重命名）
- **上下文**：支持文件/文件夹/终端输出/代码仓库/文档集/网页作为上下文

### 开发工具链
Git 工作流 + AI 生成 Commit Message、智能代码审查（摘要+流程图+diff）、插件生态、Remote SSH/WSL 远程开发。

### 安全能力
- **隐私模式**：对话和代码不用于训练，文件保存在本地
- **沙箱运行**：命令在受限环境执行，文件访问控制 + 高风险命令拦截

## 常见问题快答

### "SOLO Agent 的 Plan 和 Spec 模式有什么区别？"

| | Plan 模式 | Spec 模式 |
|------|----------|------------|
| 适用 | 中小型功能开发、模块重构 | 复杂系统级任务 |
| 产出 | 规划文档 | spec.md + tasks.md + checklist.md 三文档组 |
| 存储 | 对话中 | `.trae/specs/` 目录，可版本控制 |
| 启用 | `/plan` | `/spec` |

### "怎么创建自定义智能体？"
输入框 @ → 创建智能体 → 选择"智能生成"或"手动创建"。配置：名称、提示词、是否可被调用、MCP Server、内置工具（阅读/文件系统/终端/联网搜索/预览）。

### "Hook 钩子是什么？怎么用？"
Hook 是 v3.5.66 新增的自动化机制。用户自定义 Shell 命令，在智能体生命周期的特定事件节点自动触发执行。与规则/技能不同，Hook 执行的是 Shell 命令而非文本指令，用于实现安全检查、自动格式化、环境初始化等确定性自动化操作。详情参考 `references/hooks.md`。

### "技能(Skill)和规则(Rule)有什么区别？"
- **技能**：按需加载，描述「如何完成任务」（如测试流程）→ SKILL.md 定义
- **规则**：全量加载，约束 AI 行为（如代码风格）→ Markdown 定义
- **MCP Server**：提供可调用的「工具」（如 Playwright）

### "如何安装 MCP Server？"
设置 → MCP → 添加 → 从市场添加 / 手动添加。项目级 MCP 在 `.trae/mcp.json` 中配置，需在设置中开启。

### "沙箱怎么配置？"
设置 → 对话流 → 自动运行命令 → 沙箱运行（支持白名单）。自定义配置：编辑 `~/.trae/sandbox.json`，可控制文件读写权限和网络访问策略。

### "CUE 有哪些功能和快捷键？"
- Tab 接受补全建议、Escape 拒绝
- Ctrl+→ 逐字接受、Alt 预览采纳后状态
- Shift+Win+C 展开 Cue-Pro 视图、Alt+↓↑ 跳转变更
- Cue-Pro 是仓库级链式补全，学习编辑顺序生成连续建议

### "能接入自己的模型吗？"
支持通过 API Key 接入自定义模型，可在设置中配置自定义请求地址。

### "规则怎么嵌套和组织？"
`.trae/rules/` 下支持最多 3 层子文件夹。子目录也可创建 `.trae/rules/`，当 AI 读取该目录文件时自动应用。兼容 AGENTS.md、CLAUDE.md。
