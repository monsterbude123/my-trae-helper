# 自定义智能体 (Agent)

## 创建方式

### 智能生成（推荐）
1. 输入框 `@` → "创建智能体" → "智能生成"
2. 描述功能、使用场景、使用时机 → "生成"
3. 按需修改参数

### 手动创建
自行配置所有参数。

## 配置参数

| 参数 | 说明 |
|------|------|
| 头像 | 可选 |
| 名称 | 智能体显示名称 |
| 提示词 | Prompt：人设、口吻、工作流程、工具使用时机、规范 |
| 可被其他智能体调用 | 需配英文标识名和调用场景（仅 SOLO Agent 可调用） |
| 工具 | MCP Server + 内置工具 |

## 内置工具

| 工具 | 能力 |
|------|------|
| 阅读 | 检索和查看文件 |
| 文件系统 | 文件增删改查 |
| 终端 | 运行命令并获取结果 |
| 联网搜索 | 搜索网页内容 |
| 预览 | 提供预览入口 |

## 管理

- **使用**：输入框 `@` → 选择智能体
- **修改**：齿轮 → 编辑
- **分享**：齿轮 → 分享（可分享至 X 或复制链接，建议先脱敏）
- **删除**：齿轮 → 删除

## 导入

点击他人分享的链接 → 浏览器引导打开 TRAE → "立即获取" → 自动导入。
