## 24GB 显存下的能力

| 工作负载 | 状态 | 备注 |
|----------|------|------|
| FLUX.1-dev FP16 | 需要量化 | 24GB 装不下原生 FP16（需 FP8/NVFP4） |
| FLUX.1-dev FP8 | ✅ 原生 | ~16GB，余 8GB 给其他模型 |
| Wan 2.1 14B | ✅ 原生 | 完整质量，无需量化 |
| Wan 2.1 14B I2V | ✅ 原生 | 720p 81 帧 |
| Wan 2.2 14B | ✅ 原生 | 完整质量 |
| Wan 2.2 MoE | ⚠️ 紧张 | A14B 推理峰值可能接近上限 |
| FramePack | ✅ 过剩 | 设计目标 6GB，3090 Ti 跑得很轻松 |
| AnimateDiff + LoRA | ✅ 原生 | batch 4x 可行 |
| SDXL + ControlNet | ✅ 原生 | 多 ControlNet 并行 |
| LoRA 训练 (FLUX) | ⚠️ 需量化 | 标准训练需 24GB+，建议 FP8 + 8bit Adam |
| LoRA 训练 (SDXL) | ✅ 原生 | batch 2-3 |

## 推荐启动参数

```
--listen 0.0.0.0 --preview-method latent2rgb --enable-manager
```

按显存压力，**可叠加**：

```
--fp8_e4m3fn-unet    # FLUX/UNet 用 FP8 节省 ~8GB
--highvram           # 模型驻留显存不卸载（并发场景慎用）
```

## 性能调优要点

- **不要用 `--highvram`**：24GB 不算富余，让 ComfyUI 自动卸载更稳
- **FLUX 默认开 FP8**：原始 FP16 跑不动，必须量化
- **视频生成串行**：不要并发跑两个 Wan 14B 任务
- **Wan 2.6 / LTX-2.3 24GB 起步**：1080p 没问题
- **tiled VAE 仅在 8K+ 放大时开启**，否则浪费
- **batch 2-3 for SDXL**，batch 1 for FLUX/Wan

## 与 .env 配置的关系

本档案是**实际探测结果**（运行时通过 `/system_stats` 获取），`.env` 中的
`GPU_MODEL` / `GPU_VRAM_GB` / `COMFYUI_LAUNCH_FLAGS` 是**人填的标注**。
两者不一致时，**以本档案为准**——它代表真实能力。
