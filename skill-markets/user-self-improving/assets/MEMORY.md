# MEMORY.md (personal)

> **Long-term personal reflection / preferences** — opt-in. Like a personal
> journal for things you want continuity on across all projects.
>
> See [SKILL.md §6](../SKILL.md#6-personal-workspace-files-opt-in) for the
> distinction.

## Usage

- **Write here:** things you want the agent to remember *about you* across
  sessions and projects ("I prefer TDD", "I hate LLM hype words", "I'm
  colorblind — use shapes not just colors in diagrams").
- **Don't write here:** project-specific decisions (those go in project rules),
  task lists (use the agent's task tool), one-off corrections (those go in
  `.learnings/LEARNINGS.md`).
