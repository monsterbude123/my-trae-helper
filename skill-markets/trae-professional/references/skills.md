# 技能（Skills）

> TRAE Work 通过 `SKILL.md` 文件定义和管理技能。每个技能封装指令、脚本及相关资源，为智能体提供可复用、面向特定场景的专业能力。

## 特点

- **结构化**：每个技能 = 一个 `SKILL.md`，描述任务目标、约束、流程、模板、示例等
- **动态按需加载**：智能体先扫描所有技能的简要描述，**仅当判断相关时才加载详细内容**，减少 Token 消耗

## 使用场景

- **保证输出一致性**：把设计规范、团队标准、品牌一致性封装为技能 → 输出稳定可控
- **自动化重复工作流**：测试流程 / 代码规范检查 / 常规数据分析 SOP
- **总结与共享专业能力**：个人经验 / 团队规范通过社区交流群等公共平台复用

## 技能 vs 其他功能

| 对比 | 区别 |
|------|------|
| **技能 vs 规则** | 规则**全量加载**，技能**按需加载**——技能显著降低 Token 消耗 |
| **技能 vs MCP Server** | 技能描述"如何完成任务"，MCP Server 提供"可调用的工具" |
|  | 例：Playwright MCP 提供浏览器操作能力；测试技能约定 POM 设计、测试用例编写流程 |

## 技能类型与目录

| 类型 | 存储位置 |
|------|----------|
| **项目技能** | 项目内 `.trae/skills/`（仅当前项目生效） |
| **全局技能** | `~/.trae-cn/skills`（macOS/Linux），`%userprofile%/.trae-cn/skills`（Windows） |

## 运行环境

| 环境类型 | 适用任务 | 适用客户端 |
|---------|----------|------------|
| **本地** | 仅本地任务 | 桌面版 |
| **云端** | 仅云端任务 + GitHub 拉取项目 | 网页版 + 桌面版 |

## 技能结构

```
skill-name/
├── SKILL.md          # （必须）智能体的核心指令
├── examples/         # （可选）输入/输出示例
│   ├── input.md
│   └── output.md
├── templates/        # （可选）可复用模板
│   └── component.tsx
└── resources/        # （可选）参考文件、运行脚本、素材
    └── style-guide.md
```

## SKILL.md 格式

```markdown
---
name: 技能名称
description: 简要描述这个技能的功能和使用场景
---

# 技能名称

## 描述
描述这个技能的作用。

## 使用场景
描述触发这个技能的条件。

## 指令
清晰的分步说明，告诉智能体具体怎么做。

## 示例 (可选)
输入/输出示例，展示预期效果。
```

## 创建技能

### 方式一：上传本地技能
左栏 → **插件市场** → **技能** 页签 → 右上 **上传技能** → 上传 zip / .skill（含根级 `SKILL.md` 且含 YAML `name` + `description`）→ **确认**

### 方式二：从市场安装
**插件市场 → 技能** 页签 → 搜索 → 点 `+` 安装（默认启用）

## 使用方式

| 方式 | 操作 |
|------|------|
| **手动调用** | 输入 `/` → 选技能；或直接"用 X 技能..."；或技能管理 → 卡片 → **运行技能** |
| **AI 自动调用** | AI 根据任务的"适用场景"描述自动判断加载 |

## 启用/禁用/卸载

**已安装** 页签 → 启用/禁用卡片右侧滑块 → 卸载：点卡片 → 左下 **卸载**
