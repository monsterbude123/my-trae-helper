# 配置与占位符

> 所有可调参数集中在 `.env`，本文件说明**占位符约定**与**查找顺序**。

## 占位符约定

技能包内命令示例使用 `{{VAR}}` 形式的占位符。执行时按以下顺序解析：

1. 进程环境变量（`$COMFYUI_URL` 形式）
2. 项目根目录 `.env` 文件
3. 文档方括号 `[ ]` 中的默认值

| 占位符 | 默认 | 含义 |
|--------|------|------|
| `{{COMFYUI_URL}}` | `http://127.0.0.1:8188` | ComfyUI 服务地址 |
| `{{COMFYUI_INSTALL_DIR}}` | `C:\ComfyUI` | 本地安装路径（离线扫描用） |
| `{{COMFYUI_API_TIMEOUT}}` | `30` | 接口超时（秒） |
| `{{COMFYUI_POLL_INTERVAL}}` | `5` | 轮询间隔（秒） |
| `{{COMFYUI_POLL_TIMEOUT}}` | `600` | 轮询总超时（秒） |
| `{{GPU_MODEL}}` | `RTX 5090` | 当前显卡型号 |
| `{{GPU_VRAM_GB}}` | `32` | 显存（GB） |
| `{{COMFYUI_LAUNCH_FLAGS}}` | `--highvram --fp8_e4m3fn-unet` | 推荐启动参数 |
| `{{COMFYUI_CLIENT_ID}}` | `comfyui-api-skills` | 提交工作流时的客户端标识 |
| `{{OUTPUT_DIR}}` | `ComfyUI/output/` | 结果下载目录 |

## 典型 .env 写法

```bash
# 远程 GPU 服务器
COMFYUI_URL=http://192.168.1.20:8188
COMFYUI_INSTALL_DIR=

# 笔记本低显存
GPU_MODEL=RTX 4060 Laptop
GPU_VRAM_GB=8
COMFYUI_LAUNCH_FLAGS=--lowvram --fp8_e4m3fn-unet
COMFYUI_POLL_INTERVAL=10
```

## 修改流程

1. 复制 `.env.example` → `.env`
2. 编辑 `.env`
3. 重启会话让编排器重新加载

## 与项目清单的关系

`.env` 是**全局**配置；`projects/{项目名}/清单.yaml` 是**单项目**配置。

项目级可覆盖全局，例如：
```yaml
# projects/sage/清单.yaml
comfyui_url: http://192.168.1.20:8188
gpu_vram_gb: 24
```

未指定时回退到 `.env` → 默认值。
