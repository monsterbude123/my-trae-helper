# 十一、脚本规范检查清单

编写/修改完 WebGAL 脚本后，逐项自检：

1. [ ] **所有语句以英文分号 `;` 结尾**（打开文件到最后一行检查）
2. [ ] **冒号、分号全为英文半角**（无中文 `：` `；`）
3. [ ] **每个 `choose` 都有对应的 `label`**（搜索全部 `label:` 确保目标存在）
4. [ ] **每个 `jumpLabel` 目标存在**（搜索确认目标 label）
5. [ ] **`setVar` 与 `if`/`-when` 条件中变量类型一致**（数字和字符串区分）
6. [ ] **条件判断用 `==` 而非 `=`**
7. [ ] **每个 label 分支末尾有 `jumpLabel` 跳出**（避免线性落入下一个分支）
8. [ ] **场景跳转前已清理舞台**（`changeFigure:none` / `changeBg:none` / `:;`）
9. [ ] **资源路径与实际文件匹配**（检查 `background/` `figure/` `bgm/` `vocal/` 等目录）
10. [ ] **`Game_key` 与目录名一致**（config.txt）
11. [ ] **`start.txt` 存在且未被改名**
12. [ ] **未触碰只读目录 `docs/reference/`**
13. [ ] **所有被 `setVar` 设置的变量在至少一处 `if`/`-when` 中被读取**（消除"有设无用"变量）
14. [ ] **所有结局条件与 story-design.md 中的设计稿一致**（逐项对照 变量名 + 逻辑运算符 + 阈值）
15. [ ] **角色对话使用 `角色名:` 而非 `{旁白}`**（确认 TTS 配音可达，经验 §5.1）
16. [ ] **跨文件 flag 传播路径已验证**（无"设而不用"的死 flag）
