# TRAE Work 客户端

> TRAE Work（前身 TRAE SOLO，v0.1.18 / 2026-06-09 正式更名）是字节跳动推出的 **AI 原生工作台**，覆盖网页版、桌面版和移动版，账号体系与任务数据三端实时同步。

## 产品定位

TRAE Work 是与 **TRAE IDE** 并列的产品形态，差异点：

| | TRAE IDE | TRAE Work |
|---|---------|-----------|
| 定位 | 专业 AI 编程 IDE，覆盖编码→调试→重构→部署全流程 | AI 原生工作台，覆盖编码、文档、数据、演示稿、设计 |
| 形态 | 桌面 IDE | 网页版 + 桌面版 + 移动版 |
| 模式 | IDE 模式 / SOLO 模式（Agent 主导） | Work / Code / Design 三模式 |
| 目标用户 | 软件开发者与工程团队 | 所有职业（产品、数据、运营、设计、开发者、领导） |
| 核心能力 | CUE 补全、智能体、Hooks、规则、技能、MCP | 三端协同、云端智能体、技能市场、办公/设计/编码一体化 |

> 一句话：**TRAE IDE 走深（专业开发），TRAE Work 走广（全员职业场景）**。

## 三端形态

| 端 | 入口 | 核心亮点 |
|---|---|---|
| **网页版** | [https://work.trae.cn/](https://work.trae.cn/) | 有网络即用、无需下载、开箱即用云端环境、轻量化交互 |
| **桌面版** | [下载页](https://www.trae.cn/ide/download#solo-download) | 文字/语音/附件/技能多元输入、对话内预览验收、独立运行、深度性能优化 |
| **移动端** | 应用商店搜索 "TRAE"（TRAE APP） | "按住说话"语音输入、跨设备任务管理、离线自动切云端、三端无缝同步 |

### 三端联动

- 共享同一套账号体系和任务数据，任务信息实时三端同步。
- **TRAE 移动端** = 跨设备任务下发中心（手机推送、家庭/公司电脑协同）。
- **TRAE Work 网页版 / 桌面版** = 负责任务执行、深度交互、产物验收。
- 网页版仅支持 **云端** 运行环境；桌面版支持 **本地** 与 **云端** 双环境；移动端可下发到云端或配对电脑。

## 三种模式（桌面版与网页版）

| 模式 | 面向用户 | 典型场景 |
|------|----------|----------|
| **Work 模式** | 产品经理、数据分析师、运营等非开发用户 | 文档处理、数据分析、PPT / Excel 制作、报告撰写 |
| **Code 模式** | 开发工程师 | 编码、调试、代码库管理、Git 工作流 |
| **Design 模式** | 有设计需求的用户（TRAEWork v0.1.21~23 / 2026-06-24 上线） | 设计稿生成、自然语言批量修改、设计系统管理、设计稿转代码 |

> 移动端仅提供 Work + Code 两种模式。

## 核心能力

### 云端智能体（Cloud Agent）

在云端沙箱中执行代码分析、运行和调试。统一运行时 + 依赖管理，避免本地环境差异。
- 网页版只能运行云端任务
- 桌面版可在 **本地 / 云端** 间切换
- 移动端可向云端或已配对电脑下发任务

### 任务管理与多端同步

- 每个任务均有标题、AI 自动生成摘要、产物文件列表、参考信息
- 网页版与桌面版"云端"模式下发起的任务自动同步至另一端
- 移动端与配对电脑之间同步"本地任务"；网页版不参与本地任务同步
- 设备离线时系统自动切到云端执行，任务不中断
- 支持任务置顶、重命名、删除、跨模式全局搜索

### 三端工具面板（桌面版）

| 页签 | 适用模式 | 作用 |
|------|----------|------|
| 任务摘要 | Work / Design | 待办列表 + 任务产物 + 参考信息（技能/文件/联网搜索） |
| 任务摘要 | Code | 待办列表 + 上下文（可点击"压缩"按钮） |
| 浏览器 | 全模式 | 预览 Web 产物、浏览其他网页 |
| 终端 | Code | 运行命令、调试 |
| 画布 | Design | 展示设计成果、导入素材、导出设计文件 |

### 预览与编辑产物（Web 应用）

1. 点击右上角"选择元素"
2. 选择目标元素
3. 三种修改方式：**直接修改**（右侧"设计"/"CSS"面板）/ **评论到对话** / **添加到对话**

### 拓展能力

| 能力 | 入口 | 说明 |
|------|------|------|
| 外部应用授权 | GitHub、飞书 | 由 AI 自动创建 PR 等操作 |
| MCP | 设置 → MCP / 项目级 `.trae/mcp.json` | 连接外部工具与服务 |
| 技能（Skill） | 技能市场 / 项目内 `.trae/skills/` | 装专业能力说明书 |
| 斜杠命令 | 输入 `/` | 自定义快捷指令 |
| 规则（Rules） | `.trae/rules/` | 规范 AI 输出 |

### 移动端特有流程

1. 在手机上用手机号登录 TRAE 移动端
2. 在电脑上用同手机号登录 TRAE Work 桌面版
3. 桌面版 **设置 → TRAE 移动端 → 开启"允许 TRAE 移动端控制当前设备"**
4. 授权访问 `/documents` 目录
5. 配对有效期 **180 天**；可开启"保持电脑唤醒"避免睡眠断任务

> iOS 美区 App Store 未上架 TRAE；需切换其他地区 Apple ID 下载。

## 常见问题

**Q：TRAE Work 收费吗？**
A：提供免费版（含 500 积分/月），付费档可享更高积分、并发数、Seed 模型 2.5 折。

**Q：TRAE Work 和 TRAE IDE 有什么区别？**
A：TRAE IDE 是专业 AI 编程工具；TRAE Work 是 AI 原生工作台，覆盖编程 + 文档 + 数据 + 设计 + 全角色。

**Q：移动端怎么连电脑？**
A：两端用同一手机号登录 → 桌面版开启"允许 TRAE 移动端控制"→ 授权 `/documents` 目录 → 配对 180 天有效。
