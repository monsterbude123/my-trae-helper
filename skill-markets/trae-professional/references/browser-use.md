# 浏览器控制（Browser Use）

> TRAE Work 支持 AI 通过浏览器自动执行网页相关任务，可选内置浏览器或外部 Chrome 浏览器。

## 适用场景

| 场景 | 说明 |
|------|------|
| **信息检索** | 打开指定网页 → 查找资料 → 阅读 → 提取关键信息 |
| **页面操作** | 点击按钮、切换页面、填写表单、其他可交互操作 |
| **结果验证** | 打开本地或线上页面 → 检查展示效果 → 辅助定位布局/文案/交互问题 |

> **使用限制**：**Chat** 智能体无法操作浏览器。

## 内置浏览器 vs 外部浏览器

| 类型 | 效果 |
|------|------|
| **内置浏览器** | AI 在 TRAE Work 内打开浏览器页签并执行操作 |
| **外部 Chrome** | AI 打开的网页被分配至 "TRAE" 组，左侧显示绿色 "TRAE" 标签 |

## 启用内置浏览器

**设置 → 浏览器 → 允许 AI 控制内置浏览器** 开关。

## 启用外部浏览器

1. **设置 → 浏览器** → **连接到 Chrome** → **安装扩展**（跳转 Chrome Web Store）
2. 添加 **Trae Work Browser Extension** → Chrome 状态变 "已连接"
3. 开启 **默认使用外部浏览器** 开关（开启后无论内置开关如何都优先用外部）

## 更多操作

| 操作 | 入口 |
|------|------|
| 清除内置浏览器数据（Cookies、本地存储等） | **内置浏览器 → 清除** |
| 完成浏览器操作后自动截图（不消耗 Token） | **通用 → 自动截图** |
