# 核心循环模式库

> 关联：game-design-doc SKILL.md §核心循环

---

## 8 种经典核心循环

### 1. VN 选择循环

| 阶段 | 内容 |
|------|------|
| Action | 阅读文本 → 面临选择 |
| Reward | 新信息揭示 / 角色好感度变化 |
| Growth | 剧情分支解锁 / 新角色关系建立 |

断裂信号：选择无后果、分支殊途同归 → 玩家失去决策感。
代表：Doki Doki Literature Club, Steins;Gate, Ace Attorney.

### 2. RPG 战斗-成长循环

| 阶段 | 内容 |
|------|------|
| Action | 遇敌 → 战斗决策（攻击/技能/道具/逃跑） |
| Reward | 经验值 + 金币 + 掉落物 |
| Growth | 升级（属性提升）→ 新技能解锁 → 装备强化 |

断裂信号：刷怪无脑（无策略选择）、等级压制（数值碾压一切）。
代表：Final Fantasy, Persona, Dragon Quest.

### 3. 平台跳跃-收集循环

| 阶段 | 内容 |
|------|------|
| Action | 跳跃/奔跑/攀爬通过障碍 |
| Reward | 收集品（金币/星星/月亮） |
| Growth | 新能力解锁（二段跳/冲刺/飞行）→ 可达区域扩展 |

断裂信号：收集品无功能（纯成就点数）、能力解锁不改变探索方式。
代表：Super Mario, Celeste, Ori.

### 4. 卡牌抽-打-弃循环

| 阶段 | 内容 |
|------|------|
| Action | 抽牌 → 出牌 → 结束回合 |
| Reward | 击败敌人 / 获得新卡 |
| Growth | 牌组优化（加入新卡 + 移除弱卡） |

断裂信号：最优解固定（每局同一策略）、新卡加入无决策意义。
代表：Slay the Spire, Hearthstone, Inscryption.

### 5. 模拟建造-管理循环

| 阶段 | 内容 |
|------|------|
| Action | 建造设施 → 分配资源 → 等待产出 |
| Reward | 资源产出 / 居民满意度提升 |
| Growth | 解锁新建筑/新区域/新功能 |

断裂信号：等待无意义（纯挂机）、后期目标缺失（全部解锁后无动力）。
代表：SimCity, Stardew Valley, Factorio.

### 6. Roguelike 死亡-继承循环

| 阶段 | 内容 |
|------|------|
| Action | 探索地牢 → 战斗 → 收集遗物 |
| Reward | 局内货币 / 遗物 / 解锁信息 |
| Growth | 死亡 → 局外永久升级（属性/新道具池/新角色） |

断裂信号：死亡无成长（纯重开）、局外成长过快（碾压前期内容）。
代表：Hades, Dead Cells, The Binding of Isaac.

### 7. 三消交换-消除循环

| 阶段 | 内容 |
|------|------|
| Action | 交换相邻方块 → 三连消除 |
| Reward | 连锁消除 + 分数 + 特殊方块 |
| Growth | 关卡推进（新机制/新障碍/新目标） |

断裂信号：消除无反馈（纯运气）、新机制不改变核心策略。
代表：Candy Crush, Puyo Puyo, Bejeweled.

### 8. 开放世界探索-任务循环

| 阶段 | 内容 |
|------|------|
| Action | 自由探索 → 发现兴趣点 → 接受任务 |
| Reward | 任务奖励 + 地图解锁 + 情报 |
| Growth | 等级提升 / 新区域解锁 / 新能力获取 |

断裂信号：任务同质化（全是跑腿/打怪）、探索无发现（地图虽大但无惊喜）。
代表：Breath of the Wild, Elden Ring, Genshin Impact.

## 循环断裂诊断

| 信号 | 根因 | 修复方向 |
|------|------|----------|
| Action 段无聊 | 选择少、无风险、无变化 | 增加决策维度/随机性/限制条件 |
| Reward 段无感 | 奖励无意义、获得无反馈 | 强化视听反馈/稀缺性/惊喜感 |
| Growth 段停滞 | 成长天花板、边际递减过强 | 引入横向扩展（非数值）/新系统 |

## 循环延长技巧

| 技巧 | 机制 | 适用类型 |
|------|------|----------|
| 支线任务 | 非主线但有独特奖励的内容 | RPG / 开放世界 |
| 图鉴收集 | 全收集成就 + 图鉴奖励 | 卡牌 / 收集类 |
| 成就系统 | 挑战性目标 + 永久展示 | 全部类型 |
| 收藏品 | 隐藏/稀有物品 + 背景故事 | 平台 / 开放世界 |
| 赛季/活动 | 限时内容 + 限定奖励 | 卡牌 / 模拟 |
| 难度梯度 | 通关后解锁高难度 + 新奖励 | Roguelike / RPG |
