# 演进日志

> 技能包更新协议与变更历史。

## 协议

### 何时更新

- 新模型/工具发布
- 关键 bug 修复
- ComfyUI 版本更新
- 节点 API 变更
- 用户反馈的体验问题

### 更新流程

```
1. 识别变更（通过 comfyui-research 或用户报告）
   ↓
2. 在 references/研究日志.md 记录
   ↓
3. 更新对应 references/ 文件
   ↓
4. 更新 references/陈旧度报告.md
   ↓
5. 如涉及 skill 行为，更新 skills/ 下 SKILL.md
   ↓
6. 同步到 IDE 的 skills/ 目录
   ↓
7. 通知用户重启 IDE
```

### 同步命令

```powershell
# 同步单个 skill
Copy-Item -Recurse "{skill_root}\skills\comfyui-api" "$env:USERPROFILE\.trae-cn\skills\comfyui-api"

# 同步整个包
Copy-Item -Recurse "{skill_root}" "$env:USERPROFILE\.trae-cn\skills\comfyui-api-skills"
```

### 兼容性

- 主版本变更（X.0）可能破坏向后兼容
- 次版本变更（X.Y）增加功能，向后兼容
- 补丁版本（X.Y.Z）修复 bug，向后兼容

## 版本历史

### v1.0.0（2026-03-18）

**首次发布**——基于 comfyui-expert 全量中文本地化

**包结构**：
- 1 个编排器（`SKILL.md`）
- 5 个基础层文件（`foundation/`）
- 15 个 skill 模块（`skills/`）
- 9 个参考文件（`references/`）

**核心特性**：
- 全中文界面
- 15 个专项 skill：comfyui-api、comfyui-inventory、comfyui-prompt-interview、comfyui-prompt-engineer、comfyui-workflow-builder、comfyui-character-gen、comfyui-research、comfyui-video-pipeline、comfyui-video-production、comfyui-voice-pipeline、comfyui-lora-training、comfyui-troubleshooter、project-manager、video-assembly、video-publisher
- 三层上下文：基础（~2K tokens）、工作（项目）、参考（按需）
- 15 个 skill 的 YAML frontmatter 完整且合规

**翻译策略**：
- 模型/库/工具名保留英文（FLUX、Wan、LoRA、VAE、ComfyUI 等）
- 首次出现用 `中文名（English Name）` 形式
- API 端点、命令行参数、节点类名、文件名一律英文
- 其余说明性文字全部中文

**目录结构**：

**相比 comfyui-expert 英文版的差异**：

| 方面 | 英文版 | 中文版 |
|------|--------|--------|
| 语言 | 英文 | 全中文（保留专有名词） |
| 编排器文件 | `CLAUDE.md` | `SKILL.md` |
| foundation 文件名 | 英文 | 中文（智能体人设.md 等） |
| references 文件名 | 英文 | 中文（模型清单.md 等） |
| SKILL.md（子 skill） | 英文 | 全中文 |
| skill 数量 | 15 | 15（1:1 对齐） |
| 模型信息 | 同步 | 同步 |
| 工作流模板 | 同步 | 同步 |
