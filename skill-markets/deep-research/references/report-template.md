# Deep Research — 报告模板

> 套这个结构产出。每个章节都不是"必须填"——按需删/合并。

---

## 完整模板

```markdown
# [主题]: 研究报告
*生成日期: YYYY-MM-DD | 来源数: N | 置信度: 高/中/低 | 工具: firecrawl+exa*

## Executive Summary
[3-5 句关键发现，结论先行]
- 关键发现 1（[Source](url)）
- 关键发现 2（[Source](url)）
- 关键发现 3（[Source](url)）

## 1. [第一主要主题 / 子问题 1+2]
### 核心发现
- 事实 A（[Source Name](url)）
- 事实 B（[Source Name](url)）

### 细节与数据
- 关键数据 1（数值 + 单位 + 来源）
- 关键数据 2

### 争议与未验证
- ⚠ 单源声明（仅 [Source X](url) 提及）
- 争议点: A 来源说 X，B 来源说 Y（差异原因？）

## 2. [第二主要主题 / 子问题 3+4]
...（同上结构）

## 3. [第三主要主题 / 子问题 5]
...（同上结构）

## 关键 Takeaways
- [可执行见解 1]（谁该做什么）
- [可执行见解 2]
- [可执行见解 3]

## 数据空白 / 限制
- 子问题 X 找不到 ≥ 2 个独立来源
- 关键数据来自 1 个来源且未发表
- 时效性问题：X 领域 2024 后无新数据

## Sources
1. [Title](url) — 一行摘要（什么类型 / 何时 / 谁）
2. [Title](url) — 一行摘要
3. ...

## Methodology
- 工具: firecrawl / exa（启用哪些）
- 查询数: N 个
- 分析来源: M 个
- 子问题: [list]
- 时间窗口: YYYY-MM-DD 至 YYYY-MM-DD
- 限制: [如 "X 子问题受限于英语来源"]
```

---

## 字段语义

| 字段 | 含义 | 缺失后果 |
|------|------|---------|
| Executive Summary | 3-5 句结论先行 | 用户首屏看不到核心结论 |
| Sources 章节 | 完整 URL 列表 | 不可验证 = 报告作废 |
| Methodology | 工具 + 查询 + 时间 | 不可复现 = 不可信 |
| 数据空白 | 主动声明未找到 | 用户被误导 |
| Takeaways | 可执行（不是简单总结） | 报告只是"信息堆" |

---

## 置信度判定

```
高 (High):
  - 关键事实 ≥ 3 个独立来源印证
  - 数据有原始研究/官方统计支撑
  - 时效性 < 12 月

中 (Medium):
  - 关键事实 2 个来源印证
  - 部分数据来自二手转述
  - 时效性 12-24 月

低 (Low):
  - 关键事实仅 1 个来源
  - 数据多来自行业报告（公司利益相关）
  - 时效性 > 24 月 或 时效不明
```

## 反例（避坑）

```
❌ 摘要写"AI 将改变医疗"（无来源 + 无具体）
✅ 摘要写"2024 年 FDA 批准了 12 个 AI 诊断产品，比 2023 年增长 50%（[FDA 报告](url)）"

❌ 章节只列事实不分析
✅ 事实 + 横向对比 + "对用户的启示"

❌ Sources 只列标题不给 URL
✅ 完整 [Title](url) + 一行摘要
```
