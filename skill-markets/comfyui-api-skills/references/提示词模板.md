# 提示词模板库

> 各模型专用提示词策略与模板。

## 模型速查

| 模型 | 提示词风格 | 长度 | 负面 | 核心 |
|------|------------|------|------|------|
| FLUX.1-dev / FLUX.2 | 自然语言 | 30-80 词 | 可选 | 语义 |
| SDXL | 标签 + 描述 | 50-150 字符 | 必备 | 平衡 |
| SD1.5 | 短标签 | 30-77 token | 必备 | 标签 |
| Wan 2.6 | 动作 + 镜头 | 30-80 词 | 必备 | 运动 |
| HunyuanVideo 1.5 | 详细描述 | 50-150 字符 | 必备 | 摄影 |
| Qwen-Image | 自然语言 | 30-80 词 | 可选 | 排版 |

## FLUX 提示词模板

### 写实人像

```
{Sage}，{服装}，{场景}，{光线}，{镜头}，{情绪}，{风格}
```

**完整示例**：

```
Sage 半身像，身穿棕色皮夹克，森林背景，金色阳光透过树叶，
写实风格，自然光，50mm 镜头，浅景深，专业摄影
```

### 全身像

```
{角色名}全身像，{服装}，{场景}，{姿态}，{镜头}，{风格}
```

**示例**：

```
Sage 全身像，米色长裙，海边日落，双手自然下垂，
写实人像，85mm 镜头，柔和光线
```

### 场景特写

```
{主体}特写，{细节}，{环境}，{光线}，{风格}
```

**示例**：

```
手部特写，握着一杯咖啡，温暖的咖啡馆背景，
自然光，写实摄影，微距镜头
```

### 参数

| 参数 | 范围 | 推荐 |
|------|------|------|
| 步数 | 20-50 | 28-35 |
| CFG | 1-5 | 3.0-3.5 |
| 采样器 | euler, uni_pc, dpmpp_2m | uni_pc |
| 调度 | normal, sgm_uniform | sgm_uniform |
| 分辨率 | 1024-2048 | 1024x1024 |

## SDXL 提示词模板

### 基础结构

```
{masterpiece, best quality, photorealistic:1.4}, {主体}, {特征}, {场景}, {风格}
```

### 完整示例

**正面**：
```
(masterpiece, best quality, photorealistic:1.4), 1girl, auburn hair, green eyes,
freckles, leather jacket, forest, golden hour, professional photography, 50mm lens
```

```
(cartoon, painting, anime:1.3), (deformed, distorted:1.2), (extra limbs, extra
fingers, mutated hands:1.4), (blurry, low quality:1.3), (watermark, text:1.4)
```

## Wan 2.6 视频提示词

### 关键原则

- **描述运动**——而非静态画面
- **镜头术语**——景别、运动、视角
- **时长意识**——3 秒动作 vs 10 秒动作

### 基础结构

```
{主体}，{动作}，{场景}，{镜头运动}，{风格}
```

### 完整示例

**人物动作**：
```
Sage 慢慢转头微笑，森林中阳光斑驳，背景树叶轻微飘动，
电影感，特写镜头，稳定
```

**镜头运动**：
```
从特写缓慢拉远到全身，城市天际线，黄昏，电影感，稳定运镜
```

**对话场景**：
```
Sage 说话时自然眨眼和嘴部动作，室内柔和光线，浅景深，
特写镜头，24fps
```

### 参数

| 参数 | 范围 | 推荐 |
|------|------|------|
| 步数 | 30-50 | 30-40 |
| CFG | 3-7 | 5.0 |
| 采样器 | euler, dpmpp_2m | euler |
| 调度 | karras, normal | karras |
| 分辨率 | 720p / 1080p | 720p |
| 帧数 | 49-121 | 81（3.4 秒） |
| fps | 24 / 30 | 24 |

## 身份保持方法提示词

### InstantID

**原则**：
- 描述**稳定特征**（脸型、眼距、痣的位置）
- 不描述**动态特征**（表情、动作）
- 配合 IP-Adapter 增强相似度

**模板**：
```
{角色名}, {稳定面部特征}, {场景}, {光线}, {风格}
```

**示例**：
```
Sage, oval face, defined cheekbones, green eyes, auburn hair, slight freckles,
leather jacket, forest background, golden hour, photorealistic
```

### PuLID Flux II

**原则**：
- 明确"two people"或"two characters"（双角色）
- 为每个角色编号

**双角色模板**：
```
{场景}，{角色 1 描述}，{角色 2 描述}，{光线}，{风格}
```

**双角色示例**：
```
两位人物并排站立，character_1: Sage 穿皮夹克，character_2: Mike 穿衬衫，
城市街道背景，街头摄影，浅景深
```

### IP-Adapter

**原则**：
- 提示词描述**内容**
- IP-Adapter 提供**风格/构图**

**模板**：
```
{内容描述}, {风格关键词}
```

**示例**：
```
城市街道，霓虹灯，雨夜，电影感，黑色电影风格
```
（IP-Adapter 提供具体风格参考）

### LoRA

**模板**：
```
{LoRA 触发词}, {服装/场景}, {动态描述}
```

**强度**：
- 写实：0.7-0.9
- 风格化：0.5-0.7

**示例**：
```
Sage, leather jacket, forest, golden hour, slowly walking, photorealistic
```

## 实用建议

### 提示词长度

- 30-80 词为甜点
- 过短 → 缺乏控制
- 过长 → 模型关注分散

### 权重标注

FLUX/SDXL 通用：
- `(关键词:1.2)`：权重 1.2
- `(关键词:0.8)`：权重 0.8
- 嵌套权重：`(outer (inner:1.3):1.1)`

### 顺序敏感性

模型对提示词前部更敏感：
- 主体放最前
- 场景其次
- 风格/光线放最后

### A/B 测试

最佳实践：
1. 改一个变量（如换模型）
2. 保留种子
3. 对比结果
