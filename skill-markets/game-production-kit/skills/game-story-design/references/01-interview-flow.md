# 面试流程与剧情设计

## 设计理念

Agent 逐节提案、用户逐节确认。不盲盒输出。不提前写文件。

## 剧情树状图（面试前先画）

在逐节面试开始前，必须先输出剧情树状图。作用：
- 让用户一眼看懂全局结构（共通线→分支→结局）
- 标记所有恐怖陷阱位置（早期/中期/末期分布）
- 标注所有坏结局触发条件（包括早期陷阱死亡结局）
- 为后续面试节提供"总览锚点"

### 树状图格式

```
                                    [开 始]
                                       │
                    ┌──────────────────┼──────────────────┐
                    │                  │                  │
              第一章：日常异变（共通线 · 无法跳过）
                    │
         ┌─────────┼─────────┐
         │         │         │
    [场景A-可调查] [场景B-恐怖陷阱] [场景C-可调查]
     ┌┴┐          ┌┴┐              ┌┴┐
   选择1│选择2  进入│退缩         选择1│选择2
    ║   ║        ║    ║           ║    ║
    ║   ║    [恐怖事件] ║         ║  [坏结局]
    ║   ║     (flag (flag        ║   (死亡原因)
    ║   ║     +1)  trap_        ║
    ║   ║          skip         ║
    ║   ║          =true)       ║
   flag:║                       flag:
   xxx  ║                       yyy
  =true ║                       =true
        ╚═══════════════════════╝
```

### 结局汇总表

| # | 结局 | 类型 | 触发时机 | 触发条件 | 情感落点 |
|---|------|------|----------|----------|----------|
| ① | 名称 | 早期坏结局 | 第X章 | 触发动作 | 情感 |
| ② | 名称 | 中期坏结局 | 第X章 | 触发动作 | 情感 |
| ③ | 名称 | 真结局 | 终章 | 累积flag条件 | 情感 |
| ④ | 名称 | 普通结局 | 终章 | 条件不足 | 情感 |
| ⑤ | 名称 | 坏结局 | 终章 | 放弃/失败 | 情感 |

### 恐怖陷阱分布表

| 位置 | 类型 | 触发方式 | 效果 | 是否致命 |
|------|------|----------|------|----------|
| 场景X | 追逐恐惧 | 选择"回头" | 脚步声加速→屏幕震动→坏结局 | 是 |
| 场景X | 循环恐怖 | 进入某区域 | 重复对话3次→文本变红→畸变 | 否（线索+1） |
| 场景X | 视觉恐怖 | 查看某物品 | 照片人脸替换 | 否（线索+1） |

### 关键原则

- **恐怖陷阱必须早期分布**：第一章就要有致命陷阱和视觉恐怖
- **坏结局 = 游戏性的一部分**：让玩家觉得"这个游戏会死人"，不是惩罚
- **恐怖与线索共存**：恐怖事件同时也是线索获取点
- **flag 驱动一切**：所有选择、所有结局条件，最终都落到 flag 的累积与组合

## 面试 10 节流程

树状图确认后，逐节面试，每节提案后等待用户确认：

| 节号 | 内容 | 说明 |
|------|------|------|
| 1.1 | **核心概念** | 2-3 句话概括故事核心冲突与情感基调 |
| 1.2 | **标题提案** | 提供 3-4 个标题选项 |
| 1.3 | **人物设计** | 逐个角色见下文「人物设计格式」 |
| 1.4 | **场景列表** | 每个场景：名称、触发条件、可调查物、恐怖陷阱、关键对话、对应背景图 |
| 1.5 | **谜题设计** | 线索分布表、解锁条件、变量名定义 |
| 1.6 | **三幕结构** | 25% 共通线 / 50% 发展 / 25% 结局，每幕叙事任务 |
| 1.7 | **伏笔矩阵** | 伏笔元素 → 第一幕种植 → 第二幕发展 → 第三幕收割 |
| 1.8 | **环境叙事检查** | 用画面传递信息而非文字说明？是否有幻象选择？ |
| 1.9 | **多结局** | 早期坏结局 / 中期坏结局 / 真结局 / 普通结局 / 最终坏结局 |
| 1.10 | **恐怖气氛** | 恐怖事件必须早期分布，标注触发点/效果/致命性 |

## 确认格式

每节提案后必须使用：

```
以上是 [节名称] 的提案。

请确认：
1. Yes — 通过，继续下一节
2. Tweak — 告诉我需要调整的地方
3. Rewrite — 换一个方向重新提案
```

用户明确确认前，不写入文件。全部确认后一次性写入 `docs/story-design.md`。

## 三幕结构模板

| 幕 | 占比 | 叙事任务 | 关键事件 |
|----|------|----------|----------|
| 第一幕（共通线） | 25% | 建立日常 → 暗示异常 → 不下结论 | |
| 第二幕（发展） | 50% | 异常扩大 → 选择与分支 → 价值观被测试 | |
| 第三幕（结局） | 25% | 选择结果收敛 → 情感落点 | |

## 多结局设计规范

| 结局类别 | 触发时机 | 触发机制 |
|----------|----------|----------|
| **早期陷阱坏结局** | 第一章/第二章 | 单次选择直接致死 |
| **中期条件坏结局** | 第二章 | 关键事件中未满足勇气/救助条件 |
| **终章结局** | 第三幕 | flag 累积组合判断 |

终章结局的 flag 组合：

```
if: 全条件满足         → 真结局
elif: 部分条件满足      → 普通结局（多种变体）
else:                → 最终坏结局
```

每个结局必须有明确的情感落点（一句话概括玩家感受）。

## 恐怖气氛设计

恐怖元素必须**早期分布**，类型多样化：

| 恐怖类型 | 机制 | 推荐位置 |
|----------|------|----------|
| 追逐恐惧 | 选择错误→立即死亡 | 第一章 |
| 循环恐怖 | 重复场景→微小变化→揭示真相 | 第一章 |
| 视觉恐怖 | 立绘/背景渐变畸变 | 第一~二章 |
| 认知恐怖 | 角色存在被否定 | 第二章 |
| 声音恐怖 | BGM 异常 + 音效 | 全部章节 |
| 电话恐怖 | 单向通讯 + 身份谜团 | 第二章 |

## 环境叙事检查项

| # | 检查项 |
|---|--------|
| 1 | 关键信息是否用画面传递而非文字说明？ |
| 2 | 场景中的物体是否有叙事功能（而非纯装饰）？ |
| 3 | 文字是否避免了描述画面已有内容？ |
| 4 | 是否存在"幻象选择"（选择不产生即时差异）？ |
| 5 | 是否至少有一个环境细节在第二幕发生了变化？ |

核心原则：用画面传递信息，用文字探索内心。
