# P3 工作流 · 细节降噪

> 从章级规划到具体场景
> 主导: Scene Composer | 工具: evaluate.py, combat_narrative.py, drama_narrative.py, theme_check.py

---

## 工作流触发
P2 门禁通过，开始实际写作。

## 每个场景的写作循环

### Loop: 写 → 评 → 修

```
┌─────────────────────────────────────────┐
│  1. 读 8 维索引 + 角色档案 + 宪法       │
│  2. 写场景正文                           │
│  3. 自检 → 六维评估 (evaluate.py)        │
│  4. 评分 < 70 → 修 → 回到 3             │
│  5. 武戏/文戏专项 → 专项引擎评分          │
│  6. 主题 → theme_check.py               │
│  7. 涟漪 → 检查新概念                    │
│  8. 评分满意 → 下一场景                  │
└─────────────────────────────────────────┘
```

### 写作前的强制检查清单

```
□ 已读该章的 8 维索引
□ 已读涉及角色的档案 (allowed_methods / forbidden_methods)
□ 已读本章涉及的宪法公理 (forbids 内容已内化)
□ 已读本章的科技树节点 (必须出现在叙事中)
□ 已确认前章结尾情绪 → 需要承接
```

### 写作中的实时规则

```
感官四通道: 每个重要场景至少覆盖 2 个通道 (视觉/听觉/触觉/灵觉)
量化描写: 数字+单位，不是"威力巨大"
对话: 每句标注 P/E/I Δ (权力/情感/信息)
武戏节奏: 快/慢/静三态交替，连续 3F 无 P = 扣分
文戏温度: 情感跃迁 ≤ 1 级/步
留白: 0.30-0.45 区间
角色红线: 禁止出现角色档案中的 forbidden_methods 关键词
```

### 场景评分门禁

```
六维总分:
  ≥ 85: S 级—直接通过
  70-84: A 级—通过
  60-69: B 级—标记改进，可以暂时通过
  50-59: C 级—需要重写
  < 50: D 级—停止，回到章级规划重新设计

武戏(如果是武戏章):
  质量分 ≥ 70 → 通过
  ＜ 70 → 补充关键帧/调整节奏

文戏(如果是文戏章):
  温度 ≥ 40(温热) → 通过
  ＜ 30(冷却) → 检查情感连续性

主题:
  无"主题断裂"级偏离(25 分)
  "严重偏离" ≤ 1 → 修复
```

## P3 常见陷阱

| 陷阱 | 症状 | 修正 |
|------|------|------|
| 感官贫乏 | 全章只有视觉描写 | 每场景加至少 1 个非视觉感官 |
| 对话纯信息 | 对话只有信息传递，无权力/情感博弈 | 标注每句的 P/E/I Δ |
| 武戏匀速 | 全程快节奏无停顿 | 插入 2-3 个"呼吸点" |
| 情感跳跃 | 从冷漠直接到感动 | 插入至少 1 个中间状态 |
| 角色行为违规 | 林岳调监控/严峰查数据库 | 检查角色档案 forbidden_methods |
