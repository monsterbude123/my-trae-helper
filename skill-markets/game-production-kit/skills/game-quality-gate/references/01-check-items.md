# 质量门禁检查项

> 引擎无关的自动化质量检查。任何检查不通过 → 阻断构建，回到素材管线重新生成。

## 自动化检查项

| 类别 | 检查项 | 阈值 | 失败含义 |
|------|--------|------|----------|
| 立绘 | RGBA 模式 | 必须是 RGBA | BiRefNet 抠图失败 |
| 立绘 | 832x1216 | 精确匹配 | 生成参数错误 |
| 立绘 | 30KB~2MB | 范围内 | 过小=空白图，过大=伪影 |
| 立绘 | HSV 饱和度 | > 5% | 过灰=生成失败 |
| 立绘 | 主体像素占比 | > 30% | 大面积空白/伪影 |
| 背景 | 1216x832 | 精确匹配 | 生成参数错误 |
| 背景 | >=15KB | 最小值 | 过小=单色填充 |
| 标题 | 1920x1080 | 精确匹配 | 生成参数错误 |
| 标题 | >=30KB | 最小值 | 过小=空白 |
| BGM | >=500KB | 最小值 | 可能为静默文件 |
| BGM | RMS/peaks 互异 | 所有文件不相同时 | seed 固定/重复 |
| TTS 配音 | 后 30% RMS | < max_amp × 0.01 | 过长静音 |

## 执行方式

自动化检查脚本需实现以下逻辑：

```python
# 核心接口
results = run_all_checks(game_key)   # → [{category, check, status, value, threshold}]
all_pass = print_check_report(results)
if not all_pass:
    raise SystemExit("质量门禁未通过！请根据上方 FAIL 信息修复后重新审查。")
```

## 人工确认点

自动化检查通过后，必须提示用户人工核查：

```
全部自动化检查通过。建议人工核查：
1. 立绘：五官正常？服装颜色与设计稿一致？白底纯净？
2. 背景：场景氛围正确？无畸变？
3. BGM/SFX：试听后确认氛围匹配？
4. 标题图：文字清晰？设计符合预期？

确认无误后继续构建？(Y/n)
```

## TTS 静音检测

检查各配音文件后 30% 的 RMS 值。
若平均 RMS < max_amp × 0.01 则判定为"过长静音"。
