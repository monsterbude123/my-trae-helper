# P0 工作流 · 沙盒定义

> 从用户的艺术种子到可检测的自洽世界
> 主导: World Architect | 门禁: Consistency Auditor

---

## 工作流触发
用户说："我想写一个关于...的小说" / "帮我设计世界观" / "我有一个世界的想法..."

## 工作流步骤

### Step 1: 种子收集（对话）

AI 应该依次问以下问题，每次等用户回答后再问下一个：

```
问题 1 (独特性):
  "这个世界最独特的地方是什么？
   有什么是在别人的作品里绝对不可能发生的？
   用一句话概括你的核心创意。"

问题 2 (主角):
  "主角是什么样的人？
   他/她绝对不能做什么？（不是弱点，是'做不到'——比如'不能用魔法''看不懂文字'）
   他/她有什么与众不同的视角？（别人看不到的，只有他/她能看到的）"

问题 3 (画面):
  "有没有一个让你兴奋到睡不着的画面或场景？
   哪怕只有一个片段——那一瞬间的光线、气味、声音。"

问题 4 (感情):
  "这个故事最让你动情的是什么？
   是愤怒？悲伤？希望？孤独？复仇？
   这不是选择题——是你写这个故事的燃料。"

问题 5 (规则):
  "这个世界有没有什么'铁律'——绝对不能被打破的规则？
   比如'死者不能复活''时间不能倒流''代价永远大于收益'？"
```

### Step 2: 种子分类

将用户的回答分类为：

```yaml
seeds:
  world_uniqueness: [用户对问题1的回答]
  protagonist_core: [用户对问题2的回答]
  key_visuals: [用户对问题3的回答]
  emotional_fuel: [用户对问题4的回答]
  iron_laws: [用户对问题5的回答]
```

### Step 3: 宪法推导

从 seeds.iron_laws 和 seeds.world_uniqueness 推导公理：

```
推导规则:
1. 每条 iron_law → 一条公理
2. 从 world_uniqueness 中提取隐式规则 → 公理
3. 如果公理 < 3 条 → 问用户补充
4. 如果公理 > 7 条 → 合并冗余公理

每条公理格式:
  name: "短名(4-8字)"
  statement: "完整陈述(一句话)"
  allows: "允许的操作"
  forbids: "禁止的操作 (具体到可检测)"
  severity: 1-10
```

### Step 4: 物理层

```
如果世界有超自然力量:
  定义它的物理学类比
  定义至少 3 个物理常量 (名称/符号/值/单位)
  定义力量的: 来源→转换→衰退 完整闭环

如果世界同现实物理:
  声明"物理层同现实世界"
  标注任何例外 (如果有)
```

### Step 5: 势力版图

```
定义 2-5 个关键势力:
  名称 | 目标 | 资源 | 内部矛盾(0-1) | 对主角态度 | "为什么不是单纯的坏人"
```

### Step 6: 角色种子

```
主角:
  身份 | 核心限制 | 可用手段 | 禁用手段 | 独特视角

配角 (2-3):
  名称 | 与主角关系 | 当前状态 | 提供给主角的独特资源

反派 (1-2):
  名称 | 动机(在他的世界观里完全合理) | 结构性优势 | 结构性盲区
```

### Step 7: 门禁自检

```
在提交给 Consistency Auditor 之前:
□ 每条公理的 forbids 可用 grep/正则检测？(读 references/constitution_guide.md)
□ 角色都有 allowed_methods 和 forbidden_methods？
□ 物理常量是否量化(数字+单位)？
□ 超自然力量的来源→转换→衰退是否完整闭环？
□ 所有种子都被保留了吗？(检查 seeds 中的每一项是否在输出中有对应)
```

### Step 8: 门禁提交

将 P0 产物提交给 Consistency Auditor 进行宪法可检测性审查。

## P0 产物清单

```
□ 宪法文档
□ 物理常量表 (或"同现实"声明)
□ 势力版图
□ 角色种子档案
□ 概念注册表初始化 (≥10 概念)
□ 门禁自检报告
```

## P0 常见陷阱

| 陷阱 | 症状 | 修正 |
|------|------|------|
| 公理太模糊 | forbids 写成"魔法是神秘的" | 具体到"禁止无代价施法" |
| 角色无限制 | 主角没有 forbidden_methods | 没有限制的主角 → 没有张力 |
| 反派纯邪恶 | 动机写成"他就是坏" | 找到"在他的世界观里完全合理"的动机 |
| 种子丢失 | 用户的某个核心灵感没有体现在产物中 | 回到 seeds 逐条核对 |
