## Agent 上下文恢复协议（V9 NEW — 重入必读）

```
每次新会话/新窗口加载时:

1. intake 步骤 0 读取 Cockpit → 发现 🐛段有未解决 bug
2. intake 步骤 0.05 → 提示用户: "有 N 个未解决 bug"
3. 用户确认后 → 读取本文件完整内容
4. 输出:
   "Bug B{N} 当前状态: {status}
    上次交流: [时间] {用户最后一句}
    下一步建议: {继续调查/等待用户反馈/准备修复}"
5. 由用户选择: 继续调查 | 更新反馈 | 标记已修复 | 忽略
```

**用户反馈列使用规则**：
- 用户在对话中针对某个 Bug 说的任何新信息 → Agent 写入"用户反馈"列
- 用户说"不是这样的，应该是..." → Agent 记录为反馈 → 同步更新交流历史
- 用户说"已确认修复""测试通过了" → Agent 标记状态 ✅已修复 → 写入修复时间
