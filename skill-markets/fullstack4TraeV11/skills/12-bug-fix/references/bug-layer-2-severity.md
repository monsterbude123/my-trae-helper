# Bug 处理分层决策框架 — Layer 2 严重性分层

> **V11.8.3 核心新增层**：这是 V11.8.2 缺失的关键层。原设计把所有 bug 都走一遍修复，但实际应该**按严重性分波处理**。

---

## 核心思维模型

```
严重性分层决策树（Triage）
├── L1 阻断：必须立即停
│   └── 策略：单独修，修完才能继续
│
├── L2 不可用：影响核心功能
│   └── 策略：按波次修，优先级高于 L3
│
├── L3 视觉瑕疵：不影响功能
│   └── 策略：批量修或延后
│
└── 波次分配：冒烟波 → 功能波 → 细节波
    └── 每波修复后回归验证
```

---

## §L2.1 严重性定义（通用）

| 等级 | 定义 | 用户影响 | 处理优先级 |
|------|------|---------|-----------|
| **L1 阻断** | 核心流程完全无法使用 | 用户无法完成主要任务 | 立即单独修 |
| **L2 不可用** | 功能缺陷但不阻断流程 | 用户可以绕过或部分使用 | 按波次优先修 |
| **L3 视觉瑕疵** | UI 问题，功能正常 | 用户体验下降但不影响任务 | 批量修或延后 |
| **L4 体验问题** | 微小瑕疵 | 用户可能不注意到 | 可不修 |

---

## §L2.2 波次分配策略

> **核心思想**：不是"发现多少修多少"，而是"按严重性分波处理"。

```
Wave 1（冒烟波）:
    目标: 确保 L1 阻断全部清除
    内容: 只修 L1
    验证: 每修一个 L1，回归测试核心流程
    停止条件: L1 清零

Wave 2（功能波）:
    目标: 清除 L2 不可用
    内容: 按模块分批修 L2（每批 ≤ 3 个）
    验证: 每批修复后回归验证
    停止条件: L2 清零 或 时间预算耗尽

Wave 3（细节波）:
    目标: 清除 L3 视觉瑕疵
    内容: 批量修 L3（可 ≤ 5 个一批）
    验证: 批量回归
    停止条件: L3 清零 或 预算耗尽
```

---

## §L2.3 波次间回归策略

| 波次后 | 回归内容 | 通过标准 |
|--------|----------|---------|
| Wave 1 后 | 核心流程冒烟 | 0 L1 |
| Wave 2 后 | 受影响模块功能 | 0 L2（已修范围） |
| Wave 3 后 | 视觉回归 | 0 新增 L1/L2 |

**铁律**：Wave 1 后如果回归发现新的 L1，**立即切回 Wave 1**，不继续 Wave 2。

---

## §L2.4 时间预算决策

```
IF 剩余预算 < 预计修复时间:
    按严重性排序，优先 L1 > L2 > L3
    超出预算的 L3 可延后到下一迭代
    
IF 发现新 L1 且预算耗尽:
    立即上报阻断（5 字段阻塞报告）
    不继续 Wave 2/3
```

---

## §L2.5 严重性判定决策表

| 现象 | L1 | L2 | L3 | 判定依据 |
|------|:--:|:--:|:--:|----------|
| 登录失败 | ✅ | | | 核心流程阻断 |
| 支付按钮无响应 | ✅ | | | 核心流程阻断 |
| 页面空白 | ✅ | | | 完全不可用 |
| 列表加载失败 | | ✅ | | 功能缺陷，可绕过 |
| 表单校验错误 | | ✅ | | 功能缺陷 |
| 字体降级 | | | ✅ | 视觉问题 |
| 间距不一致 | | | ✅ | 视觉问题 |
| 控制台 warning | | | ✅ | 不影响功能 |

---

## §L2.6 严重性分层产出

| 产出 | 用途 | 下一层 |
|------|------|--------|
| L1/L2/L3 分类清单 | 波次分配依据 | Layer 3 修复 |
| 波次计划 | 修复顺序 | Layer 3 执行 |
| 时间预算分配 | 停止条件 | Layer 4 收敛 |

---

## 反模式

| # | 反例 | 问题 |
|:--:|------|------|
| L2-1 | 所有 bug 一视同仁修 | 效率浪费，L1 未优先 |
| L2-2 | Wave 2 修完不回归 | 可能引入新 L1 |
| L2-3 | 预算耗尽仍继续修 L3 | ROI 低，应上报 |
| L2-4 | 发现新 L1 不切回 Wave 1 | 阻断未优先处理 |

---

## 与 V11.8.2 的差异

| 项目 | V11.8.2（批处理） | V11.8.3（波次分层） |
|------|------------------|-------------------|
| 修复顺序 | 按发现顺序串行 | 按严重性分波 |
| L1 处理 | 和 L2/L3 一起排队 | 单独立即修 |
| 回归验证 | 修完全部才回归 | 每波后回归 |
| 时间约束 | 无显式预算 | 预算驱动停止 |
