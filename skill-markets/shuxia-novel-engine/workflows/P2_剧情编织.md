# P2 工作流 · 剧情编织

> 从叙事骨架到章级规划
> 主导: Plot Orchestrator | 工具: enumerate.py, ripple.py

---

## 工作流触发
P1 门禁通过。

## 工作流步骤

### Step 1: 章级规划（逐章）

```
使用 8 维模板，逐章填写:

1. 定位: 阶段 + 叙事功能 + 情绪基调 + 字数预估
2. 时空: 时间(恒元年月) + 场景清单 + 地图参考
3. 人物: 出场角色 | 当前状态 | 本章作用 | 情绪/态度
4. 世界观依赖:
   4.1 前置依赖(需要读的世界观文档)
   4.2 涉及规则(本章涉及的宪法公理/物理规则)
   4.3 新揭示设定(本章首次揭示的世界观信息)
5. 剧情:
   5.1 核心事件(本章发生的最重要的一件事)
   5.2 主线推进(本章如何推动主线)
   5.3 伏笔操作(埋设/推进/回收 - 表格)
   5.4 信息差(主角知道什么 vs 敌人知道什么 vs 读者知道什么)
6. 场景: 关键场景的描述分镜
7. 衔接: 前章结尾情绪 → 本章结尾情绪 | 待解决问题
8. 科技树节点: 本章贡献/使用的科技树节点
```

### Step 2: 可能性枚举（每章结尾）

```
对每章的结尾状态:
  运行: enumerate.py --chapter N --count 5
  验证: 作者计划的"下一章"是否在候选列表中
  - 在列表中且排前 3 → ✅
  - 在列表中但排后 2 → ⚠️ 检查是否被"安全但无聊"的选项挤下去
  - 不在列表中 → ❌ 回溯到上游设定找原因
```

### Step 3: 赢面验证（关键冲突章）

```
识别"关键冲突章":
  主角与反派的直接/间接对抗
  主角的生死/自由/核心目标受到威胁
  主角的重大选择(影响后续 ≥10 章)

对每个关键冲突:
  计算: 赢面 = (认知差 × 信息差 × 傲慢 × 脆弱性) / 力量优势
  判定: PASS(>0.5) / BORDERLINE(0.1-0.5) / FAIL(<0.1)
  FAIL → 回溯修正(增加优势因子或降低敌人力量)
```

### Step 4: 伏笔覆盖检查

```
逐章检查:
□ 本章有伏笔操作吗？
  - 埋设(首次引入) → 标注 ★新伏笔
  - 推进(新线索) → 标注 →推进
  - 回收(揭示真相) → 标注 ✓回收

□ 伏笔覆盖度: ≥70% 的章节有伏笔活动
□ "到期"伏笔: 是否有计划在本章回收但未回收的伏笔？
```
