# 设计系统

> 设计系统用于存放主题、图形、组件和设计规范，规范产物设计风格。TRAE Work 提供 16 套内置设计系统，同时支持自定义。

## 四大组成

| 名词 | 描述 |
|------|------|
| **主题** | 视觉风格基础配置：主题色、字体、字号、间距、圆角、阴影等设计变量 |
| **图形** | 图标、SVG、插画等视觉资源 |
| **组件** | 基于主题和图形组合形成的可复用界面（按钮、输入框、卡片、弹窗等） |
| **设计规范** | Markdown 文档，说明主题/图形/组件使用规则、设计原则与边界 |

## 添加自定义设计系统

入口：左栏 → **设计系统** → 右上角 **添加设计系统**。

| 方式 | 说明 |
|------|------|
| **解析 Figma** | 导出 `.fig` → AI 解析颜色/字体/组件 → 生成设计系统 |
| **导入设计系统** | 上传已有 TraeDesign `.zip` 直接复用 |
| **风格探索** | 自然语言描述偏好 → AI 追问确认细节 → 生成新设计系统 |

## 编辑自定义设计系统

入口：**设计系统 → 自定义 → 目标卡片 → 管理**。四页签：

| 页签 | 编辑能力 |
|------|----------|
| **主题** | 颜色 / 排版 / 圆角 / 尺寸 / 间距设计变量；支持"添加到对话让 AI 改"或"打开编辑器手改" |
| **组件** | 查看 + 通过对话让 AI 修改 |
| **图形** | 添加到对话编辑 / 重命名 / 删除 / 上传 `.svg`（可选去色） |
| **设计规范** | 添加到对话编辑 / 删除 / 添加 README（纯 `.md`）和 Skill（`.skill` / `.zip` / `.md`，含 `SKILL.md` 与 YAML frontmatter） |

## 管理自定义设计系统

**设计系统 → 自定义 → 卡片右下角 `···`**：重命名 / 创建副本 / 导出 `.zip` / 删除。

## 排版字段说明

主题编辑器中 `font-family` 可选四类：
- `font-family-sf-pro-text`（正文文本）
- `font-family-sf-pro`（标题/展示）
- `font-family-inter`（通用界面）
- `font-family-jetbrains-mono`（等宽/代码）

均支持选内置或上传其他字体。
