# 八、UI 定制

## 8.1 文本框样式

模板文件：`game/template/Stage/Textbox/textbox.scss`

可替换样式名（用于 `applyStyle`）：`TextBox_main`、`TextBox_Background`、`TextBox_showName`、`TextBox_ShowName_Background`、`text`、`outer`、`inner`、`outerName`、`innerName`、`TextBox_textElement_start`、`TextBox_textElement_Settled`、`miniAvatarContainer`、`miniAvatarImg` 等。

**注意**：SCSS 文件需使用 CSS 语法（WebGAL 不支持 Sass 的 `$变量`、`@mixin`、`@include`）；子选择器需嵌套在类内（`.Title_button { &:hover { ... } }`）。

## 8.2 选择支样式

模板文件：`game/template/Stage/Choose/choose.scss`

可替换样式名：`Choose_Main`、`Choose_item_outer`、`Choose_item`、`Choose_item_disabled`。

## 8.3 标题页样式

模板文件：`game/template/UI/Title/title.scss`

可替换样式名：`Title_main`、`Title_buttonList`、`Title_button`、`Title_button_disabled`、`Title_button_text`、`Title_button_text_outer`、`Title_button_text_inner`、`Title_backup_background`。

## 8.4 applyStyle 动态切换

```webgal
applyStyle:Choose_item->Choose_item_Red;
applyStyle:TextBox_ShowName_Background->TextBox_ShowName_Background_Red,TextBox_main->TextBox_main_Black;
```

无论替换多少次，始终保持原样式名在 `->` 左侧。
