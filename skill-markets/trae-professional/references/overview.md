# TRAE IDE 概述

## 产品定位

TRAE IDE 是一款深度融合 AI 能力的开发工具，提供从代码编写、项目理解、调试运行到变更管理的完整开发体验。

### 使用场景

| 场景 | 说明 |
|------|------|
| 从 0 到 1 创建项目 | 自然语言描述需求 → 智能体协助需求拆解 → 代码生成 → 运行验证 → 结果预览 |
| 维护已有代码库 | 基于项目上下文定位文件、理解依赖关系、修改、重构、排查问题 |
| 提升编码效率 | 使用 CUE 获取代码补全、多行修改、修改点预测、智能导入、智能重命名 |

## 双重开发模式

| 模式 | 特点 | 适用场景 |
|------|------|----------|
| **IDE 模式** | 保留编辑器、终端、调试、插件、Git 等传统工作流 | 精细控制代码改动和执行过程 |
| **SOLO 模式** | AI 主导，自然语言/语音输入，自动规划 → 代码生成 → 测试 → 预览 | 快速构建、复杂任务自动化 |

通过界面左上角模式切换按钮切换。

## AI 编程能力

### 模型
内置多种先进模型，支持通过 API Key 接入自定义模型，可根据任务类型、性能、成本和偏好选择。

### 智能体 (Agent)
- 自然语言定义任务，AI 理解需求、检索代码库、制定多步骤计划、调用工具完成开发
- 支持创建自定义智能体，配置提示词、MCP Server 和工具集

### CUE
- 代码补全、链式补全
- 多行修改、修改点预测与跳转
- Python/TypeScript/Golang 项目中辅助导入依赖和重命名引用

### 上下文
可提供：文件、文件夹、代码片段、终端输出、代码仓库、文档集、网页。

## 开发工具链

| 能力 | 说明 |
|------|------|
| 代码编辑与调试 | 主流编程语言和框架，集成编辑、运行、调试 |
| 源代码管理 | 完整 Git 工作流，AI 生成规范的 Commit Message |
| 智能代码审查 | 对未提交变更、单次提交、分支差异总结和审查 |
| 插件扩展 | 丰富插件生态 |
| 远程开发 | Remote SSH / WSL 连接远程主机 |

## 安全能力

| 能力 | 说明 |
|------|------|
| 隐私模式 | 开启后对话内容、代码及 AI 输出不用于训练；代码保存在本地 |
| 沙箱运行 | 智能体命令在受限环境执行，文件访问控制 + 高风险命令拦截 |
