# 模式自动选择

Agent 在新会话启动时，读用户的第一句话，按以下规则自动判定模式。

## 意图关键词 → 模式映射

| 用户意图关键词 | 自动判定模式 | Phase 范围 |
|--------------|:---:|------|
| game jam / 48小时 / 周末做个小游戏 / 快速原型 | 🏃 game-jam | Phase 0→0.5→极简1→极简2→极简3→5→6 |
| 加个功能 / 改一段对话 / 换个立绘 / 修 bug | ✂️ lean | Phase 0→目标Phase→阶段门禁(仅自动化) |
| 从零开始做 / 完整项目 / 商业发布 / 团队合作 | 🏛️ full | Phase 0→7 全部 |

## 自动判定的机械规则

```
用户第一句话包含以下任一:
  "game jam" | "48小时" | "周末做" | "快速原型" | "jam"
  → 🏃 game-jam 模式，激活 §Game Jam 精简流程

用户第一句话包含以下任一:
  "从零开始" | "新项目" | "开始做" | "完整" | "正式" | "完整游戏" | "商业"
  且不含 game jam 关键词
  → 🏛️ full 模式

其他（"改一下" / "加个" / "换个" / "修" / "更新"）:
  → 检查 .project-cockpit.md 是否存在
    ├── 存在 → ✂️ lean 模式（已有项目，增量改动）
    └── 不存在 → 询问用户选择模式（3 选 1，10 秒超时默认 lean）
```

## 各模式裁剪规则

### 🏃 Game Jam
- Phase 1: story-design 只跑 lean interview（Want/Fear + 场景列表最简版，1 轮）
- Phase 2: 素材只做立绘 1 张/角色（无差分）+ BGM 1 首，跳过 rembg
- Phase 3: 脚本只写主线，无分支
- Phase 4: **跳过**（唯一可跳过的 Phase）
- Phase 5-6: 正常构建+部署
- Phase 7: 标记 N/A

### ✂️ Lean
- 保留所有 Phase 结构
- 但 Phase 4 只用 `solo` 模式（自动化检查，跳过人工确认）
- Phase 1 只改涉及的部分，不重新跑全套设计
- 增量变更优先

### 🏛️ Full
- 完整 8 Phase，不可跳过
- 所有门禁全开
- GDD + 角色宪法 + 完整分支树
