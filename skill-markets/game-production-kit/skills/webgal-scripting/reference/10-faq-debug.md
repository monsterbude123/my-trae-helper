# 十、常见错误与 FAQ + 调试技巧

## 10.1 脚本语法

| 问题 | 原因 | 解决 |
|:---|:---|:---|
| 对话不显示 | `:` 或 `;` 用了中文全角 | 使用英文半角 `:` 和 `;` |
| `choose` 后执行了后续分支 | 分支末尾没加 `jumpLabel` 跳出 | 每个 label 分支结尾用 `jumpLabel:公共标签;` |
| 标签跳转失败 | 同一场景定义了多个同名 label | 每个场景每个标签名只定义一次 |
| 变量判断无效 | 用了 `=` 而不是 `==` | 条件判断用 `==` |
| `changeScene` 后仍然执行 | 不了解 `changeScene` 是异步的 | 正常，引擎会在切换后停止当前场景 |
| `if` 真分支直接 `callScene` 无效果 | `callScene` 与 `if` 搭配的特殊行为 | 参见[条件判断](04-conditions.md) |
| JSON 字符串中 `"` 未转义 | 脚本解析器按 `"` 划分 JSON | 使用 `\"` 转义内部引号 |

## 10.2 资源加载

| 问题 | 原因 | 解决 |
|:---|:---|:---|
| 文件没被识别 | 文件名含特殊符号、空格 | 使用纯英文命名，避免特殊符号 |
| 音频不播放（Safari） | Safari 不支持 `.ogg` | 转换为 `.mp3` |
| 导出的网页无法打开 | 浏览器安全策略限制 | 使用 HTTP 服务器部署（Nginx/VSCode Live Server 等） |

## 10.3 舞台/场景

| 问题 | 原因 | 解决 |
|:---|:---|:---|
| 切换场景后背景/立绘还在 | `changeScene`/`callScene` 不清除舞台 | 切换前手动 `changeBg:none`、`changeFigure:none`、`:;` |

## 10.4 资源命名

- 文件名使用纯英文，避免空格与特殊符号
- 文件后缀名小写
- 背景放 `background/`，立绘放 `figure/`，BGM/音效放 `bgm/`，配音放 `vocal/`，视频放 `video/`

## 10.5 已踩坑汇总（经验文档）

| 问题 | 根因 | 修复 |
|:---|:---|:---|
| 角色对话 TTS 为 0 句 | 使用 `{旁白}` 代替角色名写对话 | 所有角色对话用 `角色名:内容;`，只有系统描述用 `{旁白}` |
| 跨文件标签跳转失败 | label 定义在 A 文件却在 B 文件中 `jumpLabel` | 确认目标 label 在同一文件或已被 `callScene` 加载 |
| 条件变量不生效 | `setVar:flag=true`（布尔）但 `-when=flag==true`（比较字符串） | 确保类型一致：布尔用 `===` 或裸写 |
| 变量"有设无用" | setVar 设置了变量但从未在任何 if/-when 中读取 | 用 validate_scenes.py 检测死 flag，或手动 grep 确认 |
| 线性落入下一个分支 | label 分支末尾缺少 `jumpLabel` 跳出 | 每个 label 末尾必须显式跳转 |
| 孤立 label 浪费脚本 | 定义了 label 但没有 choose/jumpLabel 引用 | 用 validate_scenes.py 检测未引用标签 |

## 10.6 调试技巧

### 查看变量

```webgal
showVars;                       在对话框中显示所有变量当前值
```

### 注释定位

使用行内注释标记关键位置：
```webgal
setVar:coin=coin-3;  扣钱
jumpLabel:buy -when=coin>=3;  检查余额
```

### 逐行排查

- 通过 `:;` 空对话暂停并以注释标记进度
- 利用 `wait:3000;` 暂缓执行以观察演出效果
- 使用 `setTextbox:hide;` 和 `setTextbox:on;` 临时开关文本框

### 场景调试

- 使用 WebGAL Terre 可视化编辑器 **预览** 功能（推荐）
- 或者导入 WebGAL 引擎目录，通过 `yarn dev` 启动开发服务器调试
- 注意：Terre 编辑器中预览单个场景时，不携带上一场景的舞台状态，与实际运行可能不同

### 常见排查顺序

1. 检查分号、冒号是否英文半角
2. 检查 `choose`/`jumpLabel` 目标 label 是否存在
3. 检查变量是否已被正确设置（用 `showVars` 验证）
4. 检查条件表达式类型是否正确
5. 检查文件命名和路径
