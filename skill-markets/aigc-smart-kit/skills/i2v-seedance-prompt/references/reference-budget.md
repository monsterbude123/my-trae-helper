# Seedance 2.5 — 50 槽参考素材预算细则

> "50 references" 不是 1 个池子里随便填 50 张图。官方文档拆 3 个独立预算: **30 图 + 10 视频 + 10 音频**。混算 = 计划错位。

## §0 三个独立预算(总 ≤50)

| 预算 | 上限 | 用途类别 | 标签语法 |
|------|------|----------|----------|
| **图片** | 30 | 角色 / 道具 / 场景 / 风格 / 构图 / 文字渲染参考 | `@Image1` ... `@Image30` |
| **视频** | 10 | 动作 / 节奏 / 镜头行为 / 风格参照 | `@Video1` ... `@Video10` |
| **音频** | 10 | 声音 / 音乐 / 节奏 / 卡点参考 | `@Audio1` ... `@Audio10` |

## §1 图片分配(30 张)

### §1.1 推荐分配

| 类别 | 数量 | 用途 |
|------|------|------|
| **角色身份** | 3-5 | 正面 / 侧面 / 背面 / 表情特写 — 锁定身份防漂移 |
| **道具 / 产品** | 3-5 | 不同角度 / 细节 / 包装 / 文字 |
| **场景** | 5-8 | 主场景 / 过渡场景 / 远景 / 近景 / 调色 |
| **风格 / 美学** | 3-5 | 色调 / 光照 / 画面质感参考 |
| **构图 / 文字** | 2-4 | 构图示意 / 文字内容 / Logo 位置 |
| **缓冲** | 余量 | 不同主体 / 备用角度 |

### §1.2 典型角色 IP 三视图

```
@Image1   角色正面
@Image2   角色侧面
@Image3   角色背面
@Image4   角色特写(表情)
@Image5   角色服装 / 道具特写
```

### §1.3 多主体场景分配

```
@Image1   角色 A 正面
@Image2   角色 A 侧面
@Image3   角色 B 正面
@Image4   角色 B 侧面
@Image5   场景背景
@Image6   美学调色
@Image7   Logo / 品牌元素
```

> ⚠️ Seedance 推荐主体总量不超过 4 个;超过 4 个时,身份一致性会下降。

## §2 视频分配(10 段)

### §2.1 推荐分配

| 类别 | 数量 | 用途 |
|------|------|------|
| **运镜节奏** | 2-3 | 慢推 / 快切 / 拉远 — 控制镜头行为 |
| **动作节奏** | 2-3 | 连续性动作 / 表情 / 运动轨迹 |
| **场景氛围** | 2-3 | 整体氛围 / 风格参考 |
| **局部细节** | 1-2 | 表情 / 手部 / 局部动作 |

### §2.2 用法示例

```
@Video1   整段 30s 节奏参考(基准)
@Video2   Opening 镜头运镜参考
@Video3   Turn 调色转向参考
@Video4   Progression 动作节奏
@Video5   Resolution 收束方式
```

## §3 音频分配(10 段)

### §3.1 推荐分配

| 类别 | 数量 | 用途 |
|------|------|------|
| **BGM** | 2-3 | 主旋律 / 副旋律 / 收尾 |
| **环境音** | 2-3 | 不同场景的氛围音 |
| **音效 / SFX** | 1-2 | 卡点 / 关键事件 |
| **对白参考** | 1-2 | 音色 / 语速 / 情绪参考 |

### §3.2 卡点锚定

```
音频与画面时间点对齐:
  "Cut the edit to the rhythm of @Audio1 with beats landing on the flashes."

多音频分层:
  "BGM @Audio1 + ambient @Audio2 + SFX @Audio3"
```

## §4 @Clay Render(3D 块参考)

> Seedance 2.5 新增 — 传无纹理 3D blockout,模型读取空间结构 / 角色姿势 / 动作轨迹 / 相机角度。

```
@ClayRender  3D 几何块(空间结构 + 姿势 + 镜头角度)
```

适用:
- 已有 previs(预演)的项目 — 直接复用 pipeline
- 复杂空间镜头 — 3D 块比平面图更能传达深度信息

## §5 反例(MUST 避免)

### §5.1 把 50 当作 1 个池子

```
❌ 用满 50 张图片(超 30 上限)
   → 图片被截断或报错

✅ 30 图 + 10 视频 + 10 音频 = 独立预算,各自不超
```

### §5.2 上传素材但 prompt 不引用

```
❌ 上传 10 张图,prompt 里不写 @Image
   → 模型用 1 张 + 自己猜其余 = 浪费参考

✅ prompt 显式: "@Image1 @Image2 锁定身份" / "@Image5 控制场景色调"
```

### §5.3 主体过多

```
❌ 一个 30s 视频塞 6 个主角
   → 身份一致性崩溃

✅ 主体 ≤ 4,每个主体 3-5 张参考图
```

### §5.4 视频当图用 / 图当视频用

```
❌ 把视频当图片引用(只取一帧)
   → 浪费视频槽

❌ 把截图当视频上传(无时间信息)
   → 浪费视频槽,模型无法读取节奏

✅ 图 = 静态参考;视频 = 动态节奏参考;音频 = 时间结构参考
```

## §6 标签速查

| 标签 | 类型 | 引用示例 |
|------|------|----------|
| `@Image<N>` | 图片 | `identity locked by @Image1, aesthetic from @Image5` |
| `@Video<N>` | 视频 | `pacing reference from @Video2` |
| `@Audio<N>` | 音频 | `music bed @Audio1, ambient @Audio2` |
| `@Clay Render` | 3D 块 | `camera angle from @Clay Render` |
