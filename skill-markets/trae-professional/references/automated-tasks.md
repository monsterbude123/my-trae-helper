# 定时任务（自动化）

> TRAE Work 的自动化功能：根据设定时间或频率，自动执行预设任务并生成结果，无需人工干预。

## 使用场景

| 场景 | 说明 |
|------|------|
| **代码仓库定期维护** | 代码安全扫描、Bug 排查与修复、补齐测试用例、生成变更日报 |
| **信息检索与汇总** | 行业资讯、竞品动态、市场数据、用户反馈归集、应用商店评论摘要、社区跟踪、政策法规更新提醒 |
| **周期性内容产出与汇报** | 品牌舆情周报、行业速递、关键指标监控、运营日报 |

## 触发方式

| 方式 | 说明 |
|------|------|
| **固定时间** | 按每天/每周/每月的固定时间点 |
| **间隔触发** | 按固定时间间隔（分钟/小时/天）循环 |
| **自定义** | 自然语言描述（如"工作日早上 9 点"），**仅"在对话中创建"方式支持** |

## 创建方式

入口：左栏顶部 → **自动化**。

### 方式 A：在对话中创建
1. 右上角 → **在对话中创建** → 系统预填模板
2. 输入任务内容和执行时间
3. 选择运行环境 + 输出存储位置
4. 发送 → AI 解读需求并确认细节 → 创建定时任务
> 运行模式（Work / Code）默认当前模式，**不支持修改**

### 方式 B：手动新建
右上角 → **手动新建** → 配置：任务名称 / 触发时间 / 任务内容 / 运行模式 / 运行环境 / 输出存储位置

### 方式 C：从模板创建
**任务模板** 页签 → 选择模板 → 按需修改 → **创建**

## 管理定时任务

**已配置** 页签下管理所有任务：开启 / 关闭 / 修改 / 删除。
> 创建后**无法再修改**运行模式、运行环境和输出内容的存储位置。

## 查看执行记录

**执行历史** 页签查看执行记录。
> **前置条件**：TRAE Work 当前运行模式（左上角）需与任务运行模式一致。
点击记录跳转到任务对话流页面。
