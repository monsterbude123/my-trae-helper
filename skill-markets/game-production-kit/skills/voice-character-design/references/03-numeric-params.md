# Step 3 — 数值参数怎么调

> **核心原则**：数值参数**有物理含义**——不是为了"听感好"而调，而是**为了解决具体问题**而调。

## 5 个核心数值参数

| 参数 | 物理含义 | 默认 | 调整方向 |
|------|---------|------|---------|
| `temperature` | 采样随机性 | 0.7-0.8 | 越低越稳定/越死板，越高越多样/越易翻车 |
| `top_p` | 概率截断 | 0.85-0.9 | 越低越保守，越高越多变 |
| `top_k` | 候选数 | 40-50 | 越低越稳定 |
| `repetition_penalty` | 抑制重复 | 1.05 | 越低越可能复读，越高越可能语义断裂 |
| `max_new_tokens` | 最大生成数 | 2048 | **决定静音问题**——见 §静音 |

## 4 个常见问题的调参

### 问题 1：语音有大量静音 / 间隔

**原因 1：max_new_tokens 太大，模型先想很久再说话**
```
解决：max_new_tokens 调到 280-350（短对话）
```

**原因 2：repetition_penalty=1.0 → 模型陷入重复**
```
解决：repetition_penalty=1.05-1.10
```

**原因 3：文本分句没标点，模型不知道何时停顿**
```
解决：源文本用正常中文标点（。！？），不要连写
```

**原因 4：top_p > 0.9 + temperature > 0.85 → 模型"走神"**
```
解决：top_p=0.85, temperature=0.7-0.75
```

**原因 5：instruct 里写"pause"或"silence"**
```
解决：删掉这些词，模型可能过度执行
```

### 问题 2：同一角色多次生成，听感不一样

**原因：seed 没固定 / temperature 太高**

```
解决：
1. 固定 seed（单角色同一 seed）
2. temperature 降到 0.65-0.7
3. top_p 降到 0.85
```

参考 NVIDIA 社区研究：
> 音频剧里，temperature=0.65-0.75，top_p=0.85 是音色稳定的甜蜜点。
> 温度再高，timbre 漂移严重；温度太低，听感呆板。

### 问题 3：复读 / 重复字

```
repetition_penalty 调到 1.10-1.15
```

注意：太高的 repetition_penalty（> 1.3）会让语义断裂。

### 问题 4：单条太长生成失败

```
长文本分句：
  "今天..." / "他..." / "但是..."
  → 多次调用，单次 < 50 字
```

## 按角色类型推荐参数

| 角色类型 | temperature | top_p | repetition_penalty | max_new_tokens |
|---------|-------------|-------|-------------------|----------------|
| 老者/旁白 | 0.7 | 0.85 | 1.05 | 320 |
| 主角内敛独白 | 0.75 | 0.85 | 1.05 | 280 |
| 少女/恋爱 | 0.7 | 0.85 | 1.05 | 280 |
| 反派/紧张 | 0.8 | 0.9 | 1.10 | 320 |
| 新闻/解说 | 0.7 | 0.85 | 1.05 | 320 |
| 小孩/萌系 | 0.75 | 0.9 | 1.05 | 240 |

> 提示：这些只是**起点**。每条生成后听一遍，再单独调出问题的。

## 长对话的 max_new_tokens 计算

> 粗略公式：**音频秒数 × 12.5 + 余量**

- 12.5 Hz = Qwen3-TTS codec 频率
- 中文正常语速 4 字/秒
- 一句 20 字 → 5 秒 → codec tokens ≈ 63 → 配 max_new_tokens 100-120

**安全值**：
- 单句 < 20 字：`max_new_tokens = 200`
- 单句 20-40 字：`max_new_tokens = 280`
- 单句 40-80 字：`max_new_tokens = 380`
- 单句 > 80 字：**拆句**

## seed 的正确用法

> ❌ 每条用不同 seed → 同一角色音色漂移
> ❌ 全部用同一 seed → 失去多样性
> ✅ **每角色锁定一个 seed，跨场景复用**

```python
# 角色种子字典
CHAR_SEED = {
    "qiu_suwan": 10042,
    "lin_zhiyi": 10043,
    "cafe_boss": 10044,
    "narrator": 10045,
}
```

## 调试流程（生成一条新语音出问题）

```
1. 听 → 静音多？→ max_new_tokens 调小 / repetition_penalty 调高
2. 听 → 复读？→ repetition_penalty 调高
3. 听 → 声音奇怪？→ 调低 temperature / top_p
4. 听 → 音色飘？→ 固定 seed
5. 听 → 太机械？→ 调高 temperature 0.05
```
