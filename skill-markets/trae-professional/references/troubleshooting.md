# 问题排查

> 收录 TRAE Work 使用过程中的常见问题与解决方案。

## 工作环境启动失败

错误提示："工作环境启动失败，请重试"。

### 通用解决方案

#### macOS
1. `Cmd + Q` 完全退出 TRAE Work
2. 打开 macOS **活动监视器** → CPU 页签 → 搜索 "SOLO"
3. 结束 "TRAE SOLO CN" 进程（如存在）
4. 检查磁盘空间 ≥ 2G、可用内存 ≥ 1G
5. 重新打开 TRAE Work

#### Windows
- 检查 Windows 系统版本：操作系统内部版本（OS Build）需 ≥ 19044（Windows 10 21H2 或更高）

### 错误码速查

| 错误码 | 平台 | 问题 | 解决方案 |
|--------|------|------|----------|
| **992501** | macOS | 项目目录不存在 | 确保项目目录存在 |
| **992503** | macOS | 无项目目录访问权限 | 检查用户权限；前往系统"隐私与安全性"检查是否已授权 |
| **992602.xxxx** | macOS / Windows | 工作环境启动失败 | 参考"通用解决方案"重启 |
| **992607** | macOS | 加载宿主机文件错误 | 通用方案无效时检查工作区目录是否被删除 |
| **992608** | macOS | 工作环境配置错误 | 1. 帮助 → 在文件夹中打开日志<br>2. 进入 `ModularData/ai-agent/vm/`<br>3. 删除 `vms` 文件夹<br>4. 通用方案重启 |
| **992614** | macOS | 可用内存不足 | 通用方案无效时释放内存（关闭应用、重启电脑） |
