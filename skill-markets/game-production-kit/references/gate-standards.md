# 质量门禁标准与 Verdict 系统

> 参照 Claude-Code-Game-Studios Director Gates verdict 系统（APPROVE/CONCERNS/REJECT）。

## Verdict 三态

| Verdict | 含义 | 后续动作 |
|---------|------|---------|
| **APPROVE** | 检查通过，无问题 | 继续下一检查项 |
| **CONCERNS** | 有问题但不阻塞（偏差可接受 or 非致命） | 展示问题 → 用户决定"修复"或"接受" |
| **REJECT** | 阻断性缺陷，不可接受 | 立即阻断流水线 → 回退 Phase 2 修复 |

## 整体判定规则

> 参照 CC Studio 并行 Gate 协议：按最严格 verdict 决定整体状态。

```
任一 REJECT → 整体 REJECT → 阻断
任一 CONCERNS + 零 REJECT → 整体 CONCERNS → 询问用户
全部 APPROVE → 整体 APPROVE → 通过
```

## 自动化检查项（engine-agnostic）

每个检查项的 verdict 判定标准：

| 类别 | 检查项 | REJECT 条件 | CONCERNS 条件 | APPROVE 条件 |
|------|--------|------------|--------------|-------------|
| 立绘 | RGBA 模式 | 不是 RGBA | — | RGBA |
| 立绘 | 尺寸 | 偏差 > 10% | 偏差 ≤ 10% | 精确匹配 |
| 立绘 | 文件大小 | < 最小值 or > 最大值 | 接近边界 (±10%) | 范围内 |
| 立绘 | HSV 饱和度 | < 拒绝阈值 | 接近阈值 | > 阈值 |
| 立绘 | 主体占比 | < 拒绝阈值 | 接近阈值 | > 阈值 |
| 背景 | 尺寸 | 偏差 > 10% | 偏差 ≤ 10% | 精确匹配 |
| 背景 | 文件大小 | < 最小值 | 接近最小值 | > 最小值 |
| 标题图 | 尺寸 | 偏差 > 10% | 偏差 ≤ 10% | 精确匹配 |
| 标题图 | 文件大小 | < 最小值 | 接近最小值 | > 最小值 |
| BGM | 文件大小 | < 最小值 × 0.5 | < 最小值 | ≥ 最小值 |
| BGM | 互异性 | 100% 相同 | 80% 相似 | 互异 |
| TTS | 尾部静音 | 尾部 30% → 零振幅 | 尾部 10-20% → 低振幅 | 正常 |
| **全部素材** | **版本一致性** | source_version < 当前设计版本 **且** 变更影响该素材类型 | source_version < 当前设计版本 **但** 变更不影响该素材类型 | source_version == 当前设计版本 |

## 版本一致性检查（新增）

> 针对 97% 变更率场景。素材跟设计版本脱节是最常见的质量问题。

**检查逻辑**：

```
1. 读取 story-design.md 当前版本号
2. 遍历 asset-manifest.md 中每个素材的 source_version
3. 从 .project-state-card.md「设计变更日志」中读取每次变更的「影响范围」
4. 对比判断:
   ├── source_version == 当前版本 → APPROVE
   ├── source_version < 当前版本 AND 影响范围匹配该素材 → CONCERNS（具体: "设计 v{N} 变更了 {内容}，可能影响本素材"）
   └── source_version < 当前版本 BUT 影响范围不匹配 → APPROVE（变更与素材无关）
```

**示例**：

```
素材: character_elise_01.png (source_version: v2)
当前设计版本: v3
变更日志 v3: "Elise 发色 红→深棕 | 影响: 立绘: elise_*.png"
→ 影响范围 `立绘: elise_*.png` 匹配该素材
→ 判定: CONCERNS — "设计 v3 变更了 Elise 发色，本素材可能仍为旧红色"
→ 展示给用户，逐项决定:
    A) 重新生成（推荐: 发色已改变）
    B) 当前版本仍可用（发色差异可接受）
    C) 设计回退到 v2（撤销发色变更）
```

> 阈值具体数值由各引擎的素材规格决定，不写死在门禁中。素材规格定义在 game-asset-pipeline 中，门禁从 asset-manifest.md 读取。

## 人工确认项

自动化全 PASS 后，进入人工确认。对每个素材：

```
1. 立绘：五官正常？服装颜色匹配设计？白底纯净无残留？
2. 背景：场景氛围正确？无畸变/撕裂？
3. BGM/SFX：试听确认氛围匹配？
4. 标题图：文字清晰可读？设计符合预期？
```

人工确认 verdict：用户逐项 `OK` / `NG` → NG 项标记为 CONCERNS → 用户决定处理方式。

## 审查模式对 verdict 的影响

| 模式 | REJECT 行为 | CONCERNS 行为 |
|------|------------|--------------|
| `full` | 阻断 + 记录 | 逐项询问 |
| `lean` | 阻断 + 记录 | 聚合询问（一次） |
| `solo` | 阻断（仅自动化 REJECT） | 忽略（仅记录） |
