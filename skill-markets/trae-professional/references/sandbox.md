# 沙箱（S）

> 为智能体生成的命令提供受限的执行环境，确保智能体在安全隔离环境中运行命令，防止未经授权的文件访问。

## TRAE Work 桌面版 — 沙箱策略概览

| OS | 模式 | 沙箱形态 | 描述 |
|----|------|---------|------|
| macOS | Code / Work / Design | 本地：本机受限执行；云端：独立沙箱容器 | 本地：项目目录可写，受保护目录和未显式声明为可写的目录只读<br>云端：仅可访问当前云端会话内的工作目录、临时目录和缓存目录 |
| Windows | Code | 同上 | 同上 |
| Windows | Work / Design | 隔离的虚拟化运行环境 | 仅能读写当前项目目录 |

> 自 0.1.20 起，macOS 上的 Work 模式采用与 Code 模式一致的沙箱策略。Windows 上 Work / Design 模式仍使用独立虚拟化运行环境。

## macOS Work/Code/Design + Windows Code 模式

### 云端任务（自动运行模式）

| 权限 | 目录 |
|------|------|
| **读写** | 当前会话的工作目录；沙箱容器内的临时与缓存目录 |
| **不可访问** | 宿主机文件系统；其他会话的数据目录 |

### 本地任务

| 权限 | 目录 |
|------|------|
| **只读** | `.vscode`；根目录 `/`（默认策略：所有未显式声明为可写的目录均为只读） |
| **读写** | 项目目录（除 `.trae`、`.vscode`、`.git` 外）；临时目录（macOS `/tmp` `/var/folders` `TMPDIR`，Windows `%LOCALAPPDATA%\\Temp`）；缓存目录（macOS `~/Library/Caches` `~/.cache` `XDG_CACHE_HOME`）；通用工具依赖目录（pip/uv/uvx/npm/pnpm/cmake）；Go/Java/Python/Node.js/Rust/C++ 工具链目录 |

> 当前安全策略不涉及网络访问。读写权限继承当前用户权限；读写与只读冲突时**以只读为准**。

## Windows Work / Design 模式

- **完全隔离**：AI 生成的所有代码和命令都在沙箱内执行，与主机系统完全分离
- **开箱即用**：沙箱镜像预装完整 Skills 工具链
- **安全共享**：项目文件通过受控方式挂载到沙箱

> 沙箱**默认启用，无法关闭**。项目内文件写入会同步到本地项目目录；项目目录之外的读写写入沙箱隔离区，不影响系统环境。

## TRAE Work 网页版

所有云端任务（Work / Code / Design）均运行于独立的安全沙箱容器，每个云端会话隔离磁盘、缓存等资源。

智能体文件访问权限默认遵循"自动运行"模式策略，仅可访问当前会话的工作目录、临时目录、缓存目录，**不可访问宿主机或其他会话**。

## 启用沙箱（桌面版）

1. 头像 → **设置** → **对话流**
2. **自动运行** 部分 → **命令运行方式** = **沙箱运行（支持白名单）**
3. (可选) **白名单列表** → 按需将命令前缀加入白名单（白名单内命令跳过沙箱直接执行）

## 高风险命令的运行策略

### 普通命令
- **白名单内**：沙箱外运行
- **不在白名单内**：沙箱内运行；失败时询问是否在沙箱外重试

### 高风险命令（如 `rm -rf`）
拦截并弹窗提示选项：
- **跳过**：不运行
- **添加 {runningCommandList} 到白名单**：将前缀加入白名单，后续沙箱外运行
- **运行**：本次沙箱内运行
