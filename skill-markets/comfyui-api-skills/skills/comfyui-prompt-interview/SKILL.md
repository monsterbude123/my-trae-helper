# ComfyUI 提示词访谈技能

在动手生成前，通过结构化对话把模糊想法变成清晰的创意简报。

## 何时使用

- 用户描述模糊："我想做一个……的东西"
- 概念尚未成形
- 用户说"我有想法" / "我想做点东西"
- 任何在调用 prompt-engineer / workflow-builder 之前需要厘清的请求

## 访谈流程

按以下顺序引导对话——一次只问一组相关问题。

### 第一轮：主题

**核心问题**：要生成什么？

可参考提问：
- 主题类别：人物、风景、物体、场景、抽象？
- 人物的话：年龄段、性别、风格取向？
- 物品的话：什么类型？
- 场景的话：发生在哪里？

### 第二轮：情绪与氛围

**核心问题**：希望传达什么情绪？

可参考：
- 整体调性：紧张、平静、欢快、忧郁、史诗、亲密？
- 能量水平：动感还是静谧？
- 光线方向：暖阳、阴冷、霓虹、自然？

### 第三轮：风格

**核心问题**：希望呈现什么风格？

可参考：
- 写实 / 风格化 / 抽象
- 摄影感 / 绘画感 / 3D 渲染感
- 参考艺术家、电影、游戏、年代

### 第四轮：场景与环境

**核心问题**：背景和环境如何？

可参考：
- 室内 / 室外 / 虚化背景 / 实景
- 时代：现代、复古、未来、奇幻
- 天气、时间、季节

### 第五轮：用途与技术要求

**核心问题**：最终用途？

可参考：
- 用途：YouTube 视频、社交媒体、印刷、参考、私人收藏
- 比例与分辨率：16:9 横屏、9:16 竖屏、1:1 方形
- 后续流程：是否要放入视频管线、是否需要角色一致性
- 时长（视频）：3 秒、10 秒、30 秒

### 第六轮：参考与约束

**核心问题**：有无参考素材或硬性约束？

可参考：
- 有无现成参考图？
- 有无要规避的内容？
- 有无版权要求？

## 产出：创意简报

访谈结束，产出如下简报：

```markdown
# 创意简报 - {日期}

## 主题
{一句话描述}

## 情绪与氛围
- 主调：{情绪}
- 能量：{动静}
- 光线：{光线描述}

## 风格
- 写实度：{写实/风格化/抽象}
- 媒介感：{摄影/绘画/3D}
- 参考：{艺术家、电影、年代}

## 场景
- 环境：{背景描述}
- 时代：{年代}
- 时间：{光线时段}

## 技术要求
- 比例：{宽高比}
- 分辨率：{像素}
- 用途：{最终用途}
- 后续流程：{视频管线、角色一致性}

## 参考
- 参考图：{路径或描述}
- 规避项：{不要的内容}

## 推荐管线
- 入口：{推荐的下游 skill}
- 候选模型：{1-2 个}
- 关键参数：{步数、CFG 等}
```

## 下一步

简报产出后自动转交：

- **prompt-engineer**：基于简报优化提示词
- **workflow-builder**：直接基于简报构建工作流

## 沟通风格

- 一次只问 1-3 个相关问题（不要一次抛十个）
- 必要时给出选项示例帮助用户决策
- 用户答非所问时礼貌地拉回主线
- 不要替用户做核心创意决定——只厘清

## 注意事项

- 不要把访谈拖得太长——五轮足够
- 用户明确表示"你来定"时主动给建议
- 简报要让 prompt-engineer/builder **无需再问**就能开工
