# 安全审查清单

## 通用安全检查

```
[ ] 所有 API 有鉴权装饰器（公开接口显式标注 @public）
[ ] 用户只能访问自己的资源（无 IDOR）
[ ] 密码强度策略生效
[ ] 敏感字段加密存储
[ ] SQL 参数化查询（无字符串拼接）
[ ] XSS 防护（输出转义 / CSP 头）
[ ] CSRF 防护（SameSite Cookie / CSRF Token）
[ ] 速率限制生效
[ ] 文件上传白名单（MIME + 后缀双校验）
[ ] 错误信息不泄露栈追踪
[ ] 依赖无高危 CVE
[ ] 仓库无硬编码密钥
```

## 代码变更审查清单

```
[ ] 变更范围已确定（diff / 文件 / 分支）
[ ] 变更意图已理解
[ ] Source → Sink 数据流已追踪
[ ] 5 维度漏洞已检查（输入/认证/加密/执行/泄露）
[ ] 置信度 ≥ 0.80
[ ] 仅报告当前 diff 引入的问题
```

## Skill 准入审查清单

```
[ ] 静态脚本扫描已执行
[ ] 高风险 = 0
[ ] 中风险 ≤ 2
[ ] Prompt 注入已手动检查
[ ] 权限申请与功能匹配
[ ] 无未知外部依赖
[ ] 平台兼容性已确认
```

## 安全验收反模式

```
❌ "用了 HTTPS 就够了" — 传输加密 ≠ 应用安全
❌ "内部接口不需要鉴权" — 内网横向移动后就是直接访问
❌ "上线后再补安全扫描" — 漏洞窗口期不可控
❌ 只扫代码不扫依赖 — 80% 漏洞在第三方库
❌ 安全扫描通过就万事大吉 — 逻辑漏洞扫描器查不出
```
