# CUE 智能编程引擎

## 基础功能

| 功能 | 说明 |
|------|------|
| 代码补全 | 理解当前文件已有代码，自动续写 |
| 多行修改 | 一次性修改多行 |
| 修改点预测 | 预测下一步编辑位置 |
| 修改点跳转 | 快速跳转到预测位置 |

## Cue-Pro（仓库级链式补全）

学习开发者编辑顺序，结合 LLM 深度推理与工具调用能力，在完整仓库上下文下识别整体编辑意图，生成多条连续、相关的编辑建议。按贴合"编辑心流"的顺序呈现。

## 智能导入 (Beta)

Python、TypeScript、Golang 项目中，自动识别并导入所需依赖模块。

## 智能重命名 (Beta)

修改变量/函数名称后，自动识别引用位置并提示一同修改。

## 开关管理

| 操作 | 路径 |
|------|------|
| Tab-Cue（全局开关） | 设置 → CUE → 开关 |
| Cue-Pro | 资源管理器 → Cue-Pro 视图 → `···` → 开关 |
| 休眠 | 右下角 CUE 图标 → 休眠 → 选择时长 |
| 自动显示摘要 | 右下角 CUE 设置面板 → 开关 |

Tab-Cue 是全局开关，关闭后智能导入和智能重命名同步关闭。

## 快捷键

| 目的 | 快捷键 |
|------|--------|
| 跳转至修改点 | `Tab` |
| 一次性完整接受修改建议 | `Tab` |
| 逐字接受修改建议 | Mac: `Cmd + →` / Win: `Ctrl + →` |
| 拒绝修改建议 | `Escape` |
| 预览采纳后代码状态 | Mac: `Option` / Win: `Alt` |
| 展开/关闭 Cue-Pro 视图 | Mac: `Ctrl + Shift + C` / Win: `Shift + Win + C` |
| 跳转至下个 Cue-Pro 变更 | Mac: `Cmd + ↓` / Win: `Alt + ↓` |
| 跳转至上个 Cue-Pro 变更 | Mac: `Cmd + ↑` / Win: `Alt + ↑` |

## 使用限制

修改点预测、修改点跳转、自动显示摘要和 Cue-Pro 功能在美国地区不可用。
