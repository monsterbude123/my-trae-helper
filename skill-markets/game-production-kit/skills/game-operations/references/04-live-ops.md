# 内容更新与赛季运营

> 来源：游戏运营行业标准
> 关联：game-operations SKILL.md §骨架流程.4

引擎无关的长期运营框架。从单次发布到持续服务。

## §1 版本迭代节奏

| 节奏 | 内容 | 测试要求 | 适用 |
|------|------|---------|------|
| **热修复** | bug 修复 | smoke + targeted | S1/S2 紧急 |
| **周更** | 小调整/平衡/活动配置 | 自动化回归 | 在线服务型 |
| **双周更** | 活动/小功能 | 自动化 + 功能 E2E | 推荐节奏 |
| **月更** | 内容更新/新关卡/角色 | 完整 QA | 大型内容 |
| **季更** | 赛季/DLC/重大版本 | 完整 QA + 存档兼容 | 叙事/竞技 |

**版本号语义**：`{主版本}.{副版本}.{修订号}.{构建号}`

## §2 赛季系统设计

```
赛季长度：4-12 周（视品类）
```

**Battle Pass 层级**：

| 轨道 | 层数 | 奖励占比 |
|------|------|---------|
| 免费 | 30-50 层 | 30% 奖励（吸引参与） |
| 付费 | 50-100 层 | 70% 奖励（独占皮肤/货币） |

**赛季衔接检查**：
- [ ] 赛季倒计时 UI
- [ ] 未领取奖励自动发放
- [ ] 排名数据归档
- [ ] 新赛季内容预载
- [ ] 旧赛季内容是否进入常驻商店

## §3 DLC 发布

| DLC 类型 | 内容 | 定价 | 兼容要求 |
|---------|------|------|---------|
| 剧情 | 新章节/故事线 | $5-20 | 需基础版 |
| 角色 | 新可玩角色 | $3-10 | 需基础版 |
| 地图 | 新关卡/区域 | $5-15 | 需基础版 |
| 皮肤 | 外观/装饰 | $1-5 | 需基础版 |
| 扩展包 | 大类内容组合 | $15-40 | 需基础版 |
| 独立 | 可独立运行 | 完整价格 | 无 |

**DLC 兼容性检查**：
- [ ] 无 DLC 玩家不报错（DLC 内容正确隐藏）
- [ ] 有 DLC 存档解绑 DLC 后能降级加载
- [ ] DLC 版本号 ≤ 基础版版本号

## §4 活动运营模板

```yaml
activity:
  name: "中秋节活动"
  type: "限时活动"          # 限时/节日/联动/社区
  duration: "2024-09-10 ~ 2024-09-20"
  mechanics:
    - type: "收集"
      desc: "收集月饼兑换奖励"
    - type: "排行榜"
      desc: "收集数排名发放限定称号"
  rewards:
    free: ["限定头像框", "金币×500"]
    paid: ["限定皮肤", "钻石×100"]
  rollback: "活动结束后奖励商店保留 7 天"
```

**活动类型速查**：

| 类型 | 特点 | 周期 |
|------|------|------|
| 限时活动 | FOMO 驱动，限时奖励 | 3-14 天 |
| 节日活动 | 文化节日主题，限定外观 | 3-7 天 |
| 联动活动 | IP 联动，跨游戏推广 | 7-30 天 |
| 社区活动 | 玩家创作/UGC 比赛 | 7-30 天 |

## §6 停服协议

```
停服通知期：≥ 30 天
```

| # | 步骤 | 时间节点 |
|---|------|---------|
| 1 | 停服公告 | T-30d |
| 2 | 停止新用户注册 | T-15d |
| 3 | 停止内购 | T-7d |
| 4 | 停服 | T |
| 5 | 离线模式可用 | T+1d（如已实现） |
| 6 | 玩家数据导出 | T+1d ~ T+30d |
| 7 | 数据最终删除 | T+90d（按法规） |

**必选项**：
- [ ] 离线模式或数据导出方案已实现
- [ ] 退款政策已声明
