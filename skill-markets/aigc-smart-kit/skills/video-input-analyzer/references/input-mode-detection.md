# input_mode 判定协议(Input Mode Detection)

> **定位**:`video-input-analyzer/SKILL.md §4` input_mode 判定的细则。
> **不重复**:SKILL.md §4 的判定算法;本文给边界 case + 优先级详解 + 询问协议。

## §0 何时加载

```
MUST 加载: 主 Agent 拿到 input_inventory 后,需判定 input_mode / 处理边界 case
MUST NOT: input_mode 已显式给出(用户传 --input-mode) — 直接用
```

## §1 判定算法(优先级降序)

```
Step 1 显式参数优先
  → 用户传 --input-mode {i2v|t2v|v2v|ref2v} → 直接使用
  → 用户传 --input-mode mm2v → 询问用户

Step 2 视频输入检测
  → input_inventory.videos 非空(>= 1)
  → 检查是否是"参考视频"(辅助参考)还是"续写前序"(主体视频)
  → 主体视频 → v2v
  → 参考视频 + 其他素材 → ref2v

Step 3 多模态检测(ref2v)
  → 图片 >= 2 → ref2v
  → 图片 + 视频 → ref2v
  → 图片 + 音频 → ref2v
  → 视频 + 音频 → ref2v

Step 4 单图检测(i2v)
  → 图片 == 1(无视频) → i2v

Step 5 纯文本检测(t2v)
  → 图片 == 0 且 视频 == 0 且 音频 == 0 → t2v(若有 user_text)
  → 完全无输入 → mm2v

Step 6 输入不明确(mm2v)
  → 文本为空 + 无视觉输入 → mm2v
  → 输入组合矛盾(例如 1 张图 + 0 文本)→ mm2v(询问用户)
```

## §2 边界 case 详解

### §2.1 v2v vs ref2v 的边界

```
判定规则:
  - 输入仅 1 个视频 + 文本 → v2v(续写)
  - 输入 1 个视频 + 0 张图 + 1 段音频 + 文本 → ref2v(视频 + 音频作为参考素材)
  - 输入 1 个视频 + 1 张图 + 文本 → ref2v(图作为风格 / 主体参考)
  - 输入 0 个视频 + 多张图 → ref2v

关键区分:
  v2v: 视频是"续写前序",是主体
  ref2v: 视频是"参考素材",与图 / 音频并列
```

### §2.2 i2v vs ref2v 的边界

```
判定规则:
  - 1 张图 + 文本 → i2v
  - 2 张图 + 文本 → ref2v
  - 1 张图 + 1 段音频 + 文本 → ref2v

边界 case: 1 张图 + 0 文本
  → 默认 i2v(用 vision 自动分析)
  → 但 vision 可能识别不出主体 → mm2v(询问用户)
```

### §2.3 t2v vs mm2v 的边界

```
判定规则:
  - 0 张图 + 0 视频 + 0 音频 + 有 user_text → t2v
  - 0 张图 + 0 视频 + 0 音频 + 0 user_text → mm2v(询问用户"你想要什么")
  - 0 张图 + 0 视频 + 0 音频 + 仅 keywords → t2v(关键词当作需求描述)
```

## §3 mm2v 询问协议

```
当 input_mode = mm2v 时,主 Agent MUST 询问用户:

"我看到你的输入是 <input_inventory 描述>,但还不太确定你想做哪种视频。
  请确认是以下哪一种:
    1. i2v(图生视频) — 你需要先上传一张图
    2. t2v(文生视频) — 纯文字描述想要什么
    3. v2v(视频续写) — 你需要先上传一段视频
    4. ref2v(参考生视频) — 多图 / 多视频 / 音频组合

  或者直接告诉我: '用 i2v 模式,这是图: <URL>' 等具体指令。
"
```

### §3.1 mm2v 询问的特殊 case

```
case 1: 用户传了 1 张图但无文本
  → 询问:"你是想要 i2v(图生视频)吗?还是想补充更多图做 ref2v?"

case 2: 用户传了关键词但无任何视觉输入
  → 询问:"你是想纯文字生成(t2v),还是有参考图 / 视频可用?"

case 3: 用户传了多个素材但类别模糊
  → 询问:"这些素材中,哪个是主体,哪些是参考?"

case 4: 用户文本明确("把这段视频续写 5s")
  → 优先信任文本,自动判定 v2v,无需询问
```

## §4 优先级冲突解决

### §4.1 显式 vs 自动判定

```
MUST: --input-mode 显式参数 > 自动判定
  例:用户传 2 张图 + 文本 + --input-mode i2v
     → 强制 i2v(忽略"2 张图应为 ref2v"的自动判定)
  例:用户传 0 张图 + --input-mode i2v
     → 警告但仍按 i2v 处理(input_inventory.images = [])
```

### §4.2 文本 vs 输入组合冲突

```
例 1: 用户文本"把这张图变成视频" + 实际有 2 张图
  → 默认 ref2v(实际输入主导)
  → 提示用户"检测到 2 张图,会自动按 ref2v 处理"

例 2: 用户文本"纯文字生成" + 实际有 1 张图
  → 询问用户(文本与输入冲突)
```
