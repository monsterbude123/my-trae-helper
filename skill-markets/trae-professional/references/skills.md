# 技能系统 (Skills)

## 核心特点

| 特点 | 说明 |
|------|------|
| 结构化 | 一个技能对应一个 SKILL.md 文件，含任务目标、约束、流程 |
| 动态按需加载 | 智能体先扫描所有技能描述，仅加载相关技能的详细内容 |

## 使用场景

- **保证一致性**：设计规范、团队标准、代码约定封装为技能
- **自动化重复工作流**：测试流程、代码规范检查、SOP
- **共享专业能力**：在社区、团队间复用

## 技能 vs 其他功能

| | 技能 | 规则 | MCP Server |
|------|------|------|------------|
| 加载 | 按需 | 全量（对话开始时注入） | 工具调用 |
| 用途 | 如何完成任务 | 行为约束和规范 | 提供可调用工具 |
| 示例 | 测试流程 + POM 规范 | 代码风格、命名规范 | Playwright 自动化 |

## 技能类型

| 类型 | 目录 | 范围 |
|------|------|------|
| 全局 | `~/.trae/skills/` | 所有项目 |
| 项目 | `.trae/skills/` | 当前项目 |

## 技能目录结构

```
skill-name/
├── SKILL.md       # (必须) 核心指令
├── examples/      # (可选) 输入/输出示例
├── templates/     # (可选) 可复用模板
└── resources/     # (可选) 参考文件、脚本、素材
```

## SKILL.md 格式

```markdown
---
name: 技能名称
description: 简要描述功能和触发条件
---

# 技能名称

## 描述
## 使用场景
## 指令
## 示例 (可选)
```

## 创建方式

1. **AI 对话创建**：直接描述需求让 AI 生成
2. **手动创建**：设置 → 技能与命令 → 创建 → 填写名称、描述、指令
3. **导入外部**：上传 SKILL.md 文件或 .zip

## 使用方式

- **手动调用**：明确告知 AI "用 xxx 技能做 xxx"
- **AI 自动调用**：AI 根据任务与技能描述匹配，自动判断

## .agents 技能目录

`.agents/skills/` 是 Agent Skills 规范约定目录。设置中启用后生效。若与 `.trae/skills/` 重名，优先调用 `.trae/skills/`。
