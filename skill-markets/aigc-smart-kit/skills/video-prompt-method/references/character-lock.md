# 主角锁定原则(Video Prompting · Character Lock)

> **定位**:`video-prompt-method/SKILL.md §3` 主角锁定的细则。
> **不重复**:SKILL.md §3 的 4 步流程;本文给反例库 + 多主体分配 + 跨时段身份一致性。

## §0 何时加载

```
MUST 加载: 主 Agent 处理多主体场景 / 跨时段身份一致性 / 配角分配 / 主体漂移修复
MUST NOT: 单主体短镜头 — 主角锁定是默认原则,无需独立加载
```

## §1 核心铁律(重申)

```
MUST:     镜头语言围绕一个主角塑造 — 不要给 6 个主体平均用力
MUST NOT: 主角淹没在场景描写 / 主角设定模糊("年轻貌美女郎") / 配角抢戏
```

## §2 多主体分配规则

### §2.1 主角 vs 配角比例

```
主角: ≥ 60% 的描述篇幅
配角: ≤ 2 个,每个只用 1-2 句话
场景: ≤ 1-2 句承载,不要大段铺陈

判断标准:
  ✅ 主角身份(姓名 / 外貌 / 服饰)每段首句复述
  ❌ 配角单独段落 / 配角主动作 / 配角表情细节
```

### §2.2 配角定位

```
配角 MUST 的特征:
  - 有名有姓 / 有身份
  - 位置 / 动作清晰(但不抢主角镜头)
  - 1-2 句话提及,无独立段

配角 MUST NOT:
  - 单独镜头(分给主角)
  - 详细表情 / 内心戏
  - 长台词(短反应即可)
```

### §2.3 场景"角色"

```
场景(街景 / 建筑 / 鹅卵石)也视作一个"配角":
  - 1-2 句话承载
  - 必须出现,但不能让场景抢戏
  - 装饰元素 / 背景杂物可省略

反例:
  ❌ "街道两旁是古老的鹅卵石,维多利亚式建筑,
     铸铁街灯,飘落的梧桐叶,咖啡馆橱窗里陈列着
     各种糕点,远处传来马车铃声……"  ← 8 句话写场景
  ✅ "街道两旁维多利亚式建筑,远处马车铃声。"
```

## §3 主体分层 5 要素(可自由替换)

```
主体 + 动作 + 场景 + 镜头视角 + 镜头运动 + 艺术风格

替换示例:
  主体: 光影婚纱女 / 场景: 金色舞台 / 风格: 1920 装饰艺术
  → 自由替换 3 要素即可生成新场景,主体身份一致性仍保留
```

### §3.1 5 要素分配权重

| 要素 | 篇幅 | 必填? |
|------|------|-------|
| **主体**(who) | 30% | ✅ |
| **动作**(doing) | 30% | ✅ |
| **场景**(where) | 10% | ✅ |
| **镜头视角 + 运动** | 20% | ⚠️ |
| **艺术风格** | 10% | ⚠️ |

> **原则**:主体 + 动作 占 60%,其他加起来 40%。

## §4 锁定约束(prompt 必带)

```
MUST 写进 prompt 的 must_not_change:
  - subject face identity(主体脸部保持)
  - subject facial expression(如"笑容持续"、"目光不移")
  - 主体核心外貌特征(年龄 / 服饰 / 配饰)

MUST NOT 跨段改变:
  - 主体服饰颜色(除非剧情要求)
  - 主体身份线索
  - 主场景锚点
```

### §4.1 锁定约束写法

```
平台特化:不同儿子 skill 用不同字段名写入 must_not_change

H3 / Hailuo:  constraints.must_not_change 字段
Seedance:    "subject face identity remains consistent throughout"
可灵:        element reference 角色锁定
通用:        在 description 中显式说 "S1 maintains the same appearance throughout"
```

## §5 跨时段身份一致性

### §5.1 身份复述规则

```
每段首句 MUST 复述:
  - 主体名 / 代号(S1 / 女生 A / old man)
  - 核心外貌特征 1-2 个(年龄 + 服饰 + 1 个可数特征)
  - STYLE 锚(SAME ART STYLE)

不允许:
  ❌ "镜头推到脸部特写"  ← 主体身份丢了
  ✅ "镜头推到 S1 脸部特写,Same Art Deco style"
```

### §5.2 跨时段同名原则

```
同一主体跨段 MUST 用同一名字:
  ❌ "女生 A" → "the girl" → "她" → "少女"  ← 漂移
  ✅ "女生 A" → "女生 A" → "女生 A" → "女生 A"

例外:代词可用("她 / 他"),但身份首次出现 MUST 给出名 / 代号
```

## §6 主角锁定示例(紫金屏风传承)

```
[0-1s]   低光破败记忆空间: 紫衣东方女侠转身,从腰后拔出折叠紫金屏风
[2-4s]   紫金屏风展开:    屏风撑开,绘有古老的紫金符文浮现;镜头聚焦屏风中央紫金印记
[5-8s]   传授仪式:        紫火药尊祖之手点主角额头,身后紫金火焰燃烧
[9-12s]  眼眸迸发紫金雷光: 特写,镜头聚焦眼眸,主角睁眼迸发紫金雷光
```

### §6.1 应用检查表

```
☑ §3.1 主角 60% 篇幅(紫衣女侠出现 4 次,配角 / 道具点缀)
☑ §2.1 配角 ≤ 2 个(此处无配角,场景只 1 句话承载)
☑ §4.1 跨段身份一致(紫衣女侠 / 主角 始终用同一代号)
☑ §5.1 每段身份复述 + STYLE 锚(虽然本例没写明 STYLE,但结构对)
☑ §2.2 时段切分按"前因后果"(转身 → 展开 → 传授 → 雷光)
```

## §7 反例速查

| ❌ 反模式 | ✅ 正确做法 |
|---------|----------|
| 把主角淹没在场景描写 | 主体段先写,场景 1-2 句 |
| 6 个主体平均用力 | 主角 60%+ 配角 ≤ 2 |
| 没有"前因后果"结构 | Opening → 展开 → 收束 |
| 配角色彩过浓抢戏 | 配角 1-2 句话提到 |
| 跨段身份漂移(女生 A → the girl → 她) | 每段用同一名 / 代号 |
| 跨段省略主体(后段不写主角是谁) | 每段首句复述身份 |
| 配角单独段 / 配角特写 | 配角融入主体段,不单独 |
| 主角模糊("年轻貌美女郎") | 具体化:20 岁 + 东方 + 蕾丝 + 蝴蝶结 + 珍珠 |
