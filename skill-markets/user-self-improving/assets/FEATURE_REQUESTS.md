# Feature Requests

> User-stated capability gaps. Each entry = one concrete missing capability
> that the user has explicitly asked for across sessions.

**Areas**: `frontend` | `backend` | `infra` | `tests` | `docs` | `config`
**Complexity**: `simple` | `medium` | `complex`

## Example

```markdown
## [FEAT-20260821-001] export_to_csv

**Logged**: 2026-08-21T16:45:00Z
**Priority**: medium
**Status**: pending
**Area**: backend

### Requested Capability
Export analysis results to CSV format

### User Context
User runs weekly reports and needs to share results with non-technical
stakeholders in Excel.

### Complexity Estimate
simple

### Suggested Implementation
Add `--output csv` flag to the analyze command.

### Metadata
- Frequency: recurring
- Related Features: analyze command

---
```
