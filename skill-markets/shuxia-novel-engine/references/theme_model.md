> 核心问题：这段叙事是否服务于"外物证道"？

> 状态: 设计规范（非代码实现）

## 零、设计公理

### 0.1 主题不是"说了什么"——是"为什么说"

一条普通的修仙情节——主角躲避追杀——在《凡人修仙传》里是在讲"谨慎"。
在《万古余烬》里必须是在讲"用经典物理的视角，看到修真者看不见的路"。

**同样的A→B→C事件链，不同的叙事纹理，服务于不同的主题。**

主题检查引擎不关心"发生了什么"——它关心"发生的理由和方式是否在服务核心主题"。

### 0.2 主题是作品的神经系统

```
主题 = 场景    不是装饰   而是结构
     = 角色    不是标签   而是驱动力
     = 冲突    不是打斗   而是认知碰撞
     = 装置    不是道具   而是世界观的身体延伸
```

每个场景至少一根神经连接到至少一个核心主题。没有连接的场景——是死肉。

### 0.3 三主题不可分割

《万古余烬》的三个核心主题不是可选项：

| # | 主题 | 一句话 | 公理锚点 |
|---|------|--------|---------|
| T1 | 外物证道 | 不能用灵气的人，用科学开辟另一条路 | 公理五·绝灵之体 + 公理七·三段式创新 |
| T2 | 文明碰撞 | 修真文明与经典物理文明的认知不对称 | 公理一·双重物理轨道 |
| T3 | 认知差即武器 | 信息/知识的不对等才是真正的力量 | 赢面公式 + 公理七 |

任何场景必须至少服务 T1。大多数场景应同时服务 T1+T2。关键场景应服务 T1+T2+T3。

## 一、主题信号体系

### 1.1 什么是"主题信号"

主题信号 = 叙事中可以**客观检测**的模式，用于判断一段文字是否在服务某个核心主题。

信号不是"感觉"——是具体的叙事元素、句子结构、视角切换、修辞选择。

### 1.2 主题信号分类

每个信号有三要素：
- **模式**：可检测的叙事形态
- **检测规则**：如何从文本中定位
- **强度**：该信号对主题的贡献力度（1-5）

---

### 1.3 T1 · 外物证道信号集

> "这条路的走法，修真界没人教过。"

| ID | 信号名 | 模式 | 检测规则 | 强度 |
|----|--------|------|---------|------|
| T1-S1 | 科技树节点使用 | 使用了科技树上的技术/装置/知识 | 提取技术术语→与科技树或concept表匹配→命中 | 5 |
| T1-S2 | 量化参数出现 | 出现具体数值（息/米/秒/千瓦/Hz） | 正则匹配量化单位+具体数字 | 4 |
| T1-S3 | 灵↔电转换 | 展示了灵场↔EM场的耦合通道 | 关键词：灵能电池/灵玉供电/灵↔电/耦合/BEC超辐射 | 5 |
| T1-S4 | "修真界没人想过" | 文本明确指出修真者的认知盲区 | 关键词：没想到/从未想过/没人试过/超出……理解 | 4 |
| T1-S5 | 经典物理原型 | 经典物理学原理驱动的解决方案 | 关键词：热力学/电磁波/量子隧穿/谐振腔/驻波/干涉/傅里叶/熵 | 5 |
| T1-S6 | 零修炼/零功法 | 主角任何行动都不依赖修炼/丹田 | 全文无"运功/催动灵力/丹田运转/经脉流转"等描述 | 3 |
| T1-S7 | 装置驱动 | 解决问题的是装置/工具，非内力 | 动作主语：按下/启动/激活/部署/调整+装置名词 | 4 |
| T1-S8 | 三段式创新链 | 展示"经典物理→L场对接→可量化装置" | 提取因果连接词→检测三段链 | 5 |
| T1-S9 | 限制即张力 | 装置限制（电量/时间/范围/冷却）产生叙事张力 | 关键词：剩余/仅剩/只能/最多/无法超过/超出范围/冷却中 | 3 |
| T1-S10 | 绝灵之体物理效应 | 展示绝灵之体物理机制（灵压真空/近身衰减） | 关键词：绝灵之体/灵压真空/散射衰减/灵场退相干/近身 | 5 |

**T1 信号密度公式**（每场景）：

```
T1_density = (Σ 各信号出现次数 × 强度) / 场景字数 × 1000
期望范围：8-25（千字信号密度）
低于 5 → 场景可能偏离"外物证道"主题
高于 30 → 可能过度说教（技术说明挤占叙事空间）
```

### 1.4 T2 · 文明碰撞信号集

> "他们不知道自己不知道什么——这是他们的弱点，也是我的窗口。"

| ID | 信号名 | 模式 | 检测规则 | 强度 |
|----|--------|------|---------|------|
| T2-S1 | 修真者傲慢被利用 | 修真者的轻视/傲慢直接导致其失误，主角利用之 | 因果链：傲慢态度+因此错失信息/错误判断+主角获益 | 5 |
| T2-S2 | 经典物理优势 | 经典物理知识直接产生修真者无法获得的优势 | 连接词：因为他知道→所以他可以（修真者做不到） | 5 |
| T2-S3 | 认知盲区被点破 | 明确揭示修真者"不知道什么"，以此作为转折 | 关键词：但他不知道/修真者不懂/不是……而是……/他们从未 | 4 |
| T2-S4 | 双重视角叙事 | 同一场景在修真视角和经典物理视角下并置 | 视角切换标记：修真视角→经典物理视角的"翻译" | 5 |
| T2-S5 | 结构性盲区 | 敌人错误不是个人失误——是文明结构性问题 | 叙事中有"因为你是修真者，所以你必然……"的逻辑 | 4 |
| T2-S6 | 凡人/修真者阶级 | 触及凡人与修真者的阶级矛盾/权力不对等 | 关键词：凡人/修真者+不平等/看不起/废人/流放/外门 | 3 |
| T2-S7 | 认知不对称具体化 | "他知道A，敌人知道B，但B的框架无法容纳A" | 检测叙事中明确存在的认知分层 | 4 |
| T2-S8 | 傲慢的代价 | 修真者因轻视凡人技术而付出具体代价 | 检测修真者损失/失败+原因追溯至"轻视凡人" | 4 |

**T2 信号与T1 信号的协同关系**：

```
T1 信号（外物证道）回答"主角怎么做到的"
T2 信号（文明碰撞）回答"为什么修真者做不到同样的事"

理想比例：T1:T2 ≈ 3:2
即每3个外物证道信号，应有至少2个文明碰撞信号
如果T1过高T2过低 → 场景变成"技术说明书"，失去文明张力
如果T2过高T1过低 → 场景变成"社会批判论文"，失去主角能动性
```

### 1.5 T3 · 认知差即武器信号集

> "力量从来不在谁拳头大——在谁知道对方不知道的事。"

| ID | 信号名 | 模式 | 检测规则 | 强度 |
|----|--------|------|---------|------|
| T3-S1 | 信息不对等利用 | 主角因为知道某事（而敌人不知道）获得优势 | 关键词：他知道了/他已经分析过/数据告诉他/小真推演出 | 5 |
| T3-S2 | 敌人因无知而失败 | 敌人的失败直接原因是不知道关键信息 | 敌人失败+回溯原因是信息缺口 | 5 |
| T3-S3 | 信息差多层设计 | 叙事中至少存在2层信息差 | 读者知道→角色不知道 / 主角知道→敌人不知道 | 5 |
| T3-S4 | 赢面公式可追溯 | 胜负可用赢面公式因子乘积反推 | 提取冲突→分解为赢面因子→验证≥3因子同时生效 | 5 |
| T3-S5 | 主动信息获取 | 主角主动收集/分析/推导信息 | 关键词：采样/记录/分析/推演/建立模型/频谱分析 | 4 |
| T3-S6 | 信息转化为行动 | 信息获取→具体战术行动 | 信息获取→行动决策链 | 4 |
| T3-S7 | 认知战 | 主角主动制造敌人的认知盲区 | 关键词：误导/制造假象/让敌人以为……/掩盖 | 5 |

**T3 信号与赢面公式的硬绑定**：

```
每出现一个 T3-S4 信号 → 必须能对应到赢面公式的至少3个因子
如果声称"认知差即武器"但胜利来自运气/巧合/突然变强 → 信号为假阳性
```

## 二、主题偏离检测

### 2.1 偏离的定义

**主题偏离** = 叙事中出现与核心主题相悖的模式/修辞/叙事选择，削弱作品的独特性。

偏离不是"写得不好"——是"写成了另一本书"。

### 2.2 偏离类型与检测规则

#### D1 · 主角光环化（Protagonist Armor）

> 主角靠"运气/巧合/刚好"解决问题，而非认知差。

| 触发词/模式 | 检测规则 | 严重度 |
|------------|---------|--------|
| "恰好/刚好/碰巧/幸亏" | 正则匹配，统计每场景出现次数 | — |
| 无赢面公式可追溯的胜利 | 场景冲突胜负无法用赢面公式 ≥3 因子解释 | 严重 |
| 敌人"突然变蠢" | 敌人做了与行为模式不符的错误（非傲慢/结构性盲区） | 严重 |
| 主角"突然变强" | 无技术升级/知识获取前提下获得新能力 | 主题断裂 |

**严重度判定**：

| 频率 | 严重度 | 处理 |
|------|--------|------|
| 单场景出现1-2次"恰好/刚好"但非关键转折 | 轻微 | 警告 |
| 单场景关键转折依赖"恰好" | 严重 | 必须修改 |
| 多场景持续出现主角光环模式 | 主题断裂 | 整段重写 |

#### D2 · 通用修仙模板注入

> 用其他修仙作品的通用模板替代了本作的独有设定。

| 触发模式 | 检测规则 | 严重度 |
|---------|---------|--------|
| 主角使用"遁术/隐身术/传送符"等通用修仙手段 | 关键词匹配（遁术/传送符/隐身术/飞剑/御剑） | 严重 |
| 出现"先天灵根/天灵根/混沌体/天道意志/飞升"等模板概念 | 概念匹配（本作不存在这些概念） | 主题断裂 |
| "突破境界"的描述出现（主角不能修炼） | 关键词：突破/晋级/踏入……境 | 主题断裂 |
| 灵玉被当作"通用货币"购买功法/丹药 | 关键词：买功法/修炼功法/丹药修炼 | 严重 |

#### D3 · 科技手段退化

> 本应以经典物理为基础的技术，退化为"神奇的法器"。

| 触发模式 | 检测规则 | 严重度 |
|---------|---------|--------|
| 装置无量化限制（"无限使用/持续维持/完美隐身"） | 装置描述缺少电量/时间/范围限制 | 严重 |
| 装置原理脱离三段式创新链（无经典物理原型） | 无法追溯装置的物理基础 | 严重 |
| 装置被当成"法宝"使用（炼化/认主/滴血/神识操控） | 关键词：炼化/认主/滴血/神识绑定 | 主题断裂 |
| 小真变成"万能AI"（无推演过程） | 小真输出结论但无中间推理/计算过程 | 严重 |

#### D4 · 敌人不合理强化/弱化

| 触发模式 | 检测规则 | 严重度 |
|---------|---------|--------|
| 林岳使用凡人科技手段追踪 | 关键词：监控/数据库/算法/系统扫描 | 主题断裂 |
| 严峰使用监控/摄像头/逐帧筛查 | 关键词匹配（见 S12 废弃术语表） | 严重 |
| 敌人"突然变聪明"——超出行为模式 | 敌人在无信息获取前提下做出精确认知 | 严重 |
| 清洗司变成高效官僚机构 | 关键词：高效/系统化/流程化/标准化+清洗司 | 严重 |

#### D5 · 说教化（Over-Theming）

> 主题信号密度过高，叙事变成论文。

| 检测指标 | 阈值 | 严重度 |
|---------|------|--------|
| T1 信号密度 > 30/千字 | 超大 | 轻微（但需注意） |
| 角色对话变成"科普" | 对话中出现纯技术说明段落 | 轻微 |
| "修真者不懂"的陈述过于频繁 | 同一场景出现 ≥5 次 | 轻微 |

#### D6 · 术语残留（跨维度偏离）

> S12 废弃术语表中的词仍在使用。

| 检测 | 方法 | 严重度 |
|------|------|--------|
| 废弃术语扫描 | `python -m skf.cli check` | 每次出现视为严重 |

### 2.3 偏离严重度分级

| 级别 | 定义 | 示例 | 处理策略 |
|------|------|------|---------|
| **轻微偏离** (Minor) | 单点问题，不伤主题骨架 | 场景1-2次"恰好"非关键转折；T1密度略高(30-35) | 标记警告，可选修复 |
| **严重偏离** (Major) | 局部主题弱化，可修复 | 关键转折依赖"刚好"；装置缺少限制；出现通用修仙术语 | 必须修复 |
| **主题断裂** (Rupture) | 核心设定被破坏，不可接受 | 主角突然能修炼；先天灵根等不存在概念；林岳用数据库 | 必须整段重写 |

### 2.4 偏离评分公式

```
偏离评分 = Σ(偏离事件 × 严重度权重)

严重度权重：
- 轻微 = 1
- 严重 = 5
- 主题断裂 = 25

偏离评分 0    → CLEAN
偏离评分 1-4  → WARNING (存在轻微偏离)
偏离评分 5-24 → FAIL (存在严重偏离，需修复)
偏离评分 ≥25  → CRITICAL (存在主题断裂，不可出版)
```

## 三、主题密度模型

### 3.1 为什么需要密度模型

主题信号太少 → 场景漂移，读者感觉"这和其他修仙小说没区别"
主题信号太多 → 说教，读者感觉"作者在给我上课"

**最佳密度区间 = 让读者感受到"独特性"而不意识到"被灌输"**

### 3.2 章节类型与主题密度

| 场景类型 | 千字T1密度 | 千字T2密度 | 千字T3密度 | T1:T2:T3 比例 |
|---------|-------------|-------------|-------------|-------------|
| **武戏（躲藏/追逃/战斗）** | 12-22 | 8-15 | 6-12 | 3:2:1 |
| **文戏（对话/心理/情感）** | 5-12 | 8-18 | 5-15 | 2:3:2 |
| **技术研发/装置迭代** | 18-28 | 3-8 | 3-8 | 5:1:1 |
| **社会观察/势力交互** | 3-8 | 10-20 | 5-12 | 1:4:2 |
| **过渡/衔接场景** | 3-10 | 3-10 | 3-8 | 1:1:1 |

### 3.3 全局密度曲线（卷级）

```
卷一（86章）主题密度理想曲线：

T1 密度
│    ┌─ 上升期 ─┐  ┌─ 高潮 ─┐  ┌─ 收官 ─┐
│   ╱            ╲╱          ╲╱
│  ╱  建立        ╲  验证     ╲  完成
│ ╱   世界观        ╲ 实战      ╲ 过渡
│╱     ch1-30       ╲ch31-60   ╲ch61-86
└─────────────────────────────────────→ 章节

T2 密度（文明碰撞）随主角进入玄黄界（卷三）急剧上升
T3 密度（认知差武器）在每卷终局前达峰
```

### 3.4 密度预警系统

| 条件 | 警告 | 
|------|------|
| 连续3章 T1密度 < 5 | WARNING: 主题漂移——连续3章缺乏外物证道信号 |
| 连续3章 T2密度 < 5 | WARNING: 文明碰撞缺失——故事可能偏向纯粹冒险 |
| 单章 T1密度 > 30 | WARNING: 说教风险——技术说明可能挤占叙事空间 |
| 单章 T3密度 > 20 | WARNING: 认知差过度——可能削弱戏剧张力 |
| 全卷无 T1-S10（绝灵之体物理效应） | WARNING: 核心设定闲置——主角特殊体质未被叙事利用 |

## 四、主题检查算法

### 4.1 输入格式

```
输入类型A：章节规划文本（Markdown）
- 按"关键场景"分割为场景单元
- 每个场景 = 1个评估单位

输入类型B：已完成的叙事正文
- 按自然段落+场景变化分割
- 预处理：标注角色视角切换点、装置使用点、物理原理解释点
```

### 4.2 处理流水线

```
┌──────────────────────────────────────────────────────┐
│                主题检查流水线                          │
├──────────┬──────────┬──────────┬──────────┬──────────┤
│ 信号扫描  │→ 密度计算 │→ 偏离检测 │→ 协同分析 │→ 评分输出 │
│ Scan     │ Density  │ Deviation│ Coherence│ Scoring  │
└──────────┴──────────┴──────────┴──────────┴──────────┘
```

### 4.3 阶段一 · 信号扫描

```
算法：Signal Scan

输入：叙事文本 N（按场景分割）
输出：信号计数矩阵 S[场景][信号ID]

步骤：
1. 对每个场景s：
   a. 分句，对每句运行 25 个信号检测器
   b. 每个检测器 = 关键词正则 + 语义模式 + 否定排除
   否定排除示例：
     - 检测到"监控" → 检查语境（是否在说修真者"不用监控"）
     - 如果是"严峰不屑用监控" → 不算 D4 偏离，算 T2-S1 信号
     - 如果是"严峰调出监控" → 算 D4 偏离（严重）
2. 聚合：S[s][signal_id] = 该场景该信号的出现次数
```

### 4.4 阶段二 · 密度计算

```
算法：Density Calc

输入：S[场景][信号ID], 场景字数 wc[s]
输出：密度矩阵 D[场景][主题]

步骤：
1. 对每个场景s：
   T1_density[s] = (Σ_{t1_signals} S[s][sig] × sig.intensity) / wc[s] × 1000
   T2_density[s] = (Σ_{t2_signals} S[s][sig] × sig.intensity) / wc[s] × 1000
   T3_density[s] = (Σ_{t3_signals} S[s][sig] × sig.intensity) / wc[s] × 1000

2. 章级聚合：
   T1_chapter = mean(T1_density[s] for s in chapter)
   T2_chapter = mean(T2_density[s] for s in chapter)
   T3_chapter = mean(T3_density[s] for s in chapter)
```

### 4.5 阶段三 · 偏离检测

```
算法：Deviation Detect

输入：叙事文本N, S[场景][信号ID]
输出：偏离报告 D_report

步骤：
1. 运行 D1-D6 全部偏离检测器
2. 对每个检测到的偏离事件：
   a. 记录偏移类型、位置（场景/段落）、严重度
   b. 计算偏离评分：dev_score += event.severity_weight
3. 判断：
   dev_score == 0  → "CLEAN"
   dev_score 1-4   → "WARNING: {轻微偏离列表}"
   dev_score 5-24  → "FAIL: {严重偏离列表 + 修复建议}"
   dev_score ≥25   → "CRITICAL: {主题断裂事件 + 必须重写}"
```

### 4.6 阶段四 · 协同分析

```
算法：Coherence Analysis

输入：D[场景][主题]
输出：协同评分 C[场景]

步骤：
1. T1-T2 协同度：
   coherence_12[s] = 1 - |T1_density[s]/(T1_density[s]+T2_density[s]) - 0.6|
   // 理想 T1:T2 ≈ 3:2，即T1占比约60%

2. T1-T3 协同度：
   coherence_13[s] = min(T1_density[s], T3_density[s]) / max(T1_density[s], T3_density[s])
   // T1和T3应同步波动——没有外物就没有认知差武器

3. 必选信号检查：
   required_pass = (T1-S1 或 T1-S5 至少一个) AND
                  (T2-S1 或 T2-S2 至少一个) AND
                  (T3-S1 或 T3-S4 至少一个)

4. 协同评分：
   C[s] = (coherence_12 × 0.4 + coherence_13 × 0.3 + required_pass × 0.3) × 100
```

### 4.7 阶段五 · 综合评分输出

```
算法：Theme Score

输入：D[场景][主题], D_report, C[场景]
输出：主题评分报告

Theme Score = (
   0.35 × normalized_T1_density +   // 外物证道覆盖度
   0.25 × normalized_T2_density +   // 文明碰撞覆盖度
   0.20 × normalized_T3_density +   // 认知差武器覆盖度
   0.20 × C                          // 主题协同度
) × (1.0 - dev_penalty)

dev_penalty:
- CLEAN (dev_score=0) → 0.00
- WARNING (dev_score=1-4) → 0.05
- FAIL (dev_score=5-24) → 0.15
- CRITICAL (dev_score≥25) → 0.30

normalized_density:
- 将原始密度映射到0-1区间
- 低于最低阈值(5) → 0; 高于最高阈值(30) → 0.5（说教扣分）
- 在[8,25]区间 → 线性映射到[0.7,1.0]
```

### 4.8 输出格式

```yaml
主题评分报告:
  场景: "ch82-管道区周旋"
  类型: 武戏
  字数: 900
  
  # 密度
  T1_密度: 22.3/千字  # 绿色区间
  T2_密度: 14.1/千字  # 绿色区间
  T3_密度: 10.5/千字  # 绿色区间
  T1:T2:T3: 3.2 : 2.0 : 1.5  # 接近理想 3:2:1
  
  # 必选信号

  T2-S2_经典物理优势: ✓ (金属散射灵波)
  T3-S1_信息对等利用: ✓ (石眼+小真推演)
```
