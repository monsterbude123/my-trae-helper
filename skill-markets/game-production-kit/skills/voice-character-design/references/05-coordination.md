# Step 5 — 与 BGM 协调 + 多角色区分度

> **核心原则**：每个角色**独立成立还不够**——必须**与 BGM 协调**，**与同剧其他角色区分**。

## 协调维度表

| 协调对象 | 规则 | 反模式 |
|---------|------|--------|
| **BGM** | 角色语音频段不与 BGM 主旋律冲突 | 紧张 BGM 配低沉角色 → 听不清 |
| **其他角色** | 至少 3 个维度差异 | 同剧两个温柔少女 → 听不出谁在说话 |
| **旁白 vs 对话** | 旁白 vs 对话角色音域分开 | 旁白 = 主角音色 → 玩家混淆 |
| **场景情绪** | 角色 voice 适配场景基线 | 紧张场景用甜美少女 → 出戏 |

## BGM 频段冲突速查

| BGM 类型 | 主频段 | 角色语音建议 |
|---------|-------|-------------|
| 低频电子 | 60-200 Hz | 角色用头声/中高音 |
| 弦乐 | 200-800 Hz | 角色用中音或节奏错开 |
| 高频弦乐 + 打击 | 800-4000 Hz | 角色用胸声/低频 |
| 安静钢琴 | 200-2000 Hz | 角色不要用同节奏 |

> 经验：紧张/恐怖 BGM（低频多）配**明亮少女音**反而效果好——反差带来不安感。

## 多角色区分度检查

### 方法：差异表

```markdown
| 角色 | 年龄 | 性别 | 共鸣 | 语速 | 音调 | 情绪基线 |
|------|------|------|------|------|------|----------|
| 邱苏晚 | early 20s | female | head+chest | 慢 | 句尾微升 | 温柔忧郁 |
| 林之一 | early 20s | male | mid | 慢 | 平 | 内敛 |
| 咖啡馆老板 | late 60s | male | deep chest | 慢 | 降 | 看透 |
| 旁白 | 30s | male | mid | 中 | 平 | 中性 |
```

> **至少 3 个维度**有明显差异。

### 实战中容易撞车的组合

| 撞车 | 修复 |
|------|------|
| 两个"温柔少女" | 一个加 maturity（成熟气），一个加 youth（活力） |
| 主角独白 vs 旁白 | 让旁白用更低/更专业，主角用更个性化 |
| 男主 vs 反派 | 一个用 mid-tenor / 慢；一个用 baritone / 快 |
| 老者 vs 反派老者 | 一个用 gravelly + warm；一个用 harsh + cold |

## 角色情绪 vs 场景情绪

| 角色基线情绪 | 适配场景 | 不适配场景 |
|------------|---------|-----------|
| 温柔 | 日常、回忆、告白 | 战斗、恐怖 |
| 紧张 | 追逐、揭秘 | 日常、告白 |
| 看透一切 | 哲理、回忆 | 高潮战斗 |
| 冷峻 | 战斗、压迫 | 喜剧、日常 |

> 经验：**角色基线情绪强**时不要强塞不匹配场景——会让该场景失色。

## 实战：3 角色配置（带 BGM 协调）

```yaml
# 紧张场景 BGM: s_unease (低频 drone 60-200 Hz)
# 要求: 角色音域避开 60-200 Hz

- character: qiu_suwan
  voice: "head voice, mid-high, gentle"
  emotion_baseline: tender_melancholic
  conflict_with: s_unease  # 无
  
- character: lin_zhiyi
  voice: "mid tenor, calm"
  emotion_baseline: introverted
  conflict_with: s_unease  # 无
  
- character: cafe_boss
  voice: "deep baritone, gravelly"
  emotion_baseline: knowing
  conflict_with: s_unease  # ⚠️ 同频段冲突
  # 解决: 给 cafe_boss 的对白配上 bgm 短暂静音
```

## 旁白 vs 主角独白的处理

### 方案 A：两个不同声线
- 旁白 = 30s 男播音员
- 主角 = 25s 男青年

### 方案 B：相同声线 + 角色称呼
- 主角对话：`林之一:内容;`
- 主角内心独白：`{林之一·独白}:内容;` + 旁白音色

### 方案 C：禁用独白
- 全部用旁白朗读主角内心
- 优势：旁白稳定
- 劣势：代入感弱

**推荐**：方案 A 配合音色锁定 seed。

## 一致性检查清单

```
□ 同一角色所有 voice 条目 seed 一致
□ 同剧所有角色 5 维差异表已画
□ BGM 频段与角色音域不冲突
□ 主角、旁白、反派各 1 个声线，不共用
□ 至少 3 个场景里听到角色对白，确认"听得出谁在说话"
```

## 反模式汇总

| 反模式 | 后果 | 修复 |
|--------|------|------|
| 全剧用"标准中文女声" + 不同 seed | 听不出谁说话 | 严格画 5 维差异表 |
| 角色 voice 写"温柔" | 模型随机选女声 | 写"slow pacing + breathy + mid-volume" |
| 紧张 BGM + 低音角色 | 听不清对白 | 紧张场景换高音角色 |
| 主角内心独白用旁白声 | 玩家不知谁在想 | 主角用专属声线 |
| 给每个角色一个 seed | 漂移 | 单角色一 seed 跨场景复用 |
