# 办公助理

> 在常用通讯工具（飞书 / 微信）中直接处理工作。单聊或群聊中提交任务，原会话查看进度、接收结果。
> 适用范围：**TRAE Work 桌面版**。

## 支持的通讯工具

| 通讯工具 | 接入方式 | 状态 |
|---------|---------|------|
| **飞书** | 飞书智能体应用 | ✅ 已支持 |
| **微信** | "微信 ClawBot" 插件 | ✅ 已支持 |
| **企业微信** | — | 即将上线 |
| **钉钉** | — | 即将上线 |

> 飞书和微信的桌面版、移动端均可用于收发消息。**首次连接需要在 TRAE Work 桌面版中发起**。

## 使用场景

- **快速处理聊天中的文件**：转发表格/文档给 TraeWork → 处理需求 → 聊天中返回结论和产物
- **参考多处资料生成总结**：发送聊天记录 / 文档链接 / 历史资料 → AI 提炼总结
- **群聊协作推进事项**：将 TraeWork 加入项目群 → 群成员补充信息 / 确认方向 / 追问结果
- **手机上处理临时工作**：通过通讯工具移动端发送需求 → 复杂操作回桌面版
- **随时查看处理进展**：在原会话问进度 / 接收结果

## 快速开始

### 连接 TRAE Work 与通讯工具

左栏 → **办公助理** → 点击目标通讯工具右侧 **去绑定** → 扫码。

- **飞书**：手机飞书 App 扫码 → **立即创建** → 创建飞书智能体应用（默认名"TraeWork"） → 打开应用
- **微信**：手机微信 App 扫码 → **连接** → 自动启用"微信 ClawBot"插件

> 连接完成后，TRAE Work 办公助理面板顶部对应通讯工具状态变 "已连接"。

### 收发消息

| 场景 | 操作 |
|------|------|
| **单聊** | 打开与办公助理的聊天窗口，直接发送消息 |
| **群聊** | 输入 `@{智能体名称}` + 消息内容后发送 |

> **群聊权限**：仅办公助理的**创建者**可以使用，其他成员仅可查看消息记录。

桌面版办公助理面板的消息记录**不同步**到通讯工具；通讯工具发送的消息会在两端同步。

> 在 TRAE Work 桌面版中，办公助理对话及历史记录同步显示在 Work / Code / Design 模式中，切换模式后仍可基于已有上下文继续沟通。
> 多通讯工具的消息按发送时间汇总显示（用户名前图标区分来源）；**不同通讯工具的会话不会自动合并上下文**——避免混淆，建议原会话处理同一项任务。

### 查看子任务

工具面板 → 查看子任务列表（**不可管理**这些子任务）。

### 管理产物

| 端 | 可用操作 |
|----|----------|
| **通讯工具** | 查看简要结论、产物说明、访问链接；飞书产物卡片支持查看/下载/存到云盘 |
| **TRAE Work 桌面版** | 查看任务摘要、预览、管理、编辑、导出产物 |

## 管理连接与更多设置

**办公助理 → 管理连接**：

| 操作 | 说明 |
|------|------|
| **解绑** | 解除连接（对话历史保留） |
| **去绑定** | 连接其他通讯工具 |
| **保持电脑唤醒** | 开关：消息收发期间保持唤醒，避免中断 |
| **完全访问** | 模式：关闭沙箱保护和所有审批检查，TraeWork 可直接在宿主机上执行任意操作 ⚠️ **风险高，请充分评估** |

## 进阶：让 TraeWork 操作飞书功能

默认 TraeWork 无法直接操作飞书的云文档 / 日历 / 多维表格等。需通过 **连接器授权** 启用：
- 创建云文档、创建日程、修改多维表格数据等
- 详见 [feishu-integration.md](feishu-integration.md)
