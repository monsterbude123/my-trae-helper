# 语音讨论

> 通过语音与 AI 进行多轮交互式讨论。讨论结束 AI 自动转写 + 清洗 + 结构化处理，输出文本纪要。

## 使用场景

| 角色 | 典型用法 |
|------|----------|
| **产品经理** | 从灵感到方案的头脑风暴（PRD / 项目文档 / 代码库 / 界面截图对话式分析） |
| **研发工程师** | 基于代码库的技术讨论、Bug 根因、方案取舍 |
| **产品运营** | 依据历史讨论 / AI 报告做策略多轮推演 |
| **数据分析师** | 上传 Excel 等数据文件 → 对话式多维分析 |
| **通用场景** | 引用历史讨论 / 上传文档形成可持续追溯的上下文 |

## 操作步骤

1. 对话输入框右下角 → 点击 **语音讨论** 图标
2. 首次使用 → 授权麦克风 → 进入录音界面
3. (可选) 点击 **开启字幕** → 实时查看转录文本
4. 开始讨论；表达停顿后 AI 实时反馈
5. 讨论完成 → **结束** 按钮
6. 在对话流的 **讨论结果** 面板查看结构化纪要
7. 点击 **查看会议记录** → 原始讨论记录

## 文本处理策略

| 策略 | 说明 |
|------|------|
| **去噪与口语清洗** | 自动清理"嗯/然后/就是/那个"等语气词；合并语义重复；修复停顿断句；修正语法错误 |
| **语义理解与自动修正** | 识别发言人自我修正（"不是 A，是 B"），保留最终结论，删除被推翻内容 |
| **结构化表达** | 自动生成标题、整理要点为列表、按总分结构组织段落 |

## TRAE 移动端后台运行

在 TRAE 移动端主动开启语音讨论后，即使应用后台 / 锁屏，仍持续采集麦克风并播放音频。可通过 **静音** 停止后台麦克风采集（仅保留音频播放）。**结束对话即自动停止**后台采集。
