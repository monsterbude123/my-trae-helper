## 调用模式

- **任何生成类 skill 之前**：必先调用 `comfyui-inventory`

- **任何工作流前**：对照库存做校验（缺失节点/模型）
- **会话开始时**：通过 `comfyui-research` 做一次快速陈旧度检查
