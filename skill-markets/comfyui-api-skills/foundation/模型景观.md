# 模型景观（每类前 3）

> 模型选择速查。完整规格见 `references/模型清单.md`。

<!-- 更新：2026-03-18 | 来源：英伟达博客、ComfyUI 更新日志、HuggingFace、ComfyUI 博客 -->

> **ComfyUI 版本**：v0.17.2（2026 年 3 月 15 日）。包含 App 模式、Nodes 2.0 Vue、FluxKVCache 节点。

> **NVFP4 关键提示**：RTX 50 系列的 NVFP4 加速**需要基于 CUDA 13.0（cu130）构建的 PyTorch**。否则 NVFP4 模型运行速度比 FP8 **慢 2 倍**。使用前用 `torch.version.cuda` 验证。

> **性能更新（2026 年 2 月）**：ComfyUI 在所有英伟达显卡上通过异步卸载 + 固定内存（默认开启）**提速 40%**。RTX 50 系列：NVFP4 = 提速 3 倍 / 显存省 60%；NVFP8 = 提速 2 倍 / 显存省 40%。
