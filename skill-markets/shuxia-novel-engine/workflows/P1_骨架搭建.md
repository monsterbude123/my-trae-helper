# P1 工作流 · 骨架搭建

> 从沙盒世界到叙事骨架
> 主导: Plot Orchestrator | 门禁: Consistency Auditor

---

## 工作流触发
P0 门禁通过，用户确认沙盒满意。

## 工作流步骤

### Step 1: 卷结构定义

```
对每卷:
  卷号 | 主题(一句话) | 主角所处阶段 | 章数 | 开篇钩子 | 结尾钩子

卷的主题演进:
  卷一: 建立世界 + 建立局限 → "主角知道了什么"
  卷二: 深化冲突 + 第一次重大失败 → "世界的残酷"
  卷三: 转折 + 力量重组 → "代价"
  卷四: 全面对抗 + 逼近真相 → "真相的重量"
  卷五: 终局 + 文明选择 → "一切的意义"
  
(这是通用模板，适配你的故事)
```

### Step 2: 角色弧设计

```
主角弧线:
  起点状态 ──[事件]──→ 状态2 ──[事件]──→ ... ──[事件]──→ 终点状态
  
  每卷的状态转变:
  卷一末: 主角获得了什么新认知/能力？
  卷二末: 主角失去了什么？
  卷三末: 主角做出了什么不可逆的选择？
  卷四末: 主角逼近了什么真相？
  卷五末: 主角成为了什么样的人？

配角弧线(每个主要配角):
  名称 | 起点 | 每卷的转变 | 终点 | 与主线的交叉点
```

### Step 3: 冲突网络

```
主冲突: 主角 vs 核心反派
  [卷一起点] 力量对比: 主角 0 : 反派 N
  [每卷] 关键逆转事件 → 力量对比变化
  [卷五终点] 力量对比: 主角 ? : 反派 ?

副冲突(每卷至少 2 条):
  冲突名称 | 类型(人物关系/势力博弈/内部挣扎) | 涉及角色 | 与主线的交叉章
```

### Step 4: 伏笔播种

```
目标: 20-40 个伏笔

伏笔类型分配:
  人物型: ~30% (与角色背景/命运相关)
  事件型: ~30% (与具体情节相关)
  世界观型: ~25% (与设定/规则相关)
  情感型: ~15% (与人际关系相关)

每卷伏笔密度:
  卷一: 40% (大部分伏笔在卷一埋设)
  卷二: 20%
  卷三: 20%
  卷四: 15%
  卷五: 5% (新伏笔少，回收多)

写入双表格式:
  已埋未收: | ID | 名称 | 埋设章 | 计划回收章 | 类型 | 涉及人物 | 备注 |
  已回收:   | ID | 名称 | 埋设章 | 回收章 | 类型 | 涉及人物 | 回收方式 |
```

### Step 5: 涟漪检查

```
运行: ripple.py --full-project
检查新增概念/角色/势力的影响面
要求: 零 BLOCKER
CRITICAL ≤ 3 且有修复计划
```

### Step 6: 门禁提交

提交给 Consistency Auditor 进行弧线完整性 + 涟漪审查。

## P1 常见陷阱

| 陷阱 | 症状 | 修正 |
|------|------|------|
| 角色弧跳级 | 从"不信任"直接跳到"牺牲" | 插入中间状态和触发事件 |
| 伏笔集中 | 所有伏笔都在卷一 | 按比例分摊到各卷 |
| 副线孤立 | 副冲突从不与主线交叉 | 找到交叉点，否则删除 |
| 结尾无钩子 | 卷结尾平淡，读者不急着读下一卷 | 加钩子——信息揭示/悬念/情感悬念 |
