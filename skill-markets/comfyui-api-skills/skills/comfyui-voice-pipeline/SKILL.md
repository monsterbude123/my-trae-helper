# ComfyUI 语音管线技能

语音合成 + 口型同步，覆盖从克隆声音到生成说话人视频的完整链路。

## 语音合成工具矩阵

| 工具 | 适用场景 | 许可证 | 显存/算力 | 备注 |
|------|----------|--------|----------|------|
| TTS Audio Suite | 统一 11 引擎平台 | 多 | 视引擎 | ChatterBox、F5、Qwen3、IndexTTS-2、VibeVoice、RVC 等 |
| Qwen3-TTS | 10 种语言、声音设计 | 开源 | 8GB+ | 2026 年 1 月新出；零样本克隆；基于文本的声音设计 |
| Chatterbox Turbo | 快速情绪、生产级 | MIT | 8GB | 350M 参数；延迟亚 200ms；带情绪标签 |
| IndexTTS-2 | 8 维情绪向量控制 | 开源 | 8GB+ | 情绪滑杆 + 音频参考 |
| F5-TTS | 零样本克隆、低显存 | MIT | 6GB | 6GB 显存可运行 |
| VibeVoice | 长篇（90 分钟）、多说话人 | 微软 | 16GB+ | 前沿对话模型 |
| RVC | 声音转换 | 开源 | 4GB | 把任意声音转换为目标声音 |
| ElevenLabs | 云端商业级 | 商业 | 云端 | 需 API key |

## 口型同步工具矩阵

| 工具 | 适用场景 | 精度 | 速度 |
|------|----------|------|------|
| LatentSync 1.6 | 最高精度 | 极高 | 中 |
| Wan 2.6 原生 | 参考图生视频内置 | 高 | 快 |
| Wav2Lip | 久经验证、任意人脸 | 中 | 快 |
| SadTalker | 头部动作 + 表情 | 中 | 中 |
| LivePortrait | 表情迁移 | 高 | 中 |

## 决策表

| 需求 | 推荐组合 |
|------|----------|
| 快速预览、低质量可接受 | Qwen3-TTS + Wav2Lip |
| 中文场景、多语言 | Qwen3-TTS + LatentSync 1.6 |
| 高质量角色一致 | F5-TTS（声音克隆）+ Wan 2.6（参考图+内置口型） |
| 极致写实、最高精度 | IndexTTS-2 + LatentSync 1.6 |
| 商业级、零门槛 | ElevenLabs + 自带口型 |
| 长对话/多人 | VibeVoice + SadTalker |
| 风格化、实验性 | RVC（声音转换）+ SadTalker |

## 三种完整管线

### 管线 1：快速管线（图生说）

**流程**：

```
角色图
  ↓
Wan 2.6（开启音频生成 + 口型同步）
  ↓
输出：带音轨的说话人视频
```

**适用**：3-10 秒短句、概念验证、低质量可接受

**显存**：24GB+

**耗时**：30-90 秒

**质量**：中等（取决于 Wan 2.6 表现）

### 管线 2：质量管线（图生视频+口型同步）

**流程**：

```
角色图
  ↓
Qwen3-TTS / F5-TTS（独立生成语音 WAV）
  ↓
Wan 2.2 / HunyuanVideo（基于参考图 + 文本提示词生成无声视频）
  ↓
LatentSync 1.6（音频 + 视频 → 对齐口型）
  ↓
VHS_VideoCombine（合并最终视频）
```

**适用**：5-30 秒、YouTube 短片、生产级

**显存**：24GB+

**耗时**：5-15 分钟

**质量**：高

### 管线 3：高级管线（表情迁移）

**流程**：

```
目标角色图
  ↓
参考表演视频
  ↓
LivePortrait（表情迁移：参考视频表情 → 目标角色）
  ↓
Qwen3-TTS（语音合成）
  ↓
Wav2Lip（口型对齐）
  ↓
VHS_VideoCombine
```

**适用**：表情精确复刻、特定表演

**显存**：24GB+

**耗时**：15-30 分钟

**质量**：高（表演来自参考视频）

## 各工具详细配置

### Qwen3-TTS

**支持语言**：中文、英文、日文、韩文等 10 种

**使用方式**：
- 零样本克隆：上传参考音频 3-10 秒
- 文本设计：纯文本描述声音（"温柔女声，30 岁，中等语速"）

**提示词示例**：
```
用温柔的女声说：欢迎来到我的频道，希望你喜欢今天的内容。
```

**参数**：
- 语速：0.8-1.2
- 音调：±5
- 情绪：平静 / 欢快 / 严肃

### F5-TTS

**特点**：
- 零样本克隆
- 低显存（6GB 即可）
- 速度快

**使用方式**：
- 上传 5-15 秒参考音频
- 提示词：<说话内容>

### Chatterbox Turbo

**特点**：
- 350M 参数
- 亚 200ms 延迟
- 情绪标签

**情绪标签**：`<laugh>`、`<sigh>`、`<excited>`、`<whisper>`

**提示词示例**：
```
今天真是<excited>太棒了<laugh>，我们一起来试试看吧！
```

### IndexTTS-2

**特点**：
- 8 维情绪向量（滑杆控制）
- 音频参考驱动

**情绪维度**：
- 喜悦、愤怒、悲伤、恐惧、惊讶、厌恶、中性、温柔
- 每维度 0-1 滑杆

**使用方式**：
- 选情绪滑杆组合
- 上传参考音频
- 提示词：<文本>

### RVC（声音转换）

**特点**：
- 转换任意声音为目标声音
- 需预训练 RVC 模型

**使用方式**：
- 准备 RVC 模型（.pth）
- 输入源音频（任意说话人）
- 输出：转换为 RVC 目标声音

**适用**：风格化、变声、角色化

## 与项目角色档案协同

读取 `角色/{名}.yaml` 的 `声音档案` 字段：

```yaml
声音档案:
  参考音频: 参考图/voice_sample.wav
  性别: 女
  音调: 中
  语速: 中
  口音: 美式
```

自动选择工具：

- 有参考音频 → F5-TTS / Qwen3-TTS 零样本克隆
- 仅文本描述 → Qwen3-TTS 文本设计

## 输出

语音/视频生成完成后：

1. 音频文件存到 `projects/{项目}/生成记录/{时间戳}/`
2. 视频文件同上
3. 角色档案更新声音参考（如有迭代）

## 故障排查

### 声音不像参考

- 提升参考音频质量（清晰、无背景音乐）
- 参考音频 5-15 秒最佳
- 尝试不同工具（F5 → Qwen3 → IndexTTS-2）

### 口型不同步

- LatentSync 1.6 处理长视频时切分
- 检查音频采样率（16kHz / 24kHz）
- 视频 fps 与音频时长匹配

### 显存不足

- 用 F5-TTS（6GB 即可）
- 视频部分用 GGUF 量化
- 分段处理

## 注意事项

- **声音版权**：克隆他人声音需获得授权
- **商用合规**：商用前检查各工具许可证
- **多语言**：中英混合文本用 Qwen3-TTS
- **多说话人**：用 VibeVoice 或独立生成后混合
- 多次实验后**记录有效组合**到角色档案
