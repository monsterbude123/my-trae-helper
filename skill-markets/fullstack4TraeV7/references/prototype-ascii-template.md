# ASCII 线框图模板

> 字符集：┌ ┐ └ ┘ ─ │ ├ ┤ ┬ ┴ ┼

---

## 模板 1：标准 App 布局（侧栏 + 主内容）

```
┌─────────────────────────────────────────────┐
│  App Header                         [操作]   │
├──────────────┬──────────────────────────────┤
│ 导航/侧栏     │ 主内容区                      │
│ ├ 菜单项1    │ ┌──────────────────────────┐ │
│ ├ 菜单项2    │ │ 实际数据/内容              │ │
│ └ 菜单项3    │ │                          │ │
│              │ └──────────────────────────┘ │
└──────────────┴──────────────────────────────┘
```

## 模板 2：卡片网格（Gallery/仪表盘）

```
┌─────────────────────────────────────────────┐
│  标题行                        [操作按钮]    │
├──────────────────┬──────────────────────────┤
│  ┌────────────┐  │  ┌────────────┐          │
│  │  卡片 1     │  │  │  卡片 2     │          │
│  │  实际内容   │  │  │  实际内容   │          │
│  └────────────┘  │  └────────────┘          │
│  ┌────────────┐  │  ┌────────────┐          │
│  │  卡片 3     │  │  │  卡片 4     │          │
│  └────────────┘  │  └────────────┘          │
└──────────────────┴──────────────────────────┘
```

## 模板 3：表单/详情页（单列）

```
┌─────────────────────────────────────────────┐
│  页面标题                                    │
├─────────────────────────────────────────────┤
│  标签1:  [输入框 实际值__________________]    │
│  标签2:  [下拉选择              ▼]           │
│  标签3:  [文本域                        ]    │
│         [                              ]    │
├─────────────────────────────────────────────┤
│              [取消]    [保存]                │
└─────────────────────────────────────────────┘
```
