# 产物管理（产物空间 + HTML 产物）

## 1. 产物空间（"我的文件"）

> 集中查看和管理任务产物的入口。连接飞书后也可查看授权账号的飞书云文档。
> 适用范围：TRAE Work 桌面版 + 网页版的 **Work 模式**。

### 产物类型

| 类型 | 来源 | 适用范围 |
|------|------|----------|
| **本地产物** | 本地任务生成，存于本地 | 桌面版 |
| **云端产物** | 云端任务生成，存于云端 | 桌面版 + 网页版 |

### 进入入口
左栏 → **我的文件**。可按文件夹分组 / 网格视图 / 列表视图。

### 预览与管理

点击产物卡片 → 产物预览窗口。`···` 菜单支持：

| 操作 | 说明 | 适用 |
|------|------|------|
| 置顶 | 顶部显示"已置顶"分类 | 本地 / 云端 |
| 在任务中打开 | 回到原始对话继续编辑 | 本地 / 云端 |
| 发起新对话 | 新任务继承产物（**不继承原始对话上下文**） | 仅本地 |
| 分享 | 生成可公开分享链接，对方始终看到最新内容 | 本地 / 云端 |
| 下载 | 下载到本地 | 仅云端 |
| 在 Finder / 资源管理器中显示 | 定位本地路径并高亮 | 仅本地 |
| 删除 | **不可恢复**；删除产物后原始任务一并删除 | 本地 / 云端 |

### 编辑产物（在原始任务中打开后）

1. 顶部 → **编辑** → 进入编辑模式
2. 顶部中央 → 选择 **点击修改** 或 **截图修改**：
   - **点击修改**：选中元素 → 编辑栏手动改文字 / 让 AI 改（评论发送）
   - **截图修改**：截取区域 → 矩形或箭头标记 → 输入意见发送
3. **评论** 图标 → 查看和管理已添加的评论（可逐条或批量发送）

## 2. HTML 产物管理

> 生成、预览、编辑和分享 HTML 产物；可将需求文档、产品原型、分析报告生成为可直接预览的 HTML 页面。

### 可交互式 PRD

输入如"帮我生成一份 XX 产品的可交互 PRD，并生成相应的原型"。生成结果通常包含两部分：
- **原型预览**（左）：点击原型元素 → 右侧需求面板自动定位到对应"需求详情"
- **PRD 文档全文**（右）：产品背景、目标用户、核心流程、功能需求、页面说明、交互规则、异常状态等

修改原型某部分 → PRD 对应内容**自动同步更新**。

### 编辑 HTML 产物

1. 预览页签右上 → **编辑** 按钮
2. 选择元素 → 三种修改方式：
   - **评论转对话**：单条或多条评论 → 直接发送或批量发送
   - **直接编辑**：仅文字类元素（字号、加粗、对齐）
   - （图片参考详见官方文档）

### 分享 HTML 产物

预览页右上 → **分享** → **开启分享** → 复制分享链接。后续更新产物，访问同一链接看到最新内容。
