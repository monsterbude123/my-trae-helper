## 5 状态要求

每个页面必须覆盖以下 5 种状态的视觉表现：

1. **加载中**: {骨架屏/loading 动画/进度条}
   - 例: 卡片骨架屏，灰色占位块 + 闪烁动画
2. **空数据**: {空状态插画 + 引导文案}
   - 例: 居中插画 + "暂无数据" + "创建第一条" 按钮
3. **正常态**: {正常数据展示的完整页面}
   - 例: 列表 / 卡片网格 / 表格完整渲染
4. **错误态**: {错误提示样式 + 重试入口}
   - 例: 红色卡片 + 错误图标 + 错误文字 + "重试" 按钮
5. **边界态**: {极限数据场景，如超长文本/大量数据/极端缩略图}
   - 例: 标题超长截断 + 缩略图加载失败占位 + 1000+ 列表项虚拟滚动
