# Design 模式

> Design 模式是 TRAE Work 中专用于生成与迭代界面设计的工作模式。生成结果在**画布**中展示，支持继续编辑、预览、导出，并可一键切换到 **Code 模式** 转前端代码。

## 使用场景

| 场景 | 说明 |
|------|------|
| 快速生成页面设计 | 自然语言描述 → 网页/应用页面原型或高保真设计 |
| 基于既定风格生成 | 导入团队设计资产（主题/组件/图像），按规范复用 |
| 批量修改设计稿 | 全局替换颜色 / 统一字体 / 同模板多版本 |
| 设计资产管理 | 设计系统统一管理主题、组件、图形与规范 |

## 快速开始

### 1. 切换模式
界面左上角点击 **Design**。

### 2. 指定设计风格
输入框左下方 → 设计风格下拉菜单：
- **自由探索**：AI 自动选风格，适合早期概念
- **设计系统**：内置或自定义设计系统（详见 [design-system.md](design-system.md)）

### 3. 发起任务
任务类型：
- **设计还原**：上传 UI 参考图 + 自然语言说明
- **概念成稿**：直接描述目标/结构/风格
- **规范出图**：选择设计系统 + 说明要求

上下文越明确（页面类型、目标用户、视觉风格、端侧尺寸、交互），生成结果越接近预期。

## 画布工具栏

| # | 操作 | 说明 |
|---|------|------|
| 1 | 预览 | 单产物展示；可切换 **网页 / 平板 / 手机** 或自定义尺寸 |
| 2 | 连线 | 显示/隐藏页面间跳转热区的连线关系 |
| 3 | 可视化编辑器 | 选中元素 → 右侧属性面板；包含 **设计**（位置/布局/外观/填充/边框/阴影/模糊）与 **原型**（建立元素与页面的跳转关系） |
| 4 | 更多 | 导入图片素材 / 整理画布 |
| 5 | 导出 | Figma（矢量） / PNG / JPG / HTML / ZIP |

## 产物卡片操作

选中单个产物后顶部菜单：
- **添加到对话** — 让 AI 继续修改
- **预览** — 画布中展示
- **更多** — 复制 / 重命名 / 重新生成 / 导出 / 删除

## 设计 → 代码一键衔接

1. 画布中选中一个或多个产物
2. 顶部 `···` → **导出设计文件** → **在 Code 模式中开发**
3. 修改默认指令（补充技术栈 / 交互 / 响应式 / 目录规范）
4. 选择运行环境与代码存储位置 → 发送

## 内置设计系统一览

完整 16 套内置设计系统（详见 [design-system.md](design-system.md)）：TraeWork、TraeCode、Volcengine、TikTok、Doubao、Apple、Claude、Google、Vercel、Minimalist、21th、Motion Fit、Golden Time、Nerv、Barbie、Vibe Camp。

## 自定义设计系统

支持三种添加方式：
| 方式 | 说明 |
|------|------|
| 解析 Figma | 导出 `.fig` 文件 → AI 解析颜色/字体/组件 |
| 导入设计系统 | 上传已有的 TraeDesign `.zip` |
| 风格探索 | 自然语言描述风格偏好 → AI 追问 + 生成新设计系统 |

可在「主题 / 组件 / 图形 / 设计规范」四个页签编辑管理。

> 详细字段编辑（颜色、排版、圆角、间距）和设计规范上传要求见 [design-system.md](design-system.md)。
