# 万古余烬 · 六维文学评估引擎设计

> 从"感觉好不好"到"可计算的量化评分"
> 版本: v1.0 · 2026-06-16
> 状态: 设计规范（非代码实现）

---

## 零、设计原则

### 0.1 核心约束

1. **可计算性**：每个评分因子必须有可量化的输入和确定的计算规则。不允许"我感觉这里应该扣5分"。
2. **可追溯性**：每个分数必须能追溯到具体的数据源（章节计划/角色表/概念注册表/物理引擎）。
3. **分层评分**：先评子因子（0-1），再加权合成维度分（0-100），最后跨维度加权得总分（0-100）。
4. **场景感知**：权重随场景类型动态调整——武戏重World，文戏重Aesthetic。
5. **零分为锚**：每个维度的零分定义是"不可出版的最低标准"，不是"什么都没写"。

### 0.2 输入数据源

| 数据源 | 提供内容 | 对应维度 |
|--------|----------|----------|
| `physics.py` LingField | 灵压/耦合/退相干计算 | World |
| `combat.py` CombatBalance | 赢面公式验证 | Plot, World |
| `schema.sql` character | 角色战力/傲慢/动机 | Character, Society |
| `schema.sql` faction | 势力关系/内部矛盾 | Society |
| `schema.sql` concept | 概念注册/科技树依赖 | World, Theme |
| `schema.sql` foreshadow | 伏笔状态追踪 | Plot |
| `schema.sql` chapter | 章级元数据 | 全部 |
| `创作正文/世界观/亚文化建设宪法.md` | 7条公理 | World, Theme |
| `创作正文/世界观/四层索引.md` | 层级关系 | World, Theme |

### 0.3 评分粒度

- 子因子：0.00-1.00（两位小数）
- 维度分：0-100（整数）
- 总分：0-100（整数）
- 评估单位：**单个场景**（对应章节规划中的一个关键场景行）

## 一、维度一 · World —— 物理/世界层

### 核心问题

> 这场戏的物理条件是否自洽？灵压/地理/科技树/L场物理是否成立？

### 1.1 子因子定义

| 编号 | 子因子 | 含义 | 权重 |
|------|--------|------|------|
| W1 | 灵压一致性 | 当前场景灵压与地理位置/时代匹配 | 25% |
| W2 | L场物理自洽 | 灵场现象符合Klein-Gordon/BEC/耦合公式 | 25% |
| W3 | 科技树依赖 | 装置/功法有前置依赖，无跳跃 | 20% |
| W4 | 地理距离 | 移动时间/空间关系与地图一致 | 15% |
| W5 | 量化精确度 | 效果有数值（息/米/秒/千瓦），无模糊词 | 15% |

### 1.2 子因子评分算法

**W1 灵压一致性**（score 0-1）

```
W1 = 1.0 - (违规权重和)
```

违规检测规则：
- 场景地点有灵压定义（如"绝灵之地 P_L≤0.01息"、"万象宗本部 P_L≈8息"），实际描述中的灵学现象所需灵压超过该地灵压上限 → 扣0.3
- 场景时间线明确（如3635年），灵压年衰减率0.03%，若该时间点灵压已跌破某功法/阵法的最低灵压阈值但功法仍正常运行 → 扣0.4
- 绝灵之地出现修真者正常施法（无灵能电池/灵玉辅助）→ 扣0.5
- 灵压单调性：同一地点、同一时段，灵压不能忽高忽低（除非有明确的局部灵压源）→ 扣0.2/次

数据来源：`physics.py` LingField.ling_pressure()，`创作正文/世界观/底层设计.md` 灵压分布表，`创作正文/世界观/修真物理学.md` 灵场论

---

**W2 L场物理自洽**（score 0-1）

```
W2 = 1.0 - (违规权重和)
```

违规检测规则：
- 灵学现象无L场物理解释（只有"他用了法力"而无灵子流/灵场耦合说明）→ 扣0.3/次
- 灵场现象违反Klein-Gordon方程约束（如灵子以超光速传播）→ 扣0.5
- BEC凝聚态被用于需高温的场景（灵子BEC只在T<T_c时不衰减，T>T_c时退相干）→ 扣0.3
- 灵场↔EM耦合常数被忽略（灵能→电能 或 电能→灵能 转化未走耦合通道）→ 扣0.4
- 灵导率σ_L使用错误（如玄铁σ_L≈10²却声称传输效率与灵玉σ_L≈10⁸相同）→ 扣0.2

数据来源：`physics.py` LingField.coupling_effective()，`engine/physics.py` 常量区

---

**W3 科技树依赖**（score 0-1）

```
W3 = 满足的前置依赖数 / 应有前置依赖数
```

检测规则：
- 从concept表查该场景使用的所有技术/概念ID
- 从tech_dependency表查每个概念的upstream依赖
- 若upstream概念在更早章节已引入 → 满足
- 若upstream概念在更晚章节或从未引入 → 不满足
- 权重按tech_node.layer加权（底层概念缺失扣分更重）

数据来源：`schema.sql` tech_dependency, tech_node, concept, concept_chapter_ref

---

**W4 地理距离**（score 0-1）

```
W4 = 1.0 - (不合理移动数 / 总移动数)
```

检测规则：
- 从场景的"场景清单"提取地点转移
- 对比`创作正文/世界观/地图定位.md`中的距离
- 若两点距离>100km，时间跨度<1小时，且无飞行法器/传送阵 → 不合理
- 若两点距离>10km，步行时间<1小时 → 不合理
- 若场景时间覆盖无法容纳所有移动+事件 → 扣分

---

**W5 量化精确度**（score 0-1）

```
W5 = 1.0 - (模糊词计数 × 0.1)
```

模糊词库：
- `威力巨大` `极快` `极强` `巨大无比` `神奇地` `不可思议地` `难以想象的`
- 每个模糊词扣0.1，扣到0为止
- 注意：修辞性形容（"他感到一股巨大的恐惧"——情绪形容）不算

---

### 1.3 维度总分

```
World = (W1×0.25 + W2×0.25 + W3×0.20 + W4×0.15 + W5×0.15) × 100
```

### 1.4 满分条件（100分）

- 场景中所有灵学现象可追溯到L场量子物理解释
- 灵压数值与地点/时代精确匹配
- 所有使用的技术/装置有完整的科技树依赖链
- 所有地理移动在物理上可行
- 零个模糊词，所有效果有具体数值
- 示例：ch82工厂躲藏——灵压消音屏障有完整物理原理（反相灵波干扰）、绝灵近身有量化机制（三尺内灵压真空区，输出衰减40-60%）、地理约束（管道区结构限制）

### 1.5 零分条件（0分）

- 场景核心事件违反任何一条宪法公理（如绝灵之地修真者正常施法无辅助）
- 灵压出现矛盾（同一场景既是"高灵压区"又是"无法感气"）
- 科技树严重跳跃（陆之一在卷一造出卷四才有的装置）
- 地理不可能（从辛国到万象宗"一瞬间"）

## 二、维度二 · Society —— 社会/文化层

### 核心问题

> 这场戏是否体现了修真世界的结构性社会张力？阶级/文化/势力矛盾是否在场？

### 2.1 子因子定义

| 编号 | 子因子 | 含义 | 权重 |
|------|--------|------|------|
| S1 | 修真者傲慢体现 | 修真者对凡人的结构性轻视是否可感知 | 30% |
| S2 | 阶级矛盾 | 上下级/内外门/宗门与散修的权力不对等 | 25% |
| S3 | 文化冲突 | 修真世界观 vs 凡人世界观的碰撞 | 20% |
| S4 | 势力逻辑 | 清洗司/万象宗的行为符合其制度惯性 | 15% |
| S5 | 社会规则一致性 | 社会规则与已建立的世界观不矛盾 | 10% |

### 2.2 子因子评分算法

**S1 修真者傲慢体现**（score 0-1）

```
S1 = 在场修真者的平均傲慢指数 × 行为匹配度
```

- 傲慢指数从character表`arrogance`字段直接读取
- 行为匹配度：
  - 若该修真者在场景中表现出"对凡人能力的系统性低估"→ 匹配度=1.0
  - 若表现出"对凡人过于重视/恐惧"→ 匹配度=0.3（除非有明确叙事理由）
  - 若修真者未与凡人互动 → 该因子N/A，S1用剩余因子重新加权
- 严峰不吃早饭看罗盘→体现"巡查是例行公事，不认为凡人能构成威胁"→匹配度1.0×傲慢0.7=0.7

**S2 阶级矛盾**（score 0-1）

```
S2 = 矛盾体现度 × 权力差清晰度
```

- 阶级矛盾检测规则：
  - 场景中是否有不同阶级角色的互动？（内外门/宗门与散修/修士与凡人）
  - 若有 → 检查权力不对等是否在行为中体现
  - 权力差清晰度：从faction表`internal_strife`和`scale`字段计算
  - 例如：万象宗（超一流，internal_strife=0.8）→ 内部权力差极大

**S3 文化冲突**（score 0-1）

```
S3 = 冲突触点计数 × 每触点深度
```

核心文化冲突触点：
- 修真者用神识/罗盘 vs 陆之一用传感器/频谱分析 → 方法论冲突
- 修真世界"引气修炼=唯一正途" vs 陆之一"走外物证道" → 价值观冲突
- 修真者"古籍=真理" vs 陆之一"古籍=被篡改的数据源" → 认识论冲突
- 每出现一个触点 → +0.25，深度阐释（不只是提一句）→ +0.25/触点

**S4 势力逻辑**（score 0-1）

```
S4 = 行为与势力制度惯性的匹配度
```

检测规则：
- 清洗司行为是否匹配其运作模式？（执事审查/名册/手检，而非"算法扫描/系统判定"）
- 万象宗行为是否符合其结构特征？（内部矛盾/资源掠夺/版本降级）
- 命中术语红线（如"调取监控""系统自动标记""SOP"）→ 每命中一条扣0.3
- 从faction表`type`字段确定势力类型→从concept表查该势力的行为规范→匹配

**S5 社会规则一致性**（score 0-1）

```
S5 = 1.0 - (违反的已建立社会规则数 × 0.25)
```

- 如："万象宗外门弟子可以随意出入宗门禁地"——与外门地位矛盾

### 2.3 维度总分

```
Society = (S1×0.30 + S2×0.25 + S3×0.20 + S4×0.15 + S5×0.10) × 100
```

### 2.4 满分条件（100分）

- 在场修真者表现出精确匹配其傲慢指数的结构性轻视
- 至少一对阶级关系有明确的权力不对等互动
- 至少一个文化冲突触点在场景中有深层展开
- 势力行为完全匹配其已建立的制度惯性
- 零社会规则矛盾
- 示例：ch67擦肩而过——严峰（通脉境，傲慢0.7）例行巡查时吃早饭，罗盘在眼前失效8秒浑然不觉——体现修真者对凡人能力的结构性低估

### 2.5 零分条件（0分）

- 修真者行为完全不像修真者（用现代警察/官僚逻辑替代修真世界逻辑）
- 出现术语红线（"调监控""算法扫描""SOP""标记库"）
- 清洗司运作方式与现代官僚机构无异
- 阶级关系完全未体现或严重歪曲

## 三、维度三 · Character —— 角色/心理层

### 核心问题

> 每个在场角色的行为是否符合其动机/人格/情绪状态？情绪变化是否有可追溯的转折？

### 3.1 子因子定义

| 编号 | 子因子 | 含义 | 权重 |
|------|--------|------|------|
| C1 | 行为-动机一致性 | 角色行为可从其motivation字段推导 | 30% |
| C2 | 人格锚点匹配 | 行为匹配角色"一句话定义" | 25% |
| C3 | 情绪转折合理性 | 情绪变化有触发事件+过渡 | 20% |
| C4 | 绝不允许行为检查 | 无触发角色红线 | 15% |
| C5 | 角色功能明确 | 每个出场角色有不可替代的叙事功能 | 10% |

### 3.2 子因子评分算法

**C1 行为-动机一致性**（score 0-1）

```
C1 = Σ(每个角色的一致性得分) / 在场角色数
```

单个角色一致性：
- 从character表读`motivation`字段
- 场景中该角色的每个决策和行动 → 能否从motivation推导？
- 若能 → 该决策得分1.0
- 若需要额外假设才能推导 → 0.5
- 若与motivation矛盾且无叙事解释 → 0.0
- 最终 = 决策得分均值

**C2 人格锚点匹配**（score 0-1）

```
C2 = Σ(每个角色的人格匹配度) / 在场角色数
```

人格锚点速查（来自宪法第八章）：

| 角色 | 锚点 | 匹配检测 |
|------|------|----------|
| 严峰 | 被体制恐惧压垮的普通人+修真者傲慢（愤怒羞耻>>恐惧） | 行为是否有"愤怒羞耻"驱动？是否对凡人技术不屑？ |
| 林岳 | 偏执的完美主义者/猎人（强迫症触发，享受狩猎） | 是否有"观察→判断→兴趣"的模式？是否享受过程而非结果？ |
| 孟炽 | 职业化执行者（不傲慢不恐惧，只执行标准流程） | 行为是否只是"执行流程"？是否无情绪波动？ |
| 陆之一 | AI工程师（经典物理视角，猥琐发育，永远不正面战斗） | 是否用"工程思维"？是否回避正面冲突？ |
| 小真 | 硅基协处理器（v0.5起威胁建模，情感通过"不理解"体现） | 输出是否为数据/推演？"情感"是否以"不理解"方式表达？ |

- 匹配度评分：高度匹配→1.0 / 部分匹配→0.6 / 行为不符合锚点→0.2

**C3 情绪转折合理性**（score 0-1）

```
C3 = 1.0 - (无触发转折数 × 0.25)
```

- 检测场景中每个角色的情绪状态变化
- 每次情绪变化必须有：
  - 明确的触发事件（外部或内部）
  - 合理的过渡时间（不能"突然"从平静跳到暴怒，除非有极端触发）
- 缺少触发或过渡 → 扣0.25/次
- "他突然感到一阵悲伤"——无触发，扣0.25
- "他看到老猫的尸体，停了三秒，然后后退"——触发明确（尸体），过渡合理（三秒停顿），不扣分

**C4 绝不允许行为检查**（score 0-1）

```
C4 = 1.0 - (触发红线数 × 0.5)
```

红线速查（来自宪法第八章）：

| 角色 | 禁止行为 |
|------|----------|
| 严峰 | 调监控/逐帧看/查数据库/用算法 |
| 林岳 | 系统标记/算法扫描/非人格化清除 |
| 陆之一 | "运气好"逃过一劫 |
| 小真 | "魔法般"觉醒/"突然觉醒" |

- 命中一条红线扣0.5
- 命中两条以上 → C4=0

**C5 角色功能明确**（score 0-1）

```
C5 = 1.0 - (功能性冗余角色数 × 0.3)
```

- 功能性冗余 = 角色在场景中的功能可被其他在场角色完全替代
- 例如：两个"传达信息"的功能角色同时出场

### 3.3 维度总分

```
Character = (C1×0.30 + C2×0.25 + C3×0.20 + C4×0.15 + C5×0.10) × 100
```

### 3.4 满分条件（100分）

- 每个角色的每个行为可直接追溯到其motivation
- 每个角色行为精确匹配人格锚点
- 所有情绪变化有明确触发+合理过渡
- 零红线触发
- 每个在场角色有不可替代的叙事功能
- 示例：ch29病历——陆之一从虚弱→茫然→冷静，触发链完整（诊断→确认为不可修炼→开始思考替代路径）；苏晚晴克制的情感表达符合其人格；主治医生的功能性角色明确（诊断传达）。

### 3.5 零分条件（0分）

- 陆之一"运气好"逃过一劫（触发红线）
- 小真"突然觉醒"（触发红线）
- 严峰"调取监控录像逐帧筛查"（触发红线+术语红线）
- 角色行为与motivation完全矛盾且无叙事解释
- 情绪转折全无触发（角色的情绪完全由剧情需要驱动）

## 四、维度四 · Plot —— 情节/因果层

### 核心问题

> 这场戏的因果关系是否严密？伏笔是否推进/回收？节奏与章内位置是否匹配？

### 4.1 子因子定义

| 编号 | 子因子 | 含义 | 权重 |
|------|--------|------|------|
| P1 | 因果链完整性 | 每个事件有前因后果，无"凭空发生" | 30% |
| P2 | 伏笔操作质量 | 埋设/推进/回收伏笔的质量 | 25% |
| P3 | 赢面公式验证 | 对抗场景的赢面经过10因子验证 | 20% |
| P4 | 节奏匹配度 | 场景字数/事件密度与叙事功能匹配 | 15% |
| P5 | 信息差设计 | 读者知道vs角色知道的设计是否有效 | 10% |

### 4.2 子因子评分算法

**P1 因果链完整性**（score 0-1）

```
P1 = 1.0 - (无因事件数 × 0.2 + 断链事件数 × 0.3)
```

- "无因事件"：场景中某事件的发生，在前文（本场景或前置场景）找不到原因 → 每件扣0.2
- "断链事件"：事件A按因果应导致B，但场景直接跳到了C → 每处扣0.3
- 检测方式：提取场景的所有事件→对每个事件反向查找前因→对每个事件正向验证后果
- 注意：故意的省略不属于"断链"（如章末钩子——故意不给后果），只要标记为"待后续"

**P2 伏笔操作质量**（score 0-1）

```
P2 = (有效伏笔操作分) / (伏笔操作数)
```

伏笔操作分类评分：
- 有效埋设：新伏笔有明确的回收条件+合理的前置暗示 → 1.0
- 有效推进：伏笔状态从planted→developing，增加了新信息 → 0.8
- 有效回收：伏笔在合理时机回收，且回收方式满足埋设时暗示的条件 → 1.0
- 伪回收：声称回收但实际与埋设条件矛盾 → 0.0
- 僵尸伏笔：埋设后长期不推进也不回收 → 0.3（按存在时长累计扣分）

数据来源：`schema.sql` foreshadow表，status/planted_ch/revealed_ch字段

**P3 赢面公式验证**（score 0-1）

```
P3 = combat.py CombatBalance.check_conflict() 的结果映射
```

仅在场景含对抗/冲突时评估，否则N/A（用剩余因子重新加权）：
- Verdict.PASS → 1.0
- Verdict.BORDERLINE → 0.6（需要叙事技巧支撑）
- Verdict.FAIL（主角不可能赢）→ 0.2
- Verdict.FAIL（敌人太弱）→ 0.3

**P4 节奏匹配度**（score 0-1）

```
P4 = 1.0 - |实际事件密度 - 期望事件密度| / 期望事件密度
```

- 期望事件密度由场景的"叙事功能"决定：
  - 实战核心 → 高密度（1事件/300字）
  - 揭示/信息 → 中密度（1事件/500字）
  - 过渡/铺垫 → 低密度（1事件/800字）
  - 文戏/对话 → 中低密度（1事件/600字）
- 实际事件密度 = 场景字数 / 场景中的独立事件数

**P5 信息差设计**（score 0-1）

```
P5 = 有效信息差层数 × 0.34（上限3层）
```

信息差层类型：
- 读者知道角色不知道的（如ch67：读者知道罗盘失效8秒的原因，陆之一不知道）
- 角色A知道角色B不知道的（如ch82：林岳不知道陆之一已破译大阵部分结构）
- 读者和角色都不知道但即将揭示的
- 每层有效的信息差 → +0.34

### 4.3 维度总分

```
Plot = (P1×0.30 + P2×0.25 + P3×0.20 + P4×0.15 + P5×0.10) × 100
```

若P3 N/A（无对抗场景），则：
```
Plot = (P1×0.38 + P2×0.31 + P4×0.19 + P5×0.12) × 100
```

### 4.4 满分条件（100分）

- 所有事件有明确前因后果，无断链
- 每个伏笔操作有效（埋设/推进/回收质量均为1.0）
- 对抗场景赢面通过combat.py验证（PASS）
- 事件密度精确匹配叙事功能
- 至少2层有效信息差
- 示例：ch82伏击——老猫死亡（ch81）→陆之一前往确认（因果链）；屏障+绝灵近身首次实战（科技树回收）；林岳"观察→判断→兴趣"（猎人模式）；读者知道陆之一采样灵波指纹而林岳不知道（信息差）

### 4.5 零分条件（0分）

- 场景核心事件"凭空发生"——无前因，仅靠"剧情需要"
- 声称回收伏笔但条件与埋设矛盾
- 对抗场景赢面为FAIL且无合理解释
- 零信息差设计（所有角色和读者知道一样多）

## 五、维度五 · Theme —— 主题/哲学层

### 核心问题

> 这场戏是否服务于"外物证道"？是否体现"文明碰撞"？是否遵循三段式创新？

### 5.1 子因子定义

| 编号 | 子因子 | 含义 | 权重 |
|------|--------|------|------|
| T1 | 外物证道服务度 | 场景是否强化"不修炼→靠外物"的核心主题 | 30% |
| T2 | 文明碰撞体现 | 经典物理世界观 vs 修真世界观的碰撞 | 25% |
| T3 | 三段式创新 | 新发明遵循"经典原型→L场对接→量化装置" | 20% |
| T4 | 反模板化 | 避免通用修仙模板（飞升/天道意志/混沌珠） | 15% |
| T5 | 量化思维 | 陆之一用"工程/物理"思维而非"修炼"思维解决问题 | 10% |

### 5.2 子因子评分算法

**T1 外物证道服务度**（score 0-1）

```
T1 = 陆之一的行为匹配"外物证道"的程度
```

检测规则：
- 陆之一的行动是否依赖"外物"（装置/知识/计算）而非"自身修炼"？
  - 完全依赖外物 → 1.0
  - 外物为主+自身为辅 → 0.8
  - 自身为主+外物为辅 → 0.4
  - 纯自身能力（如"突然觉醒"）→ 0.0 且触发C4红线
- 陆之一未出场时 → N/A，用T2-T5重新加权
- 外物类型加分：从concept表查该外物的classification（theory/component/integration/tactical），integration类和tactical类比纯theory类加分更高（因为体现了"从理论到装置"的完整路径）

**T2 文明碰撞体现**（score 0-1）

```
T2 = 碰撞触点计数 × 每触点深度
```

文明碰撞触点：
- 修真者用灵场感知 vs 陆之一用传感器检测 → 感知方式碰撞
- 修真者"古籍=真理" vs 陆之一"古籍=数据" → 认识论碰撞
- 修真者"引气修炼" vs 陆之一"外物替代" → 方法论碰撞
- 修真者"灵气是神秘能量" vs 陆之一"灵气=灵子BEC" → 本体论碰撞
- 每出现一个且有深层对抗 → +0.25，上限1.0

**T3 三段式创新**（score 0-1）

仅当场景涉及新发明/装置使用时评估，否则N/A：

```
T3 = 三段完整度
```

- 场景中是否展示或暗示：
  1. 经典物理原型（如"EM谐振腔→符文=波导"）→ 0.33
  2. L场现象对接（如"灵纹谐振效应→反相灵波"）→ 0.33
  3. 量化装置（如"输出3.2千瓦/灵玉消耗=每小时0.03息"）→ 0.34
- 三段都满足 → 1.0
- 公理七要求：每个创新必须有这三段

**T4 反模板化**（score 0-1）

```
T4 = 1.0 - (模板化触发词数 × 0.2)
```

模板化触发词库：
- `飞升` `天道意志` `混沌珠` `顿悟` `机缘巧合` `天选之人`
- `气运` `天劫` `灵根觉醒` `血脉觉醒` `上古传承`
- 每命中一个扣0.2
- 注意："天道"在本作中指"灵场+经典物理场耦合方程组"，此为正确用法，不扣分

**T5 量化思维**（score 0-1）

```
T5 = 陆之一的思考模式匹配度
```

检测规则（只在陆之一出场/POV时评估）：
- 陆之一的思考/对白中是否有：
  - 数值估算（"距离约7米""灵压约0.003息"）→ +0.3
  - 概率评估（"成功概率约60%"）→ +0.2
  - 工程约束（"电池续航2小时""屏障能耗"）→ +0.25
  - 系统分析（"三重耦合因素""信噪比"）→ +0.25
- 无以上任何 → 0.0

### 5.3 维度总分

```
Theme = (T1×0.30 + T2×0.25 + T3×0.20 + T4×0.15 + T5×0.10) × 100
```

若T1 N/A（陆之一未出场），则：
```
Theme = (T2×0.36 + T4×0.36 + T5_若适用或T3×0.28) × 100
```

若T3 N/A（无新发明）：
```
Theme = (T1×0.37 + T2×0.31 + T4×0.19 + T5×0.13) × 100
```

### 5.4 满分条件（100分）

- 陆之一的行为完全依赖外物，零修炼依赖
- 至少3个文明碰撞触点有深层展开
- 若涉及新发明：三段式完整呈现
- 零通用修仙模板词
- 陆之一的思考充满数值/概率/工程约束
- 示例：ch82伏击——屏障+绝灵近身=外物证道；林岳的"灵波追踪"vs陆之一的"频谱分析"=文明碰撞；屏障v2.0的三段式（EM谐振腔→灵纹谐振反相→续航量化）在ch61-65已建立

### 5.5 零分条件（0分）

- 陆之一"顿悟"某功法（直接修炼）
- 出现通用修仙模板（飞升/天劫/机缘巧合）
- 新发明无经典物理原型，凭空"神奇地解决了"
- 陆之一用修真者思维而非工程思维

## 六、维度六 · Aesthetic —— 情感/审美层

### 核心问题

> 读者会感到什么？情感温度够不够？画面感/节奏感/语言质感如何？

### 6.1 子因子定义

| 编号 | 子因子 | 含义 | 权重 |
|------|--------|------|------|
| A1 | 情感温度 | 场景的情感基调是否清晰/传达是否有效 | 30% |
| A2 | 武戏画面感 | 动作场景的节奏/空间感/张力 | 25% |
| A3 | 文戏细腻度 | 对话/独白/内心活动的质感 | 20% |
| A4 | 讽刺/幽默层次 | 荒诞感/反讽/黑色幽默 | 15% |
| A5 | 感官丰富度 | 视觉/听觉/触觉/温度描写的多样性 | 10% |

### 6.2 子因子评分算法

**A1 情感温度**（score 0-1）

```
A1 = 情感基调明确度 × 传达有效性 × 情绪层次数归一化
```

- 情感基调明确度：场景是否定义了情绪基调（从章节规划的"情绪基调"字段读取）→ 有定义=1.0，无定义=0.5
- 传达有效性：场景中的描写/对话/动作是否有效传达了该基调 → 人工评估（引擎标记，人类确认）
- 情绪层次数归一化：
  - 单一情绪（纯恐惧/纯紧张）→ 0.5
  - 复合情绪（紧张中带荒诞，如ch67严峰边吃早饭边巡查）→ 0.8
  - 多层次（表面的冷静→底层的计算→最深处的恐惧/羞耻）→ 1.0

**A2 武戏画面感**（score 0-1）

仅武戏场景评估，否则N/A：

```
A2 = (空间清晰度×0.3 + 节奏变化×0.3 + 身体感×0.2 + 后果可视化×0.2)
```

- 空间清晰度：读者能否在脑中构建场景空间？（ch82管道区："金属结构散射灵波""管道区内微弱的灵压异常"）→ 0-1
- 节奏变化：动作描写中是否有快慢交替？（追逐→停顿→再追逐）→ 0-1
- 身体感：是否有身体层面的细节？（呼吸/汗水/肌肉/温度/触觉）→ 0-1
- 后果可视化：动作的后果是否清晰？（"绝灵近身→修真者灵场相干度下降→输出衰减40%"）→ 0-1

**A3 文戏细腻度**（score 0-1）

仅文戏/对话场景评估，否则N/A：

```
A3 = (对话自然度×0.35 + 潜文本×0.35 + 节奏呼吸×0.30)
```

- 对话自然度：角色语言是否匹配其身份/教育/情绪状态 → 0-1
- 潜文本：对话表面意思之下的真实含义（"别急着看。先好起来。"——苏晚晴的真正意思是"我担心你"）→ 0-1
- 节奏呼吸：对话中是否有停顿/沉默/打断——像真正的对话那样 → 0-1

**A4 讽刺/幽默层次**（score 0-1）

```
A4 = 有效讽刺/幽默触点数 × 每触点深度（上限1.0）
```

本作特有的讽刺/幽默类型：
- 猫鼠游戏荒诞感（修真者在凡人面前失效而不自知）：0.3/触点
- 黑色幽默（老猫的猫罐头散落在尸体旁）：0.25/触点
- 结构性反讽（万象宗的"阵法"本质是饮鸩止渴）：0.25/触点
- 技术性幽默（"符文=集成电路"——修真者几千年来没发现的事）：0.2/触点

**A5 感官丰富度**（score 0-1）

```
A5 = 出现的感官通道数 / 5
```

感官通道：
- 视觉（光影/颜色/形状）
- 听觉（声音/响度/音色/沉默）
- 触觉/体感（温度/质感/振动）
- 灵场感知（灵压/灵波/灵子流——本作特有）
- 嗅觉/味觉
- 每出现一个有效通道 → +0.2
- "有效"指该通道在场景中有叙事或氛围功能，而非仅仅提及

### 6.3 维度总分

```
Aesthetic = (A1×0.30 + A2×0.25 + A3×0.20 + A4×0.15 + A5×0.10) × 100
```

若A2 N/A（非武戏）：Aesthetic = (A1×0.40 + A3×0.27 + A4×0.20 + A5×0.13) × 100
若A3 N/A（非文戏）：Aesthetic = (A1×0.38 + A2×0.31 + A4×0.19 + A5×0.12) × 100

### 6.4 满分条件（100分）

- 多层次复合情感（至少3层），每层有具体传达手段
- 武戏：空间清晰+节奏有快慢交替+身体感强+后果可量化
- 文戏：对话自然+潜文本丰富+有呼吸感
- 至少3种不同的讽刺/幽默类型
- 5种感官通道全部有效使用（包括灵场感知——本作独有优势）
- 示例：ch67擦肩而过——情感多层次（紧张+荒诞+后怕）；讽刺层次（严峰边吃早饭边巡查，罗盘失效8秒浑然不觉）；灵场感知通道（灵波脉冲/罗盘AGC/屏障反相场）；空间清晰（旧车间→旧仓库→外墙转角）

### 6.5 零分条件（0分）

- 情感基调未定义或传达完全失败
- 武戏写成"他很快，敌人也很快，然后他赢了"
- 文戏全为功能性对话（纯信息传递，无人物性格/潜文本）
- 零感官描写（"白描"过头变成"无描"）
- 讽刺/幽默为负数（强行搞笑破坏氛围）

|----------|------|----------|
| 叙事功能 | 含"实战""动作""战斗""躲藏""伏击""追逐" | 武戏 |
| 叙事功能 | 含"揭示""确认""诊断""分析""发现" | 揭示 |

识别优先级：武戏 > 文戏 > 揭示 > 过渡（若多标签匹配，取最高优先级）

| 场景类型 | World | Society | Character | Plot | Theme | Aesthetic |
|----------|-------|---------|-----------|------|-------|-----------|

| **揭示** | 20% | 15% | 20% | 20% | 15% | 10% |

### 7.3 权重递变规则

场景不一定纯粹是一种类型。当场景含多类型特征时：

```
最终权重 = 主要类型权重 × 0.7 + 次要类型权重 × 0.3
```

识别方式：
- 主要类型：优先级最高的匹配类型
- 次要类型：优先级第二高的匹配类型（若存在）

### 7.4 阶段上下文权重修正

|------|----------|

注意：阶段修正是在场景类型权重之上的二次加权。

## 八、总分计算公式

### 8.1 基本公式

```
场景总分 = Σ(Wd × Sd) / Σ(Wd)
```

其中：
- `Wd` = 维度d的最终权重（场景类型权重 × 阶段修正系数）
- `Sd` = 维度d的评分（0-100）

### 8.2 维度可用性处理

若某维度的核心子因子全部N/A（如文戏场景中World维度全部N/A），则：

```
该维度不参与加权，权重分配给最相关的维度
```

N/A判定规则：
- 维度中所有子因子都标记为N/A → 维度N/A
- 至少1个子因子有值 → 维度参与计算，N/A子因子用剩余子因子重新归一化

### 8.3 维度间联动惩罚

某些低分组合触发额外扣分：

| 联动条件 | 额外扣分 | 原因 |
|----------|----------|------|
| World<30 且 Plot>80 | 总分×0.85 | 物理不成立但情节"成立"——伪成立 |
| Character<30 且 Aesthetic>80 | 总分×0.85 | 角色崩坏但写得"好看"——绣花枕头 |
| Theme<20 且 陆之一出场 | 总分×0.80 | 核心主题缺失 |
| Society<10 且 有修真者-凡人互动 | 总分×0.85 | 社会维度真空 |

### 8.4 评分等级

| 总分范围 | 等级 | 含义 |
|----------|------|------|
| 90-100 | S | 出版级——六个维度全部自洽 |
| 75-89 | A | 优秀——少数维度需微调 |
| 60-74 | B | 合格——存在可修复的逻辑/角色问题 |
| 40-59 | C | 需修改——至少一个维度有结构性问题 |
| 0-39 | D | 不可用——核心设定冲突或角色崩坏 |

### 8.5 温度带（补充指标）

除总分外，引擎输出**温度带**（场景的情感温度范围）：

```
温度 = 场景的情绪基调 → 映射到 [-5, +5]
```
