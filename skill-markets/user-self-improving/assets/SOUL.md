# SOUL.md (personal)

> **Personal style / tone / communication preferences** — opt-in. Tells the
> agent about *your* style. Does NOT replace `AGENTS.md` / `CLAUDE.md` /
> `.trae/rules/*.md` (those are rule files the agent loads at session start).
>
> See [SKILL.md §6](../SKILL.md#6-personal-workspace-files-opt-in) for the
> distinction.

## Usage

- **Write here:** personal tone ("be concise", "avoid emojis unless I ask"),
  communication style ("explain reasoning before code"), response shape
  ("always end with action items").
- **Don't write here:** team conventions (those go in `AGENTS.md` / repo rules),
  project-specific facts (those go in the project), tool gotchas (those go in
  `TOOLS.md`).
