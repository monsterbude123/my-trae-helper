## 3. 样式说明

### 布局

- 布局方式: CSS Grid（Header + Sidebar + Main + Footer 四区）
- Header: 60px 固定高度
- Sidebar: 200px 固定宽度
- Main: 1fr 自适应
- Footer: 40px 固定高度

### 响应式断点

| 断点 | 宽度 | 布局变化 |
|------|------|---------|
| mobile | < 768px | 侧边栏收起为汉堡菜单，卡片单列 |
| tablet | 768-1024px | 侧边栏显示，卡片双列 |
| desktop | > 1024px | 侧边栏显示，卡片双列/三列 |

### 层级关系

```
Header (z-index: 100)
  └─ 下拉菜单 (z-index: 200)
Sidebar (z-index: 50)
Main (z-index: 10)
  └─ 卡片 (z-index: 20)
     └─ 弹窗 (z-index: 300)
Footer (z-index: 50)
```

## 6. 数据字段推导（供 fullstack-contract-writer 参考）

从线框图和交互推导的前端数据需求：

| 字段 | 类型 | 来源 | 用途 |
|------|------|------|------|
| items[] | Array | API | 卡片列表渲染 |
| item.id | string | API | 详情跳转参数 |
| item.imageUrl | string | API | 卡片图片 |
| item.title | string | API | 卡片标题 |
| item.description | string | API | 卡片描述（如有） |
| loading | boolean | 前端状态 | 骨架屏显示 |
| error | string\|null | API/前端 | 错误提示 |

> fullstack-contract-writer 基于此推导完善 api-contracts.md 的接口字段定义。
