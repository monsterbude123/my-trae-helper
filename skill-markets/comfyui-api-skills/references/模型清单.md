# 模型参考手册

> 所有推荐模型的完整规格、下载链接、文件路径、兼容性说明。

## 目录结构

```
ComfyUI/
├── models/
│   ├── checkpoints/          基础模型（FLUX、SDXL、SD1.5）
│   ├── loras/                LoRA 适配器
│   ├── controlnet/           ControlNet 模型
│   ├── clip/                 T5、CLIP-L 文本编码器
│   ├── clip_vision/          CLIP 视觉编码器
│   ├── ipadapter/            IP-Adapter 模型
│   ├── instantid/            InstantID 模型
│   ├── insightface/          人脸分析模型
│   ├── facerestore_models/   人脸修复（GFPGAN、CodeFormer）
│   ├── ultralytics/bbox/     检测模型
│   ├── upscale_models/       放大模型
│   └── diffusion_models/     视频扩散模型（Wan、LTX、Hunyuan）
└── custom_nodes/
    └── ComfyUI-AnimateDiff-Evolved/models/  动作模块
```

## 基础模型（Checkpoints）

### FLUX.2 [dev]（写实首选，2026 年 3 月新出）

- **下载**：https://huggingface.co/black-forest-labs/FLUX.2-dev
- **文件**：`flux2-dev.safetensors`（约 32GB）
- **路径**：`models/checkpoints/`
- **配套需求**：
  - T5 编码器：`t5xxl_fp16.safetensors` → `models/clip/`
  - CLIP-L：`clip_l.safetensors` → `models/clip/`
  - VAE：`ae.safetensors` → `models/vae/`
- **显存**：24GB+（FP16 / BF16）、12GB（FP8）
- **特色**：4MP、32B 参数、多参考图（最多 10 张）、NVFP4/NVFP8 加速
- **注意**：使用 NVFP4 需 PyTorch cu130（`torch.version.cuda == '13.0'`）

### FLUX.1-dev（久经验证）

- **下载**：https://huggingface.co/black-forest-labs/FLUX.1-dev
- **文件**：`flux1-dev.safetensors`（23.8GB）
- **路径**：`models/checkpoints/`
- **配套需求**：T5 + CLIP-L + VAE（同 FLUX.2）
- **显存**：16GB+（FP16）、10GB（FP8）
- **特色**：写实最佳，生成较慢。使用 `--fp8_e4m3fn-unet` 省显存

### FLUX Kontext（角色迭代编辑）

- **下载**：https://huggingface.co/black-forest-labs/FLUX.1-Kontext-dev
- **路径**：`models/checkpoints/`
- **用途**：无需重训即可编辑已有角色图
- **显存**：12-32GB

### RealVisXL V5.0（快速 SDXL 写实）

- **下载**：https://civitai.com/models/139562/realvisxl-v50
- **文件**：`RealVisXL_V5.0.safetensors`
- **路径**：`models/checkpoints/`
- **显存**：8GB+
- **特色**：速度与画质平衡较好

### Juggernaut XL Ragnarok

- **下载**：https://civitai.com/models/133005/juggernaut-xl
- **路径**：`models/checkpoints/`
- **显存**：8GB+
- **特色**：多样化人物主体

### Qwen-Image 2.0（2026 年新出）

- **下载**：https://huggingface.co/Qwen/Qwen-Image-2.0
- **路径**：`models/checkpoints/`
- **显存**：24GB+
- **特色**：排版、2K 分辨率、分层编辑、20B MMDiT、Apache 2.0

### Z-Image

- **下载**：https://huggingface.co/ali-vilab/Z-Image
- **文件**：Base（约 12B 参数）、Turbo（蒸馏 8 步）
- **路径**：`models/checkpoints/`
- **显存**：12-16GB+
- **特色**：非蒸馏高质量（Base）/ 快速（Turbo）

## 身份保持模型

### InstantID

- **IP-Adapter**：https://huggingface.co/InstantX/InstantID
  - 文件：`ip-adapter.bin` → `models/instantid/`
- **ControlNet**：同仓库
  - 文件：`ControlNetModel/diffusion_pytorch_model.safetensors` → `models/controlnet/`
  - 重命名：`instantid_controlnet.safetensors`
- **依赖**：InsightFace `antelopev2` 模型
- **额外显存**：8GB+
- **配套基础模型**：SDXL

### IP-Adapter FaceID Plus V2

- **下载**：https://huggingface.co/h94/IP-Adapter-FaceID
- **文件**：
  - `ip-adapter-faceid-plusv2_sd15.bin` → `models/ipadapter/`
  - `ip-adapter-faceid-plusv2_sd15_lora.safetensors` → `models/loras/`
- **额外显存**：6GB+
- **特色**：比 InstantID 快，自动加载配对 LoRA

### IP-Adapter SDXL

- **下载**：https://huggingface.co/h94/IP-Adapter
- **文件**：
  - `ip-adapter_sdxl_vit-h.safetensors` → `models/ipadapter/`

### PuLID Flux II

- **下载**：https://huggingface.co/guozinan/PuLID
- **文件**：`pulid_flux_v0.9.1.safetensors` → `models/pulid/`

## 性能优化工具

### Nunchaku v1.2.0（SVDQuant）

- **下载**：https://github.com/mit-han-lab/nunchaku
- **特色**：2-3 倍加速、显存省 3.5 倍、INT4、RTX 20+ 系列、FLUX 最低 4GB

### WaveSpeed（FBCache）

- **集成**：ComfyUI 节点
- **特色**：最高 2 倍加速、首块缓存、可搭配 LoRA

### TeaCache

- **集成**：ComfyUI 节点
- **特色**：约 30% 加速、无需训练、最适合视频生成

### NVFP4 / NVFP8

- **需求**：PyTorch cu130
- **特色**：RTX 50 系列 NVFP4 提速 3 倍、显存省 60%；任意英伟达 NVFP8 提速 2 倍、显存省 40%
