# 游戏剧情策划

把**游戏创意**翻译成**可执行的剧情设计文档**。引擎无关，适用于 WebGAL / Ren'Py / Unity 等任何视觉小说引擎。

> 核心铁律：**角色宪法是唯一信息源**。每个角色只有一份宪法（Want/Fear/年龄/性格/外形/创伤/弧光），所有资产（立绘/音色/弧线/关系链）派生自宪法，不独立设计。

## 前置条件

- Phase 0 引擎已确认（WebGAL / Ren'Py / Unity 等目标引擎明确）
- game-production-kit 已加载（game-genre-visual-novel 或同类 VN 技能已激活）

## 骨架流程

1. Want/Fear 推导 → 角色三轴明确
2. 角色宪法 → story-design.md § 人物设计 落盘
3. 剧情树 → 三幕结构 + 分支/结局
4. 场景列表 → 逐场景（触发条件/可调查物/恐怖陷阱）

## 约束

- **角色宪法是唯一信息源**：立绘/音色/弧线/关系链全部派生自宪法，Phase 2 资产不独立设计
- 剧情分支用 flag/变量驱动，禁止硬编码 if-else
- 每次落盘递增版本号（内容变更必递增 vN → vN+1）

## 质量清单

- [ ] 3 个核心角色 Want / Fear / 弧光全部明确
- [ ] 角色宪法落盘 story-design.md § 人物设计
- [ ] 剧情树覆盖全部分支（至少 1 真结局 + 2 坏结局）
- [ ] 场景列表覆盖全部剧情分支
- [ ] 伏笔矩阵：每条伏笔有 种植→发展→收割
- [ ] 多结局触发条件明确（flag 变量名定义）
- [ ] 恐怖陷阱：第一章至少 1 个致命陷阱

## 流程骨架

```
1. 剧情树状图 → 全局结构可视化（共通线→分支→结局）
2. 逐节面试 → 核心概念 → 标题 → 角色 → 场景 → 谜题 → 结构 → 伏笔 → 多结局
3. 落盘 → story-design.md（全部确认后一次性写入）
```

## 面试 10 节

| # | 节 | 关键输出 |
|---|------|---------|
| 1 | 核心概念 | 2-3 句话概括核心冲突与情感基调 |
| 2 | 标题提案 | 3-4 个标题选项 |
| 3 | 人物设计 | 逐个角色：姓名、年龄、性格、Want、Fear、外观、与案件关系 |
| 4 | 场景列表 | 每个场景：名称、触发条件、可调查物、恐怖陷阱、关键对话 |
| 5 | 谜题设计 | 线索分布表、解锁条件、变量名定义 |
| 6 | 三幕结构 | 25% 共通线 / 50% 发展 / 25% 结局 |
| 7 | 伏笔矩阵 | 伏笔→种植→发展→收割 |
| 8 | 环境叙事 | 用画面传递信息而非文字说明？幻象选择？ |
| 9 | 多结局 | 早期坏结局 / 中期坏结局 / 真结局 / 普通结局 / 最终坏结局 |
| 10 | 恐怖气氛 | 早期分布恐怖事件，标注触发点/效果/致命性 |

## 铁律

- 逐节面试、逐节确认，确认前不写文件
- 选择用 flag/变量驱动，不是硬编码分支
- 恐怖陷阱早期分布，第一章就要有致命陷阱
- 对话格式由目标引擎的脚本技能决定，story-design.md 只写"谁说了什么"，不写引擎特定的标记语法
- 旁白与角色对话明确区分（格式由引擎脚本技能定义）
- **每次落盘时更新版本号**：v1, v2, v3 ... 递增。内容修改必递增（角色属性/场景变更/剧情调整），微小修改不递增（错别字/格式）

## 版本与变更日志

story-design.md 文件头部必须包含版本号和变更日志：

```markdown
# Story Design — {游戏标题}
版本: v{N} | 最后变更: YYYY-MM-DD

## 变更日志
| 版本 | 时间 | 变更内容 | 影响范围 |
|------|------|---------|---------|
| v3 | 07-08 | Elise 发色红→深棕 | 立绘: elise_*.png |
| v2 | 07-07 | 新增场景 archives_01 | 背景: bg_archives_01.png |
| v1 | 07-05 | 初始角色宪法 | 全部素材 |
```

> 影响范围写法：`立绘: {角色}_*.png` / `背景: bg_{场景}_*.png` / `TTS: {场景}.wav` / `脚本: {场景}.txt` / `全部素材`。准确，不写泛称。

## 结局分类标准

| 类型 | 触发时机 | 情感落点 | 示例 |
|------|----------|----------|------|
| 早期坏结局 | 第1-2章 | 猝不及防的致命陷阱 | 回头→被追逐→死亡 |
| 中期坏结局 | 第3-4章 | 累积错误的必然结果 | flag不足→线索断裂 |
| 真结局 | 终章 | 洞察真相的圆满感 | 全线索+全flag |
| 普通结局 | 终章 | 表面解决的残缺感 | 部分线索 |
| 最终坏结局 | 终章 | 放弃/失败的虚无感 | 主动放弃调查 |
