# 电脑控制（Computer Use）

> 让 AI 在你授权下理解并操作电脑界面，完成办公提效、重复任务、开发与验收等场景。

## 使用场景

| 场景 | 说明 |
|------|------|
| **办公提效** | 信息查询与整理、表单填写、数据录入 |
| **完成重复性任务** | 录入指定范围信息、按模板填写、逐项核对状态 |
| **开发与验收** | 直接把验收要求设为目标，AI 开发后用电脑控制验证应用并反馈 |

## 权限范围（macOS / Windows）

| 权限 | 作用 |
|------|------|
| **辅助功能** | 模拟键盘和鼠标操作 + 读取界面元素 |
| **屏幕录制** | 截取屏幕内容以理解当前界面 |

> 仅授予一项时，AI 只能用对应能力。执行任务时鼠标移动会显示"TraeWork 正在操作电脑"遮罩。

## 启用步骤

1. **设置 → 电脑控制** → **启用电脑控制** 区域 → **安装** 按钮
2. (macOS) 弹窗授权 **辅助功能** + **屏幕录制** → 系统设置中授权
3. 重启 TRAE Work 生效

> 启用后"电脑控制"插件自动装好，可在插件市场查看详情。

## 手动引用插件

启用后，对话输入框手动添加"电脑控制"插件，让 AI 更准确识别并执行电脑操作任务。

## "始终允许"机制

- 单次确认面板可勾选 **始终允许**，后续操作该应用不再请求确认
- 该应用加入 **设置 → 电脑控制 → 始终允许的应用** 列表，可随时移除
- 若不想对每个新应用逐一确认：开启 **始终允许操作应用** 开关

## 指令模板

| 场景 | 模板 |
|------|------|
| **填写表单** | 打开[表单]，根据已打开的[参考文件]填写[指定字段]。完成后检查必填项和页面提示，不要点击提交，停留在提交页等待我确认。 |
| **按模板填写内容** | 打开[模板]，复制一份并命名为[文件名]。根据[数据来源]替换模板中的[指定字段]，其他不要修改。完成后保存文件并停留在结果页，不要发送或发布。 |
| **验证核心流程** | 启动[应用]，按"[步骤1] > [步骤2] > [步骤3]"执行一次操作，检查最终是否出现[预期结果]。如果失败，停止操作，并向我说明失败步骤、页面提示和复现过程。不要删除数据或对外发布。 |
| **开发并验收功能** | 在当前项目中实现[功能要求]。完成后启动应用，并通过电脑控制按"[验收步骤]"验证[预期结果]。如果验证失败，记录页面提示和复现步骤，定位并尝试修复一次，然后重新验证。仍未通过时停止操作并向我说明结果，不要删除现有数据或对外发布。 |
