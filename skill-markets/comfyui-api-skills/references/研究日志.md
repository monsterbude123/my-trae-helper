## 2026 年 3 月新动态

### FLUX.2 [dev] 发布

- **日期**：2026-03-15
- **来源**：https://huggingface.co/black-forest-labs/FLUX.2-dev
- **关键参数**：32B 参数、4MP、24GB+ 显存
- **特色**：
  - 多参考图（最多 10 张）
  - NVFP4/NVFP8 加速
  - 与 PuLID Flux 2 协同

**应用场景**：
- 极致写实人像
- 多角度角色一致性
- 商业级图像

### LTX-2.3 发布

- **日期**：2026-03-10
- **来源**：https://huggingface.co/Lightricks/LTX-2.3
- **关键参数**：4K、24GB+、提供 GGUF
- **特色**：
  - 4K 音视频同步生成
  - Day-0 ComfyUI 支持
  - 竖屏原生

**应用场景**：
- 4K 短剧
- 竖屏短片
- 商业级视频

### PuLID Flux 2 发布

- **日期**：2026-03-12
- **来源**：https://huggingface.co/guozinan/PuLID-FLUX-2
- **关键参数**：24-40GB 显存
- **特色**：
  - 自动模型检测
  - 兼容 WaveSpeed
  - 支持 FLUX.2 Klein + Dev

**应用场景**：
- FLUX 2 角色身份保持
- 与 LoRA 组合

### Rodin3D Gen-2

- **日期**：2026-03-08
- **类型**：合作伙伴节点
- **特色**：图像生 3D、PBR 材质

### ComfyUI v0.17.2

- **日期**：2026-03-15
- **核心更新**：
  - App 模式
  - Nodes 2.0 Vue
  - FluxKVCache 节点
  - 全 GPU 异步卸载（提速 40%）
  - 默认启用固定内存

## 2026 年 2 月新动态

### Wan 2.6 进一步完善

- **修复**：
  - 早期版本的"眨眼不一致"
  - 长视频的"时间漂移"
- **新增**：
  - 内置音频生成
  - 内置口型同步
  - 1080p 输出

### NVFP4 性能优化

- **关键提示**：需要 PyTorch cu130
- **加速**：3 倍（RTX 50）
- **显存节省**：60%
- **验证**：

```bash
python -c "import torch; print(torch.version.cuda)"
# 应该是 13.0 才支持
```

### FramePack SageAttn 集成

- **加速**：30%
- **兼容性**：所有 FramePack 用户
