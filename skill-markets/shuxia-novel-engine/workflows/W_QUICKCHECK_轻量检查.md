# W_QUICKCHECK · 轻量一致性检查

> 场景: "我刚写完一句话/一段话/一个场景，它违反宪法吗？"
> 触发: 写作过程中随时调用。不阻塞创作流。

---

## 与重量级检查的区别

| | W_QUICKCHECK | check.py / evaluate.py |
|---|---|---|
| 触发时机 | 写作中随时 | 阶段门禁时 |
| 检查范围 | 当前场景/段落 | 全项目 |
| 响应速度 | 即时（AI 语言判断） | 需要引擎运行 |
| 阻塞性 | 不阻塞，仅提醒 | PASS/CONDITIONAL/FAIL |
| 详细度 | 一句话 | 完整报告 |

---

## 流程

### 输入

用户说:
- "这段有问题吗？"
- "检查一下这个设定"
- "这里违宪吗？"
- "帮我快速扫一眼"

或者 AI 在写完一段后主动自检。

### 检查项（三项快速扫描）

```
1. 宪法红线:
   - 对照项目的 forbidden 关键词列表
   - 这段文字中是否出现了 forbidden_methods 的任何关键词？
   例: 林岳的 forbidden_methods = ['监控','数据库','算法标记']
   → 如果段落中有"林岳调取了监控录像" → ❌ 违规

2. 术语合规:
   - 是否使用了废弃术语？
   例: 废弃术语 = ['SOP','杀毒软件']
   → 如果段落中有"SOP" → ⚠️ 应改为"宗门规矩"

3. 角色行为锚点:
   - 角色的行为是否符合其 allowed_methods？
   - 角色的情绪转变是否 Δ ≤ 1 级（情感阶梯）？
   例: 主角突然从"疏离"跳到"信任" → ⚠️ 需要中间状态
```

### 输出

```
=== 快速检查 ===

✅ 宪法红线: 通过（无 forbidden_methods）
✅ 术语合规: 通过（无废弃术语）
⚠️  角色行为: 注意——主角从第3段的"警惕"直接跳到第5段的"信任"，
    缺少"试探"和"认可"两个中间状态。建议在第4段插入一次试探性互动。

总结: 1 个注意项，可继续写作
```

### 规则

- 永远不阻塞写作流——即使是 ❌ 也只是"建议暂停检查"
- 如果发现 3 个以上问题 → 建议"需要更全面的 W_BRAINSTORM"
- AI 在写完每个场景后应主动执行一次 W_QUICKCHECK
