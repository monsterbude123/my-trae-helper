## §1 extend(视频延长)

### §1.1 适用 + 输入
```
典型触发:"把视频再延 N 秒" / "动作做到一半完成" / "镜头拉到更远"
必需输入:原视频 + 续写时长(3/6/10s) + 续写意图
主代理自动:抽末帧 + vision 输出 keyframe_report.json + 提取色调/节奏摘要
```

### §1.2 Prompt 6 条要点
```
1. 显式承接:"延续自原视频末帧的最后姿态..."
2. 主体 LOCKED:(KEEP IDENTITY LOCKED)
3. 仅描述变化:不复述原视频已有
4. 节奏延续:"保持末段速度曲线"
5. 时间切片新基准:prompt 时间从 [00:00] 开始
6. 风格继承:不在续写段引入新美术词
```

### §1.3 完整示例

#### 示例 1 — 剧情续写

```yaml
【平台】MiniMax H3   【模式】V2V-extend
【输入】原视频:女生站街角咖啡店门前,镜头半身。
【输出时长】6s

# integrated_multimodal_description
[00:00 - 00:02] 接续原视频末帧:
  中近景,女生 A 抬手指向橱窗,
  镜头跟踪手指方向(继承原视频 track),
  20 岁女生 + 浅色风衣 + 围巾 + 微微笑容(KEEP IDENTITY LOCKED)。
[00:02 - 00:05] 手指指向橱窗的同时目光跟随:
  镜头 shift 焦点到橱窗内陈列,侧光在橱窗玻璃形成暖色反射。
[00:05 - 00:06] 女生 A 收回手指,镜头回到半身,收束于期待表情。

# overall_soundscape
脚步声 + 衣物摩擦 + 环境城市底噪不变。
```

#### 示例 2 — 动作尾巴补完

```yaml
【平台】MiniMax H3   【模式】V2V-extend
【输入】原视频:主角转身到一半被截断。
【输出时长】4s

# integrated_multimodal_description
[00:00 - 00:02] 接续原视频末帧:
  中景,主角继续转身 180 度面向镜头,镜头静止,
  (KEEP IDENTITY LOCKED),表情:完成转身 + 决意。
[00:02 - 00:04] 主角面向镜头站稳,风衣随动作摆动,
  镜头轻微推近 + 表情定帧。

# overall_soundscape
脚步声随转身节奏 + 衣物摩擦 SFX + 城市底噪。
```

## §2 first-last-frame(首尾衔接)

### §2.1 适用 + 输入
```
典型触发:"两视频中间加转场" / "白天过渡到夜晚" / "A 的尾连 B 的头"
必需输入:首帧(A 末帧) + 尾帧(B 首帧) + 中间过渡时长(2/4/6s)
主代理自动:对比两帧差异 + 生成中间过渡描述 + 标注过渡方式
```

### §2.2 Prompt 6 条要点
```
1. 不描述起点/终态(已给)
   ✅ "光线从左上角到右下角渐次偏移"
2. 时间切片 = 平均切 N 段(4s 切 3 段;6s 切 4 段)
3. 镜头稳定:避免大幅 cut
4. 调色过渡:"光线 5500K 渐变到 3200K" / "饱和度由 80% 提升到 100%"
5. 环境音平滑:首帧音渐出 + 尾帧音渐入 + 转场 SFX
6. BGM 保持或 cross-fade:不做突变
```

### §2.3 完整示例

```yaml
【平台】MiniMax H3   【模式】V2V-first-last-frame
【输入】首帧:白天街景 / 尾帧:夜晚街景
【输出时长】4s

# integrated_multimodal_description
[00:00 - 00:01] 状态过渡起点:
  从首帧构图出发,整体曝光缓慢降低,镜头缓慢 push-in,
  街道路面保留,街灯暖光的边缘反射开始出现。
[00:01 - 00:02] 状态过渡深化:
  天空色温 6500K(冷)向 3200K(暖)渐变,
  路灯逐步点亮形成暖色光斑,镜头保持 push-in。
[00:02 - 00:04] 状态过渡落位:
  画面饱和度整体提升,阴影加深形成夜晚质感,
  构图最终落到尾帧构图,镜头减速到静止。

# overall_soundscape
白天鸟鸣 / 车流缓慢淡出,夜虫鸣叫声渐次淡入,
街灯开启的微电流声 SFX。
```

## §3 edit(视频编辑)

### §3.1 适用 + 输入
```
典型触发:"风格化为赛博朋克" / "背景换成海边" / "色调改黑白" / "加下雨转场" / "服装改蓝"
必需输入:原视频 + 修改目标(明确"改什么")
可选输入:修改范围(整段/部分时段) + 强度(light/medium/strong)
主代理自动:抽关键帧(vision) + 锁定核心元素 + 分类保留/修改清单
```

### §3.2 Prompt 6 条要点
```
1. 显式"保留 X / 修改 Y":MUST 列出哪些元素必须保持
2. 修改目标具体(不可抽象):
   ❌ "改好看"
   ✅ "改色调:色温 5500K,饱和度 95%"
3. 修改强度:light / medium / strong 显式标注
4. 分时段标注修改范围:"[00:02-00:05] 此段开始应用新色调"
5. 触发条件:若需 SFX / 时间点触发器显式写
6. 不破核心:主体 / 核心道具 / 镜头轨迹 不变
```

### §3.3 完整示例

#### 示例 1 — 风格化(赛博朋克)

```yaml
【平台】MiniMax H3   【模式】V2V-edit
【输入】原视频:现实街景   【输出时长】6s(与原视频同)

# integrated_multimodal_description
[00:00 - 00:02] 保持原视频构图 + 主体(KEEP IDENTITY LOCKED),
  镜头沿原轨迹,开始应用赛博朋克色调:
    - 品红 + 青绿色调主导
    - 霓虹灯元素在画面边缘淡入
    - 饱和度提升到 95%。
[00:02 - 00:04] 风格深化:
    - 街灯全转为 LED 霓虹
    - 主光源 5500K → 4500K(暖紫)
    - 雨滴在玻璃表面缓慢出现。
[00:04 - 00:06] 赛博朋克风格稳定:
    - 完整霓虹氛围 + 雨滴形成光线反射
    - 收束在霓虹最亮的静态构图。

# overall_soundscape
原人声保留,环境切换:
雨声 + 霓虹电流声 + 远处电子音乐底噪。
```

#### 示例 2 — 元素替换(服装颜色)

```yaml
【平台】MiniMax H3   【模式】V2V-edit
【输入】原视频:女生穿红衣 / 修改目标:服装改蓝
【输出时长】8s(与原视频同)

# integrated_multimodal_description
[00:00 - 00:02] 保持原视频所有元素(主体 LOCKED),
  服装色由红(HSL 0,80,50)过渡到蓝(HSL 220,80,50),
  镜头 / 构图 / 动作全部继承。
[00:02 - 00:05] 服装色转换完成,
  画面色相整体轻微旋转(避免突兀),
  背景 / 道具保持原状。
[00:05 - 00:08] 服装完全蓝色(KEEP IDENTITY LOCKED),
  镜头继续原视频末段动作,
  收束于稳定蓝色服装镜头。

# overall_soundscape
原视频环境音 + SFX 全部保留。
```

## §4 三子模式决策树

```
用户输入:视频 + 意图
  ├─ "续 / 延长 / 后面"        → extend(§1)
  ├─ "拼接 / 过渡 / 转场"+ 2 段 → first-last-frame(§2)
  ├─ "改 / 替换 / 风格"        → edit(§3)
  └─ 模糊没说清                → 默认 edit(低风险)+ 询问用户具体意图
```
