# 项目操作注意的事项

- MUST: 使用具有文件查询功能的mcp查询文件的时候，必须忽略掉.gitignore明确标记的文件，否则文件树太大会瞬间击穿上下文。
- MUST: 修复中遇到脏逻辑 → 记录提醒，方便后续代码治理。
- MUST: 简易单文件细碎的操作任务先整合，再去做。
- MUST: 简易多数量的文件级隔离的任务（数量大于3），先编排，最低3个并发做。
- MUST: 每次用户指导下做了一个新的系统的程序化的复杂流程，要主动的提示用户是否固化工作流到workflows
- MUST: 优先考虑git bash 执行sh
