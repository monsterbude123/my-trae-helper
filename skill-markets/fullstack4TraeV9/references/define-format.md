# Define 阶段格式规范

> 合并 Proposal + Plan + Closure，单文件 ≤ 80 行。

---

## 模板

```markdown
# {变更名称}
> 来源: {Intake 定位卡}
> 状态: draft

## Why
{1-2 句动机，为什么要做这个变更}

## Capabilities
| # | 能力 | 优先级 | 描述 |
|---|------|:---:|------|
| 1 | {能力名} | P0 | {一行描述} |

## Non-Goals
- {明确不做什么}
- {明确不做什么}

## Design
**方案**: {选择的架构方案}（{选择理由，1 句}）

{如果 ≥ 2 个方案 → 对比表}

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| A   | ...  | ...  | ✅ 选择 |
| B   | ...  | ...  | ❌ 放弃 |

## Tasks
- [ ] {任务 1}
- [ ] {任务 2}

## Closure（P0 业务闭环）
- [ ] {闭环步骤 1}
- [ ] {闭环步骤 2}

## Out of Scope
- {明确不做}
```

---

## 约束

| 约束 | 值 |
|------|-----|
| 总行数 | ≤ 80 行 |
| Capabilities | ≤ 5 项 |
| Tasks | ≤ 20 项 |
| Closure | ≤ 5 步 |
| 方案对比 | 仅 ≥ 2 方案时触发 |
