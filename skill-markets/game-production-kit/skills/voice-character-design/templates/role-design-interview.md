# 角色音色设计 — 面试式提问清单

> **不要直接给 prompt** ——先问清楚这 7 类问题，再推导。

## 流程

```
Step 1: 用这张表的"问题"问用户/作者
Step 2: 把答案填到 character-voice-card.md
Step 3: 按 5 维推导 + 30-60 词 instruct 模板
Step 4: 配置数值参数
Step 5: 协调检查
```

## 1. 基础信息

- [ ] 角色中文名？
- [ ] 角色英文/拼音 ID？（用 snake_case，不要用中文）
- [ ] 性别？（male / female / androgynous）
- [ ] 年龄？（影响声带成熟度）
- [ ] 角色身份（用来推断气质）？
- [ ] 出场量：1 句 / 几十句 / 上百句？

## 2. 人设（驱动声音）

> 这些不直接进 prompt，但**决定了 5 维怎么调**。

- [ ] Want（渴望）是什么？
- [ ] Fear（恐惧）是什么？
- [ ] 性格 3 个关键词？
- [ ] 外形 1-2 句？
- [ ] 关键场景情绪曲线？（日常 → 高潮 → 结局）

## 3. 五维声学

> 每维必须**明确**。参考 [01-five-axes.md](../references/01-five-axes.md)。

| 维度 | 问题 | 答案 |
|------|------|------|
| 年龄 | 声带成熟度？ | |
| 性别/气质 | 男性/女性/中间？气质？ | |
| 共鸣 | 胸/头/咽/鼻？ | |
| 语速 | 慢/中/快？停顿模式？ | |
| 音调 | 平/升/降/起伏？ | |

## 4. 数值参数

- [ ] 角色希望稳定还是多样？
  - 稳定 → temperature 0.65-0.7
  - 多样 → temperature 0.8-0.85
- [ ] 单条对白平均字数？
  - < 20 字 → max_new_tokens = 200
  - 20-40 → 280
  - 40-80 → 380
- [ ] seed 选什么？（跨场景固定，建议按角色顺序给：10042, 10043, 10044...）

## 5. 情绪变体

> 同一角色在不同情绪下用不同 instruct。

- [ ] 这角色有几种情绪状态？
  - 单一：跳过
  - 2-3 种：列出情绪 + 关键词
  - 5+ 种：按情绪分组

## 6. 协调

- [ ] 与 BGM 协调：会出现在哪些 BGM 场景？频段是否冲突？
- [ ] 与同剧其他角色区分：5 维差异表
- [ ] 旁白 vs 主角声线：是否需要独立主角声线？

## 7. 第一次生成

- [ ] 准备好 voices.yaml 完整条目
- [ ] 跑 gen_voice.py 生成 3-5 条测试
- [ ] 听一遍 → 微调数值参数或 instruct
- [ ] 锁定最终配置
- [ ] 写进 voices.json 归档

## 反问问题

> 回答不出来时，提示用户：

- "你想让这个角色在 5 秒的听感里给玩家什么第一印象？"
- "他/她说话像谁？（明星 / 角色原型）"
- "情绪激动时声音会怎么变？"
- "他/她有什么独特的口头禅或者说话方式？"
