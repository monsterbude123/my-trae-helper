# AIGC 专区与创作

## 专区入口

https://modelscope.cn/aigc/home

## 创作类型

### 文生图 / 图生图

- 模型：Qwen-Image、Z Image、Stable Diffusion 3.5
- 支持 LoRA 模型叠加
- 输出：PNG

### 文生视频 / 图生视频

- 输出：MP4
- 每次消耗 8-28 魔粒

### 图像编辑

- Qwen-Edit：一句话精准编辑，无需掩码
  - 增删改物体
  - 调整光影
  - 修改背景

### LoRA 模型训练

- 上传图片 → 自动裁剪 + 打标 → 选择基座模型 → 开始训练
- 训练完可直接在 AIGC 专区使用

## FlowBench 工作流

无代码 AI 工作流引擎，支持五大模态：

| 模态 | 输入 | 输出 |
|------|------|------|
| 文本 | Prompt | 文字 |
| 图片 | Prompt/图片 | PNG |
| 视频 | Prompt/图片 | MP4 |
| 音频 | Prompt/文字 | WAV |
| 3D | Prompt/图片 | GLB |

```
入口：https://modelscope.cn/aigc/workflows
```
