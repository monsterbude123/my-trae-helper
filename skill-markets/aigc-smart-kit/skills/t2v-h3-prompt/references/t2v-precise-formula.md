# T2V 7 维度精确化公式 — 完整指南

> **目的**:MiniMax H3 / Hailuo T2V(纯文字)在 prompt 抽象时跑偏率极高。本文档是 **T2V 唯一公式** = 7 个维度全部命中。
>
> **适用范围**:`t2v-h3-prompt` 子 skill 调用时,主代理按本文件填空。
> **不适用**:I2V(图生视频) — 由 `i2v-h3-prompt` 接管,有图参考时主体/场景可省略。

---

## §1 为什么需要精确化公式

```
T2V 没有图参考 → 模型 0 基础创造 → 任何抽象词都会让模型自由发挥

抽象词 → 模型自由发挥 → 跑偏
精确词 → 模型按描述执行 → 命中预期

反例:
  ❌ "一个美丽的女子走在街上"(4 个抽象词:美丽/女子/走/街)
  ✅ "20 岁东方少女,白色一字肩蕾丝连衣裙,白色蝴蝶结发饰与珍珠串,
      蓝眼睛瓷白肌肤粉润唇,巴黎街角清晨自然光下走在鹅卵石路面"

  抽象 prompt → 模型选 30 岁白人女性 + 红裙 + 沙滩
  精确 prompt → 模型按描述生成东方少女 + 白裙 + 巴黎
```

## §2 7 维度精确化清单(全部 MUST 命中)

### 维度 1 — 主体(年龄 + 族裔 + 外貌 + 服装 + 配饰 + 表情)

| 字段 | 必含 | 反例 | 正例 |
|------|-----|------|-----|
| 年龄 | 具体数字或范围 | ❌"年轻" | ✅"20 岁" |
| 族裔 | 国籍/地域/族裔特征 | ❌"东方"(模糊) | ✅"东方少女"(明确亚洲) |
| 外貌 | 3-5 个具体特征 | ❌"美丽" | ✅"蓝眼睛 + 瓷白肌肤 + 粉润唇" |
| 服装 | 完整描述 | ❌"好看的衣服" | ✅"白色一字肩蕾丝连衣裙" |
| 配饰 | 关键配饰 | ❌"戴了配饰" | ✅"白色蝴蝶结发饰 + 珍珠串" |
| 表情 | 具体情绪词 | ❌"笑着" | ✅"温柔微笑" / "眼神专注" |

**主角锁定模板**(T2V 第一句):
```
"一名 [年龄] [族裔] [外貌 3-5 词] [服装描述] [配饰] [表情]"
```

### 维度 2 — 场景(地点 + 时段 + 天气 + 关键元素)

| 字段 | 必含 | 反例 | 正例 |
|------|-----|------|-----|
| 地点 | 具体地点或风格 | ❌"在街上" | ✅"巴黎街角" |
| 时段 | 早/午/黄昏/夜 | ❌"白天" | ✅"清晨自然光" |
| 天气 | 晴/阴/雨/雪 | ❌"好天气" | ✅"晴朗 + 柔和阳光" |
| 关键元素 | 1-3 个视觉锚点 | ❌"有建筑" | ✅"身后 19 世纪公寓 + 鹅卵石路面" |

### 维度 3 — 构图(景别 + 视角 + 构图方式)

| 字段 | 必含 | 反例 | 正例 |
|------|-----|------|-----|
| 景别 | 远/中/近/特 | ❌"好看的景别" | ✅"半身景别" |
| 视角 | 平视/俯视/仰视 | ❌"(省略)" | ✅"平视视角" |
| 构图方式 | 黄金分割/中心/对角 | ❌"(省略)" | ✅"黄金分割构图" |

### 维度 4 — 镜头运动(类型 + 振幅 + 速度)

继承 i2v-h3-prompt/camera-grammar.md 三件套:

| 维度 | 取值 | 默认 |
|------|-----|-----|
| **类型** | push in/out, pan, truck, tilt, arc, tracking, static, shake, POV | - |
| **振幅** | small / large | medium(省略) |
| **速度** | slow / fast | normal(省略) |

**T2V 特化**:没有图暗示节奏,**必须显式写** — 不能省略。
完整词表 → [camera-grammar.md](../i2v-h3-prompt/camera-grammar.md)

### 维度 5 — 渲染(光照 + 调色 + 质感)

| 字段 | 必含 | 反例 | 正例 |
|------|-----|------|-----|
| 光照 | 类型 + 方向 + 强度 | ❌"好看的光" | ✅"柔和自然光 + 侧光 45°" |
| 调色 | 暖/冷 + 饱和度 | ❌"好看的色调" | ✅"暖色调 + 低饱和" |
| 质感 | 胶片/数字/特殊 | ❌"(省略)" | ✅"胶片颗粒感" / "数字锐利" |

### 维度 6 — 动作(每时段独立 + 时序词)

**时序词清单**(精确化必用):
- 开始:`Initially` / `At the start`
- 推进:`then` / `next` / `while`
- 收束:`finally` / `at the end` / `as the shot closes`

**T2V 特化**:每段独立动作,不能"一镜到底写一长串"。
反例:
```
❌ "她走在街上,看橱窗,买了一杯咖啡,继续走回家"(4 个动作挤一段)
✅ [00:00-00:02] 中近景, 主角停下脚步, 目光看向橱窗
   [00:02-00:05] 中近景, 主角抬手指向橱窗, 镜头推进
   [00:05-00:08] 中近景, 主角转头面向镜头微笑, 镜头拉远
```

### 维度 7 — 声音(每段触发音 + 整体音景)

| 层 | 内容 | 写法 |
|----|------|-----|
| 动作触发音 | 走路 / 翻页 / 倒水 | "高跟鞋在鹅卵石上的哒哒声" |
| 环境音 | 风 / 雨 / 街道 | "远处钟声 + 街角咖啡机声" |
| 整体音景 | overall_soundscape 段 | 一句总结所有环境音 |

## §3 完整 T2V Prompt 示例(主角声明 + 时间切片 + 三段式)

### §3.1 输入(用户文字)

```
"一个女孩在巴黎逛街"
```

### §3.2 抽象 prompt(❌ 反例 — 不要这样写)

```yaml
integrated_multimodal_description: A girl walks in Paris and looks at the
shops. The camera follows her.
overall_soundscape: City sounds.
non_diegetic_music: Soft music.
```

### §3.3 精确化 prompt(✅ 正例 — 7 维度全部命中)

```yaml
【平台】MiniMax H3
【模式】T2V(纯文字,无图)
【时长】8s  【分辨率】768P  【画幅】3:4

# integrated_multimodal_description
[00:00 - 00:02]
中近景, 一名 20 岁东方少女站在巴黎街角清晨自然光下, 身穿白色一字肩蕾丝连衣裙,
头扎白色蝴蝶结发饰与珍珠串, 蓝眼睛瓷白肌肤粉润唇, 表情温柔微笑, 身后是 19 世纪
米色公寓与鹅卵石路面。镜头以平视视角黄金分割构图拍摄, holds a static shot。
[00:02 - 00:05]
中近景, 少女向右缓慢走向咖啡店橱窗, 目光跟随手指指向橱窗内的马卡龙,
the camera pushes in with small amplitude at slow speed。
[00:05 - 00:08]
中近景, 少女转头面向镜头, 表情绽放出惊喜微笑, 镜头以
the camera pulls out with small amplitude at slow speed 收束于笑容定帧。

整体要求:少女全程面部清晰, 服装配饰不变, 镜头节奏舒缓, 表情自然过渡。

# overall_soundscape
鹅卵石上的高跟鞋声轻柔响起, 远处巴黎钟声回荡, 偶有自行车经过的铃铛声,
背景是咖啡机研磨的低沉嗡鸣。

# non_diegetic_music
手风琴主旋律的法国香颂, 节奏舒缓, 在 [00:05-00:08] 段加入竖琴点缀,
以柔和的渐弱收束。
```

### §3.4 验证清单(对照 §2 七维度)

| 维度 | 命中字段 | 正例关键词 |
|------|---------|-----------|
| 1 主体 | 6/6 | 20 岁东方少女 + 蓝眼睛瓷白肌肤粉润唇 + 白色蕾丝连衣裙 + 蝴蝶结珍珠串 + 温柔微笑 |
| 2 场景 | 4/4 | 巴黎街角 + 清晨自然光 + 19 世纪米色公寓 + 鹅卵石 |
| 3 构图 | 3/3 | 中近景 + 平视视角 + 黄金分割 |
| 4 镜头 | 3/3 | holds a static shot + pushes in small slow + pulls out small slow |
| 5 渲染 | 3/3 | 清晨自然光 + 暖色调 + 胶片质感(隐含) |
| 6 动作 | 3/3 | 站立 → 走向橱窗 → 转头微笑 |
| 7 声音 | 3/3 | 高跟鞋声 + 钟声 + 香颂手风琴 |

## §4 7 维度速查表(主代理填空模板)

```
[T2V 7 维度填空模板]
维度1(主体): 一名 __岁 __族裔__, __外貌1, 外貌2, 外貌3__, 身穿 __服装__, 头戴 __配饰__, 表情 __情绪__
维度2(场景): __地点__ + __时段__ + __天气__, __关键元素1, 关键元素2__
维度3(构图): __景别__ + __视角__ + __构图方式__
维度4(镜头): the camera __运动类型__ with __振幅__ amplitude at __速度__ speed
维度5(渲染): __光照__ + __调色__ + __质感__
维度6(动作): [时间段] __景别__, 主角 __动作__, __精确化__
维度7(声音): __动作触发音__ + __环境音__ + __BGM__

自检 PASS 条件: 7 个维度全部有具体词,无任何"好看 / 美丽 / 高级感"等抽象词
```

## §5 T2V 失败模式速查(精确化未命中)

| 现象 | 根因 | 修复指令 |
|------|------|----------|
| 主角变成白人 / 男性 / 年龄错 | 维度 1 未命中族裔/年龄/性别 | 加具体族裔 + 年龄 + "少女" |
| 场景跑到沙滩/森林/随机 | 维度 2 未命中地点/时段 | 加具体地名 + 时段 + 天气 |
| 景别忽远忽近 | 维度 3 未命中 | 每段显式写景别 |
| 镜头乱晃 | 维度 4 未命中三件套 | 加 "holds a static shot" 或三件套 |
| 调色偏冷/偏暖失控 | 维度 5 未命中 | 加 "warm tones + soft natural light" |
| 动作挤一段 | 维度 6 未切时间片 | 按 [00:00-00:02] / [00:02-00:05] / [00:05-00:08] 切 |
| 音画脱节 | 维度 7 顺序错 | description → soundscape → music 顺序 |
| 模型创造新配角 | 维度 1 主角未在第一句锁定 | 第一句必须"一名 [年龄] [族裔] ..." |
| 服装中途变化 | 维度 1 服装未全程声明 | "整体要求"段加 "服装全程不变" |

## §6 与兄弟 skill 的边界

```
本公式(T2V 精确化)接管:
  ✅ T2V 7 维度精确化清单
  ✅ T2V 完整示例 + 反例库
  ✅ T2V 失败模式 + 修复指令

i2v-h3-prompt 接管:
  → I2V(有图)不需要 7 维度全命中 — 图已暗示主体/场景/构图
  → I2V 用 "图是场景"原则,省略维度 1/2/3
  → I2V 必加 must_not_change 锁脸/锁物(T2V 不加)

video-prompt-method(爹)接管:
  → 跨平台方法学(Seedance/可灵也适用)
  → 抽象→具体的通用方法论
  → 不绑 MiniMax H3 平台
```
