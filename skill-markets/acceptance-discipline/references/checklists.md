# §10 统一 Checklist

---

## PR 提交前自检（开发者）

```
═══════════════════════════════════════════
PR Self-Check（提交者本人填写）
═══════════════════════════════════════════

【测试】
[ ] 新代码有对应的单元测试（覆盖率 ≥ 70%）
[ ] 修改的代码路径有集成测试覆盖
[ ] 测试在本地全量通过（< 30s）
[ ] 无 Flaky 测试（连跑 3 次结果一致）
[ ] Mock 完整（无未 mock 的真实网络调用）

【代码质量】
[ ] Lint 0 error
[ ] 类型检查通过（mypy / tsc）
[ ] 无 console.log / print 残留
[ ] 无 TODO/FIXME（除非关联 issue）

【安全】
[ ] 无硬编码密钥 / token
[ ] 无 SQL 字符串拼接
[ ] 用户输入有校验
[ ] 依赖无新增 HIGH CVE

【验收】
[ ] 改动的 UI 路径用 Workflow B 即时验证过
[ ] 改动的 API 用 curl / Postman 验证过
[ ] 修复的 bug 有回归测试
[ ] CHANGELOG 已更新

【文档】
[ ] 复杂逻辑有注释
[ ] API 变更同步更新了 OpenAPI
[ ] README / docs 有同步（如涉及）
```

## 模块发版前（模块 Owner）

```
═══════════════════════════════════════════
Module Release Check（模块 Owner 填写）
═══════════════════════════════════════════

【模块 E2E】
[ ] Workflow A 全量跑过，_diagnosis.md 无 HIGH 异常
[ ] 所有 MEDIUM 异常已有 issue 跟踪
[ ] 模块性能基线对比无 > 10% 退化

【测试质量】
[ ] 模块测试确定性分数 ≥ 99.5%
[ ] 模块测试覆盖率 ≥ 团队阈值
[ ] 无 skip / xfail 不带理由的测试

【安全】
[ ] 模块鉴权矩阵测试通过
[ ] 模块涉及的输入有校验
[ ] 模块依赖无新增 HIGH CVE

【文档】
[ ] 模块 README 更新
[ ] 模块 API 文档更新
[ ] Breaking changes 显式标注

【签字】
[ ] 模块 Owner 签字
[ ] 相关依赖模块 Owner 知会（如涉及接口变更）
```

## 紧急回滚前（On-call）

```
═══════════════════════════════════════════
Emergency Rollback Check（On-call 填写）
═══════════════════════════════════════════

【确认回滚必要】
[ ] 监控告警确认事故
[ ] 影响范围已评估
[ ] 回滚版本已知（最近稳定版 commit hash）

【回滚操作】
[ ] 数据库 migration 回滚脚本就绪（如有 schema 变更）
[ ] 部署回滚命令已准备
[ ] 灰度方案已选择（全量 / 分批）

【回滚后验证】
[ ] 关键路径 API 可访问
[ ] 关键路径 E2E（Workflow B）抽样验证
[ ] 监控指标恢复正常
[ ] 事故复盘 issue 已创建

【事后】
[ ] 24 小时内事故复盘会议
[ ] 复盘报告归档
[ ] 验收体系漏洞补强（如适用）
```

---

## Checklist 的使用纪律

- Checklist 不是装饰，**每一项都要真的去查**，不能"我觉得没问题就打勾"
- Checklist 应该 **Git 版本化**，随团队成熟度演进
- 定期（每季度）review Checklist，删除不再适用的项，新增新踩坑的项
- Checklist 完成后**签字归档**，作为发版证据
