## 零、核心命题

### 0.1 文戏的"好"是什么

文戏的"好"不能用情节逻辑衡量。情节逻辑回答"这件事有没有道理"——这是Plot维度的问题。文戏的温度回答另一个问题：**读者读到这一段时，胸口有没有发热，鼻子有没有发酸。**

一场好的文戏是情感温度的精确传递。不是"冷漠→感动"的跳跃，不是依靠情节转折（死人了、表白了）来强行制造情绪，而是通过微小情绪的累积、关系的渐进变化、对话中未说出口的东西，让温度在读者心里自己升起来。

### 0.2 温度的定义

`
文戏温度 = 读者在阅读过程中体验到的情感热度的峰值 × 体验时长 × 真实性感知
`

- 峰值高但只有一瞬 → 像被烫了一下，不持久
- 峰值不高但持续温热 → 像温水，不深刻
- 峰值高 + 持续 + 读者相信 → **炽热的烙印**

### 0.3 温度与R4六维引擎的关系

本模型是R4六维评估引擎中Aesthetic维度子因子A1（情感温度）的展开设计。R4中A1的评分范围是0-1，本模型输出的温度T（0-100）映射到A1：

`
A1 = T / 100
`

同时，本模型的子组件（情感递进、关系状态转移）部分贡献于Character维度（C3·情绪曲线质量）。

### 0.4 温度带定义

| 温度带 | T值范围 | 读者体验 | 生理标记 |
|--------|---------|----------|----------|
| T-3 冰点 | 0-15 | 纯信息传递，无情感投入 | 无 |
| T-2 微凉 | 16-30 | 隐约的情感意识，尚未投入 | 无 |
| T-1 温 | 31-50 | 情感参与，但保持距离 | 轻微关注 |
| T0 温热 | 51-65 | 情感投入，开始在意角色 | 心头发紧 |
| T1 灼热 | 66-80 | 强烈情感体验，胸口发热 | 胸口发热/眼眶湿润 |
| T2 炽热 | 81-95 | 眼泪/哽咽/需要停顿 | 眼泪/呼吸变化 |
| T3 烙印 | 96-100 | 终身难忘的场景 | 反复回想/身体记忆 |

### 0.5 顶级文戏的共性

分析古今中外被公认为"写得好"的文戏场景，共同特征：

1. **读者不是被告知感情，是被引导到感情的边缘，自己跨过去。**
2. **最有力的情感不在说出口的话里，在没说的话里。**
3. **情感递进是阶梯式的——每个台阶都很小，但很确定。**
4. **关系状态的变化是"不可逆"的——一旦跨过某条线，就回不去了。**
5. **最高的温度往往产生于"失去"与"得到"同时发生的时刻。**

## 一、情感阶梯模型

### 1.1 核心洞见

情感不是跳跃的——"昨晚还是陌生人，今天突然为对方挡刀"是低级写法。真正让读者发热的情感递进是**微小的、渐进的、每一步都在前一步的基础上展开**。

### 1.2 九级情感阶梯

`
Level 0: 疏离 (Estrangement)
    │   定义：完全的陌生人。不关心对方的存在与否。
    │   触发行为：无互动。
    │   读者感受：无。
    │
Level 1: 警惕 (Wariness)
    │   定义：注意到对方，但保持防御距离。
    │   触发行为：观察、评估威胁、不主动接近。
    │   读者感受：轻微紧张。
    │
Level 2: 好奇 (Curiosity)
    │   定义：产生了解对方的意愿，但不行动。
    │   触发行为：旁听、侧面打听、在安全距离观察。
    │   读者感受：轻微期待。
    │
Level 3: 试探 (Tentative)
    │   定义：主动进行低风险的接触。
    │   触发行为：搭话、提出小请求、分享不敏感信息。
    │   读者感受：紧张 + 期待（"他们会聊下去吗？"）。
    │
Level 4: 认可 (Recognition)
    │   定义：确认对方在自己世界中的位置。
    │   触发行为：记住对方的习惯/偏好、调整自己的行为。
    │   读者感受：微暖（"他们开始在意对方了"）。
    │
Level 5: 信任 (Trust)
    │   定义：向对方暴露脆弱或共享风险信息。
    │   触发行为：分享秘密、请求帮助、接受帮助。
    │   读者感受：心头发紧（"这个秘密交给ta了…"）。
    │
Level 6: 共鸣 (Resonance)
    │   定义：不需要解释的理解。对方的存在本身就是安慰。
    │   触发行为：沉默相处不尴尬、一个眼神就懂。
    │   读者感受：胸口发热（"他们是同类"）。
    │
Level 7: 依赖 (Dependence)
    │   定义：对方的缺席会造成明显的情绪/功能缺失。
    │   触发行为：遇到困难第一个想到对方、"如果你不在"的恐惧。
    │   读者感受：眼眶湿润（"别离开"）。
    │
Level 8: 牺牲 (Sacrifice)
    │   定义：为对方放弃重要事物（安全/自由/记忆/生命）。
    │   触发行为：自毁记忆、放弃逃生机会、最后的"谢谢"。
    │   读者感受：眼泪 + 胸口钝痛 + 无法呼吸。
`

### 1.3 递进规则

**规则1·步幅约束**：相邻场景之间的情感级别跳跃 ≤ 1级。
- 允许: L0→L1, L3→L4, L7→L8
- 不允许: L0→L3（跳跃太大，不真实），L2→L5（中间缺少关键递进）

**规则2·触发事件必需**：每级跃迁必须有具体触发事件。不允许"时间久了自然就信任了"。
- 好的触发事件：对方做了一件超出预期的事（苏晚晴独自去古战场采样）
- 不好的触发事件：旁白说"两人渐渐熟悉起来"

**规则3·回落规则**：情感可以在某场景中暂时回落（如L5→L4），但回落幅度≤2级，且回落本身必须是"保护性"的（为回避危险而疏远≠感情倒退）。

**规则4·天花板**：不同关系类型有不同的情感天花板：
- 朋友/导师：L7（依赖）
- 恋人/命运共生：L8（牺牲）
- 交易/功能：L4（认可）

### 1.4 递进质量评分

`
E_score = min(100, 递进步数 × 步幅合规率 × 触发事件质量 × 回落合理性 × 基础分)
`

| 参数 | 说明 | 值域 |
|------|------|------|
| 递进步数 | 场景内跨越的情感阶梯级数 | 0-8 |
| 步幅合规率 | 每次递进步幅≤1级的比例 | 0-1 |
| 触发事件质量 | 触发事件的具体性/真实性 | 0-1 |
| 回落合理性 | 如有回落，回落幅度≤2且动机保护性=1 | 0-1 |
| 基础分 | 常数 | 12.5 |

`
E_score = min(100, steps × compliance × trigger_quality × fallback_reason × 12.5)
`

示例：
- ch29 病历：从"虚弱"→"茫然"→"冷静"在同一个情感域内（都在L3-L4附近），递进步数=1（从接受诊断→用理性框架消化），步幅=1，触发=医生诊断+苏晚晴的拓片，E_score≈12.5
- ch78 陈老之死：从"哀恸"(L7)→"警觉"(L4回落，因为继承秘密后必须进入保护模式)→"沉重"(L6共鸣——和陈老的遗留物产生深度连接)，递进步数=2，但有回落，E_score≈22

每对角色有一个可枚举的状态集合，状态之间的转换需要具体触发事件。关系的"温度"取决于：(1)状态距离（从初态到终态跨越了多少状态），(2)转换的"不可逆性"（跨过某条线后是否还能回去）。

### 2.2 状态定义规范

`
状态 = {名称, 情感层级, 信任度(0-1), 信息共享度(0-1), 依赖度(0-1), 不可逆性(bool)}
`

### 2.6 关系状态距离计算

`
R_distance = Σ(每次状态转移的层级差) / 最大可能层级差
R_score = min(100, R_distance × 触发事件质量均值 × 不可逆转移率 × 100)
`

其中：
- 不可逆转移率 = 不可逆转移次数 / 总转移次数

## 三、对话张力曲线

### 3.1 核心洞见

对话不是信息传递——是权力、情感、信息的三维博弈。**每句台词同时在三个维度改变平衡。** 对话的温度取决于：哪个维度被打破、打破后谁拿到了什么、以及什么没有被说出来。

### 3.2 三维博弈模型

`
维度1·权力轴 (Power): 谁在控制对话的走向？
  - +P: 发起话题/打断/拒绝回答/转移话题
  - -P: 被动回应/被引导/暴露需求
  - 标记：每句话标注权力变化(+1/0/-1)

维度2·情感轴 (Emotion): 真实情感在表层下的流动
  - +E: 暴露脆弱/表达真实感受/非语言暴露（停顿、移开目光）
  - -E: 防御/伪装/刻意平静
  - 标记：每句话标注情感暴露度(+1/0/-1)

维度3·信息轴 (Information): 谁知道什么
  - +I: 给出信息/揭示秘密/让对方知道
  - -I: 藏住信息/误导/沉默
  - 标记：每句话标注信息差变化(+1/0/-1)
`

### 3.3 对话张力评估算法

`
对场景中的每句台词(t_1, t_2, ..., t_n):

1. 三维标注：标注每句话的(ΔP, ΔE, ΔI)
2. 累计曲线：绘制三条累计曲线 P(t), E(t), I(t)
3. 张力峰值：D_peak = max( |P(t)| + |E(t)| + |I(t)| )
4. 转折密度：D_density = 三维变化次数 / 总台词数
5. 未遂维度：是否存在某个维度始终未打破？（如全程权力均势、情感从未暴露）
6. 最终落点：对话结束时的(P_final, E_final, I_final)与开始的(P_0, E_0, I_0)差值
`

### 3.4 对话评分

`
D_score = D_peak × 20 + D_density × 40 + 维度覆盖率 × 20 + 落差感 × 20
`

| 参数 | 说明 | 计算 |
|------|------|------|
| D_peak | 张力峰值 | max(累计绝对值) / 台词数 |
| D_density | 转折密度 | 三维变化次数 / 总台词数 |
| 维度覆盖率 | 三个维度是否都被扰动 | 有变化的维度数/3 |
| 落差感 | 对话前后的状态差 | min(1, Σ|final_i - initial_i|/3) |

### 3.5 顶级对话张力的三种模式

**模式A·情感打破权力**：
- 初始：权力均势，情感隐藏，信息对称
- 转折：一方暴露脆弱(E+)，交出权力(P-)，给出真信息(I+)
- 读者感受：胸口突然发热
- 实例：陈老临终"小心光"——从一个导师的权力位置，交出了"我一辈子没解开的恐惧"。权力全交，情感全暴露。

**模式B·信息破坏平衡**：
- 初始：一方高权力低情感，另一方低权力高情感
- 转折：低权力方说出一个对方不知道的真信息
- 读者感受：紧张 + 担忧（信息会不会被误用？）
- 实例：老猫"别挖太深"——从"供应商"角色跳出，给出不该给的信息。信息+，权力-（暴露了自己知道太多），情感+（暴露了关心）。

**模式C·沉默是最高权力**：
- 初始：有问有答
- 转折：一方选择不回答
- 读者感受：胸口钝痛
- 实例：苏晚晴收到陆之一最后一条消息后，"她没有回复。她删掉了消息。她理解。"——沉默=交出所有权力+情感最大值+信息为零。

## 四、留白的艺术

### 4.1 核心洞见

**不写比写更有力。** 读者的想象力是最好的热源。如果你把所有情感都写出来，读者不需要做任何情感劳动——温度就上不去。

### 4.2 留白的定义

`
留白 = 读者必须在脑中自己完成的环节
`

一个情感事件的完整展开包含：
`
触发 → 感知 → 反应 → 处理 → 理解 → 表达 → 行动
`

如果把这7个环节全部写出来，读者不需要做任何事。但如果省略其中几个环节——比如只写触发和行动，跳过反应/处理/理解——读者必须自己填充"他为什么这么做"。"他什么都没说"的力量大于"他痛苦地说了"。

### 4.3 留白度量化

`
O_count = 省略的环节数（作者没写但读者能自己脑补的）
O_total = 完整链条的环节数（标准=7）
O_ratio = O_count / O_total
`

**最佳区间**：

`
O_ratio < 0.15  → 啰嗦（每个环节都写了，读者无参与感）
0.15 ≤ O_ratio ≤ 0.30 → 及格（略有留白）
0.30 ≤ O_ratio ≤ 0.45 → ★最佳★（读者充分参与但不断裂）
0.45 < O_ratio ≤ 0.60 → 极简（适合特定风格，如海明威式）
O_ratio > 0.60 → 断裂（读者不知道发生了什么）
`

### 4.4 留白质量评估

不是所有省略都是好的留白。好的留白满足：

1. **可脑补性**：读者有足够线索填补空缺（≠作者自己知道但读者完全猜不到）
2. **情感完整性**：省略的环节不影响情感逻辑的完整性
3. **锚点存在**：至少保留触发和行动两个锚点（否则读者根本不知道事件发生了）

**O_score 计算**：

`
O_score = 100 × (O_ratio是否在最佳区间？1:0.5) × 可脑补性 × 锚点完整性
`

其中：
- 最佳区间奖励：O_ratio∈[0.30, 0.45]→1.0，[0.15, 0.30)或(0.45, 0.60]→0.7，其余→0.4
- 可脑补性：0-1
- 锚点完整性：触发存在(0.4)+行动存在(0.4)+至少还有一个中间环节(0.2)

### 4.5 三场景留白分析

**ch29 病历（孤独的温度）**：
`
环节：触发(确诊)→感知(陆之一沉默)→反应(？)→处理(？)→理解(在病历上写字)→表达(？)→行动(翻看苏晚晴带来的拓片)
省略：反应、表达、处理中的"情绪"
O_ratio = 3/7 ≈ 0.43 → ★最佳区间
可脑补性：高（读者完全能想象他独自对着天花板在想什么）
锚点：触发√ 行动√ 理解√
O_score ≈ 100 × 1.0 × 0.95 × 1.0 = 95
`

**ch78 陈老之死（悲伤的温度）**：
`
环节：触发(临终赠器)→感知(陆之一接住)→反应(？)→处理(？)→理解(？)→表达(？)→行动(走出病房对苏晚晴摇头)
省略：反应、处理、理解、表达——四个环节全部跳过
O_ratio = 4/7 ≈ 0.57 → 极简区（但不断裂）
可脑补性：极高（读者全程在心里替陆之一哭）
锚点：触发√ 行动√（摇头=行动，虽然极简）
O_score ≈ 100 × 0.7 × 1.0 × 0.8 = 56

★注意：O_score低并不意味着不好。ch78的留白是刻意为之——在情感最高点，最有力的写法是"什么都不写"。O_score衡量的是"留白的技术质量"，但在温度公式中，ch78的高递进和高关系距离会补偿留白的低"技术分"。
`

**ch79 千年空白（温度困境）**：
`
环节：触发(碳14结果)→感知(跑三遍)→反应(盯着屏幕)→处理(跑模型)→理解(11000年空洞)→表达(？)→行动(贴新纸)
省略：表达（没有写"陆之一震惊了/恐惧了/恍然了"）
O_ratio = 1/7 ≈ 0.14 → 偏低（接近啰嗦边缘）
可脑补性：中（技术过程写得很细，情感处理几乎没有——但这章的目标不是情感温度）
锚点：触发√ 行动√ 但中间很多技术环节
O_score ≈ 100 × 0.5 × 0.6 × 0.8 = 24

ch79的留白不足→温度受限。这是结构性的——夹在两个高峰之间的技术章，留白空间天然小。
`

### 4.6 留白与温度的类型关系

不同温度类型对留白的要求不同：

| 温度类型 | 最佳O_ratio | 原因 |
|----------|------------|------|
| 悲伤(悲伤的温度) | 0.40-0.55 | 最有力的悲伤是读者自己哭的 |
| 孤独(孤独的温度) | 0.35-0.45 | 孤独的感觉需要读者自己感受 |
| 温暖(温暖的温度) | 0.20-0.35 | 需要写够细节才能传递暖意 |
| 释然(释然的温度) | 0.25-0.40 | 需要给角色和读者同步放下 |
| 震撼(冰冷理解的温度) | 0.15-0.30 | 需要信息密度，留白太多=不震撼 |

## 五、温度公式

### 5.1 公式

`
T = T_base + E_gain × R_gain × D_gain × O_gain × 80
`

其中：
- T_base = 场景固有基础温度（0-20），由场景类型决定
- E_gain = 情感递进增益（0-1），由E_score归一化
- R_gain = 关系转移增益（0-1），由R_score归一化
- D_gain = 对话张力增益（0-1），由D_score归一化
- O_gain = 留白增益（0-1），由O_score归一化

**为什么是乘法**：温度来自四要素的共振。如果留白为零（O_gain=0），即使递进、关系、张力都满分，温度也只有基础分。读者不能只在"被告知"的层面接受情感——必须在脑中参与构建。

### 5.2 参数映射

`
T_base = 场景类型基础分
  - 纯情感戏(告别/重逢/告白/死亡): 15-20
  - 混合戏(情感+信息/情感+动作): 10-15
  - 纯信息/动作戏中嵌情感: 5-10
  - 纯信息/纯动作: 0-5

E_gain = E_score / 100
R_gain = R_score / 100
D_gain = D_score / 100
O_gain = O_score / 100
`

### 5.3 完整计算流程

`
输入：场景文本/场景规划
  │
  ├─ 步骤1：识别场景的情感事件链
  │     → 列出所有触发→感知→反应→处理→理解→表达→行动
  │
  ├─ 步骤2：标注情感阶梯
  │     → 场景起点情感层级 L_start
  │     → 场景终点情感层级 L_end
  │     → 递进步数 = L_end - L_start
  │     → 步幅合规率、触发事件质量、回落合理性
  │     → E_score
  │
  ├─ 步骤3：查询关系状态机
  │     → 当前关系状态、目标状态
  │     → 状态距离、触发质量、不可逆转移率
  │     → R_score
  │
  ├─ 步骤4：分析对话张力
  │     → 标注每句台词的(ΔP, ΔE, ΔI)
  │     → 计算D_peak, D_density, 维度覆盖率, 落差感
  │     → D_score
  │
  ├─ 步骤5：计算留白度
  │     → 统计O_ratio
  │     → 评估可脑补性和锚点完整性
  │     → O_score
  │
  ├─ 步骤6：代入温度公式
  │     → T_base = 场景类型基础分
  │     → E_gain = E_score/100
  │     → R_gain = R_score/100
  │     → D_gain = D_score/100
  │     → O_gain = O_score/100
  │     → T = T_base + E_gain × R_gain × D_gain × O_gain × 80
  │
  └─ 步骤7：输出温度 + 温度带 + 诊断建议
`

### 5.4 温度诊断矩阵

当温度不达标时，按以下顺序排查：

| 温度问题 | 可能原因 | 检查项 | 修复方向 |
|----------|----------|--------|----------|
| T<30 | 基础温度太低 | 场景类型是否给出T_base | 确认是否有情感事件在场景中 |
| T<30 | 递进不足 | E_score是否<20 | 检查步幅是否过大或触发事件是否缺失 |
| T<50 | 关系停滞 | R_score是否<40 | 场景内关系状态是否有变化 |
| T<50 | 对话平淡 | D_score是否<30 | 三个维度是否都没有被打破 |
| T<50 | 留白不当 | O_score是否<30 | O_ratio是否在最佳区间外 |
| T>90 | 四要素共振 | 检查是否真实（不是计算bug） | 顶级文戏 |

   - O_ratio = 3/7 ≈ 0.43 → ★最佳区间

**验证**：ch29不是催泪章——它的目的是"确认孤独"。温度刚刚够让读者心头发紧但不会哭。诊断正确。

5. **温度**：
   `
   T_base = 8（信息戏，但开头保持了ch78的余韵——"看了一整天没碰它"）
   T = 8 + (10/100) × (40/100) × (45/100) × (24/100) × 80
     = 8 + 0.1 × 0.4 × 0.45 × 0.24 × 80
     = 8 + 0.1 × 0.0432 × 80
     = 8 + 0.3456
     ≈ 38
   `

**结果**：T≈38 → **T-1 温**（情感参与但保持距离）

**验证**：ch79的温度T=38刚好在"温"带——不是情感高峰，但也不是冰点。温度**恰好够**维持ch78的余韵和ch80的预热之间。

**关键诊断——温度困境的解决方案**：

ch79的设计中有一个精巧的结构：**用"死后的对话"维持关系温度**。虽然关系状态没有正式转移（陈老已死），但陆之一与铜片的互动本质上是在继续和陈老对话——"那个人知道自己留下了什么吗？"这句话的对象不是小真，是陈老。这种"隐性对话"让R_score没有跌到0。

同时，章末钩子（"后天有一次交易"）将老猫推入下一个情感事件的预告——这是预热机制。

**如果T<30会怎样**：ch80（老猫之死）会显得突兀——读者还没有从"技术分析"模式中切换回"情感接收"模式。T=38恰好过线。

## 七、温度设计原则

### 7.1 温度曲线的编排

一部小说不是一条平直的温度线。好的温度编排是：

`
T↑
 │         ∧ ch78                      ∧ 卷五
 │        /  \                        / 
 │       /    \____ch79___           /
 │      /              \  ch80-81  /
 │  ___/ ch29           \/        /
 │ /                             /
 │/_____________________________/→ 章
`

- **峰**（ch78陈老之死）：不可频繁。每卷1-2个T2级峰。
- **坡**（ch29病历）：峰前的累积。坡越多，峰越高。
- **谷**（ch79千年空白）：峰后的冷却。谷的存在让下一个峰有意义。

### 7.2 峰间冷却原则

1. T2（炽热）后至少需要1-2章的T-1/T0（温-温热）冷却
2. 冷却期间，温度**不能跌到T-3（冰点）**——否则读者情感断裂
3. 冷却章应用"隐性对话"或"预热钩子"维持最低温度线

### 7.3 文戏温度联动武戏

文戏温度不是孤立的。一场高温度文戏的余韵可以提升后续武戏的紧张感（读者更在乎角色死活）。反之，一场冷酷的武戏（如ch82伏击，T=-1）需要前置文戏温度来建立"角色值得在乎"。

`
文戏温度 → 读者对角色投入 → 武戏紧张感 → 生死场景的冲击力
`

### 7.4 全书温度纲领（速查）

| 温度级别 | 频率建议 | 典型场景 | 本作实例 |
|----------|----------|----------|----------|
| T3 烙印 | 全书1-2次 | 终极告别/最高牺牲 | 卷五小真人格告别 |
| T2 炽热 | 每卷1-2次 | 重要人物退场/关系完成 | ch78陈老之死 |
| T1 灼热 | 每卷3-5次 | 关系突破/关键对话 | ch80老猫之死(预估) |
| T0 温热 | 持续 | 情感递进/日常共鸣 | ch29病历, ch55小真"陈老邮件" |
| T-1 温 | 信息-情感过渡 | 冷却/预热 | ch79千年空白 |
| T-2 微凉 | 动作-信息为主 | 轻度情感 | ch82伏击(Aesthetic=-1) |
| T-3 冰点 | 纯信息/纯设定 | 无情感事件 | 纯世界观说明章 |

## 八、与六维引擎的接口

### 8.1 Aesthetic维度的A1子因子

R4六维引擎中Aesthetic维度的子因子A1（情感温度）评分：

`
A1 = T / 100
`

R4中A1权重为38%（Aesthetic维度内），Aesthetic维度权重为10%（总分内）。

因此温度对总分的影响：
`
总分影响 = T/100 × 0.38 × 0.10 = T × 0.00038
`

ch78：T=86 → 总分贡献 ≈ 86×0.00038 ≈ 0.033 → 3.3%总分
ch29：T=51 → 总分贡献 ≈ 51×0.00038 ≈ 0.019 → 1.9%总分

### 8.2 Character维度的C3子因子

情感递进质量(E_score)同时贡献于Character维度的C3（情绪曲线质量）：

`
C3 = (E_score/100 × 0.5 + 其他因子 × 0.5)
`

### 8.3 与R8引擎实现的关系

本设计为**规范文档**，代码实现（ngine/drama_narrative.py）将在后续任务中完成。核心实现步骤：

1. 读取场景文本/场景规划
2. 识别情感事件链（NLP或人工标注）
3. 自动计算E_score, R_score, D_score, O_score
4. 代入温度公式输出T
5. 生成温度诊断报告（哪些维度拖后腿？如何修复？）
