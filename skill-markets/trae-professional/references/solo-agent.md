# SOLO Agent

SOLO Agent（原 SOLO Coder，v3.5.56 更名）是面向复杂项目开发的智能体。

## 前置条件

通过界面左上角模式切换按钮，将 TRAE 切换至 **SOLO 模式**。

## 启用

对话输入框左下角 `@` → 智能体菜单 → **SOLO Agent**。

## 编辑配置

鼠标悬浮 SOLO Agent → 配置图标 → "编辑工具" → 配置可调用的自定义智能体、MCP Server 和内置工具。

## 调用自定义智能体

SOLO Agent 默认内置 **Search 智能体**（用于检索和查看文件）。

作为主控智能体，SOLO Agent 在执行复杂任务时自动调用相应智能体，将任务拆分与隔离，让不同智能体在独立上下文中专注处理各自任务。

也可以在提示词中明确指定需调用的智能体。

**配置要求**：创建自定义智能体时，开启"可被其他智能体调用"，设置英文标识名和调用场景描述。

## Plan 模式

适用于中小型功能开发和模块级重构。

流程：
1. 输入 `/` → 选择 `/ Plan`
2. SOLO Agent 分析需求 → 规划任务 → 生成规划文档
3. 确认（可手动编辑或自然语言修改）
4. 按计划逐一执行

## Spec 模式

面向复杂系统级任务。生成三阶段文档组：
- **spec.md** —— 大纲
- **tasks.md** —— 任务列表
- **checklist.md** —— 验收清单

文档存储在 `.trae/specs/` 目录，按任务名称分组。

| 使用场景 | 描述 |
|----------|------|
| 新系统/新模块 0→1 | 从零搭建完整服务、模块或应用 |
| 大规模重构 | 架构级重构或技术栈迁移 |
| 多人协作项目 | Spec 文档作为单一事实来源 |
| 高质量/高稳定性项目 | 核心业务逻辑、支付、安全模块 |
| 长期维护项目 | Spec 文档留存为知识资产 |

启用：输入 `/` → 选择 `/ Spec`。

## 一键导入的官方智能体

| 智能体 | 场景 |
|--------|------|
| UI Designer | 组件库设计、界面优化、设计系统、跨平台适配 |
| Frontend Architect | React/Vue/Angular 架构、状态管理、性能优化 |
| Backend Architect | API 设计、业务逻辑、数据库架构、安全运维 |
| API Test Pro | 契约测试、功能测试、性能测试、安全测试 |
| AI Integration Eng | LLM 集成、推荐系统、智能自动化、模型部署 |
| DevOps Architect | CI/CD、云基础设施、监控、部署自动化、安全合规 |
| Performance Expert | 性能测试、瓶颈分析、系统/代码/数据库/基础设施优化 |
| Compliance Checker | 法律文件审查、法规合规评估、风险识别 |
