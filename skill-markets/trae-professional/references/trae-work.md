# TRAE Work 客户端

TRAE Work 是 AI 原生工作台，提供网页版、桌面版和移动版，设有 Work 与 Code 双模式。

## 三端形态

| 端 | 亮点 |
|----|------|
| 网页版 | 有网络即用、无需安装、开箱即用云端环境、轻量化交互 |
| 桌面版 | 文字/语音/附件/技能多元输入、实时进度展示、对话内预览验收、深度性能优化、独立运行 |
| 移动版 | "按住说话"语音输入、跨设备任务管理、离线自动切云端、三端无缝同步 |

## 网页版

- 有网络即可访问，随时随地启动任务
- 无需下载和安装，提供开箱即用的云端环境
- 任务管理简洁高效，轻量化交互不占用本地资源

## 桌面版

- 支持文字、语音、附件、技能等多元输入
- 实时展示任务进度并自动总结输出
- 对话界面内直接预览成果并完成验收
- 深度性能优化确保 Coding Agent 运行更稳定
- 独立运行，流畅度大幅提升

## 移动版

- 默认支持"按住说话"，无需打字即可下达指令
- 支持文本、附件和快捷指令等多种输入方式
- 统一管理云端和多台电脑中的 TRAE Work
- 支持向不同设备并发派发任务并实时监控
- 设备离线时自动切换至云端执行，任务不中断
- 任务状态移动版、网页版、桌面版之间无缝同步

## 三端联动

共享同一套账号体系和任务数据，任务信息实时在三端全量同步。

## Work & Code 双模式

| 模式 | 面向用户 | 场景 |
|------|----------|------|
| Work 模式 | 产品经理、数据分析师、运营等非开发用户 | 文档、数据、演示稿等 |
| Code 模式 | 开发工程师 | 编码、调试、代码库管理、Git 工作流 |

## 云端智能体 (Cloud Agent)

在云端环境中执行代码分析、运行和调试。提供统一运行时与依赖管理，避免本地环境差异带来的兼容性问题。
