## 图例

| 符号 | 含义 |
|:---:|------|
| 🟢 | 已实现，接口稳定 |
| 🟡 | 计划中，接口可能变更 |
| 🔴 | 实施中，接口未稳定 |
| 🔷 | 框架模块 — 其他模块接入需遵循其接入手册 |

---

## 列说明

| 列 | 用途 | Agent 如何使用 |
|----|------|---------------|
| 模块 | 模块文档文件名（无 `.md`） | 定位文件路径 |
| 摘要 | ≤15 字，模块做什么 | 一眼判断是否与本次变更相关 |
| 对外接口 | 关键 API / 组件 / 公共函数 | 知道模块暴露了什么 |
| 依赖 | 此模块依赖的其他模块 | 计划阶段判断依赖就绪度 |
| 被依赖 | 依赖此模块的其他模块 | 影响面评估 — 改了谁受影响 |
| 框架标准 | 空 或 接入手册路径 | 新模块接入时知道遵循什么规范 |
| 状态 | 🟢🟡🔴 | 判断是否可以依赖此模块 |
