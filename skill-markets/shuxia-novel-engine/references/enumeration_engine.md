# 可能性枚举引擎 · 设计规范

> 给定当前章节状态 → 列出所有可合理发生的下一事件
> 版本: v1.0 · 2026-06-16
> 状态: 设计阶段（不含代码）

---

## 零、核心问题

**"第 N 章结尾时，主角在位置 X，敌人状态 Y，科技树到 Z。接下来可以发生什么？"**

这不是"随便写"——是在约束空间内枚举合法路径。引擎的职责是在作者做决策之前，把**所有不违反世界规则的路径**摊开，并标注每条路径的代价与收益。

---

## 一、约束模型 · 四层过滤器

可能性空间由四类约束逐层收缩。每一层都是"不许做什么"的硬边界。

### 1.1 物理约束（底层 + 协议层）

从底层物理常数和协议层转换规则推导的硬限制。

| 约束维度 | 来源 | 查询方式 |
|----------|------|---------|
| **距离可行性** | 角色速度 S、时间窗口、地形 | 速度(m/s) × 可用时间(s) = 最大移动距离 |
| **灵压环境** | 当前位置灵压 P_L、灵压梯度 | 绝灵之地负压区 → 修真者战力×0.3 修正 |
| **能耗预算** | 灵能电池剩余电量、装置功耗 | 剩余(息) / 功耗(息/s) = 可用时间(s) |
| **战力对比** | Z 值、S 值、神识半径、反应时间 | combat.py 赢面检查（必须 PASS/BORDERLINE） |
| **空间约束** | 管道直径、厂房高度、围墙高度 | 体型限制（林岳无法进入直径<0.8m 管道） |
| **灵波传播** | 金属散射系数、灵场退相干距离 | 钢结构散射→罗盘误差增大；消音屏障有效范围 |
| **冷却/副作用** | 装置使用后的限制 | 绝灵近身>5s→对方适应→压制衰减 |

**硬规则**：任何候选事件如果违反物理约束，直接剔除（不进入评分）。

### 1.2 角色约束（表示层）

从角色 Schema 和人格锚点推导的行为边界。

| 角色 | 会做什么 | 绝不会做什么 |
|------|---------|-------------|
| **陆之一** | 计算→回避→利用环境→收集数据 | 正面战斗；依赖"运气"；无物理原理的行动 |
| **林岳** | 观察→判断→亲自追捕（享受过程） | 直接清除；用凡人监控/数据库/算法 |
| **孟炽** | 执行标准流程→神识扫描→报告上级 | 越权决策；情绪化行动；主动创新战术 |
| **小真** | 频谱分析→路径计算→威胁建模→建议 | 替陆之一做决策；感知灵场（卷一无此能力） |
| **严峰** | 神识追踪+灵场追踪+愤怒驱动 | 用凡人科技手段；冷静接受失败 |

**硬规则**：候选事件中每个角色的行动必须匹配其人格锚点和方法约束。违反 → 降级为"违规候选"（仅保留供对比，不推荐）。

### 1.3 情节约束（会话层）

从伏笔体系、节奏设计、卷章结构推导的叙事要求。

| 约束维度 | 来源 | 检查方式 |
|----------|------|---------|
| **伏笔推进** | oreshadow 表 | 该候选是否推进或回收至少 1 条 active 伏笔？ |
| **节奏位置** | 章节在卷中的位置 | 高潮前→候选必须有升级感；过渡章→可缓 |
| **信息差维护** | 读者/角色/其他角色三方信息差 | 候选不能"意外"消除信息差 |
| **能力展示** | 科技树当前层级 | 候选是否兑现了已铺垫的能力？ |
| **衔接约束** | 前后章节锚点 | 候选必须能与下一章合理衔接 |

**软规则**：情节约束不直接剔除候选，但在评分中权重较高。

### 1.4 宪法约束（底层）

7 条公理的硬边界。违反任何一条 → 直接剔除。

| 公理 | 检查问题 |
|------|---------|
| 一·双重物理 | 事件中的"修真效果"是否有 L 场物理解释？ |
| 二·灵压衰退 | 是否暗示灵子可被创造/逆转衰退？ |
| 三·灵子=L 场量子 | 是否引入了标准模型之外的粒子？ |
| 四·版本降级 | 是否暗示功法/阵法"完整无损"？ |
| 五·绝灵之体 | 陆之一是否直接修炼了功法？（卷四前禁止） |
| 六·小真 | 小真是否"突然觉醒/魔法般变强"？ |
| 七·三段式创新 | 新装置是否有经典物理原型→L 场对接→量化？ |

## 二、状态模型 · 章节快照

引擎输入是一个**结构化章节快照**，而非自由文本。快照包含以下维度：

### 2.1 快照结构

`
ChapterSnapshot {
    // 基础
    chapter_num: 82
    chapter_title: "伏击"
    narrative_phase: "高潮" | "过渡" | "揭示" | "铺垫"

    // 主角状态
    hero: {
        position: (x, y, z, location_name)
        physical: { hp, fatigue, injuries }
        energy: { battery_remaining_息, device_status[] }
        tech_tree_level: { layer, active_devices[] }
        knowledge: { known_facts[], unknown_facts[] }
        emotional_state: "冷静" | "紧张" | "恐惧" | "决绝" | ...
    }

    // 敌人状态
    enemies: [{
        id, name, cultivation, position, action_current,
        knowledge_of_hero, emotional_state, arrogance_level
    }]

    // 环境
    environment: {
        ling_pressure, visibility, cover_quality,
        spatial_constraint, terrain_features[]
    }

    // 情节状态
    plot: {
        active_foreshadows[],      // 未回收的伏笔
        pending_setups[],          // 已铺垫但未兑现的能力/信息
        pacing_position,           // 在卷中的节奏位置
        info_asymmetry: {           // 三方信息差
            reader_knows: [],
            hero_knows: [],
            enemy_knows: []
        }
    }
}
`

### 2.2 快照来源

- chapter 表（基础字段）
- character 表（角色战力/神识/傲慢）
- 	ech_node + 	ech_dependency 表（科技树层级+依赖）
- oreshadow 表（伏笔状态）
- concept_chapter_ref 表（本章涉及的概念）
- nvironment 表（当前场景参数）

## 三、枚举算法 · 四步生成

### 步骤 1：行动基元分解

将快照中的每个角色分解为"可执行的行动基元"。基元是原子操作——不可再分的动作单元。

**陆之一行动基元库**：

| 类别 | 基元 | 前提条件 |
|------|------|---------|
| 移动 | 向 X 方向移动 D 米 | D ≤ S × 可用时间 |
| 移动 | 攀爬/翻越障碍 H 米 | H ≤ 体能上限 |
| 移动 | 钻入管道/狭窄空间 | 管道直径 ≥ 0.5m |
| 装置 | 启动灵压消音屏障 | 电池 > 5% |
| 装置 | 启动反相灵波干扰 | 已获取目标灵波频谱 |
| 装置 | 启动绝灵近身 | 距离目标 ≤ 1m |
| 装置 | 启动电磁干扰（短路） | 附近有电气设施 |
| 环境 | 释放蒸汽/物理障碍 | 附近有蒸汽管道 |
| 环境 | 利用金属结构散射灵波 | 附近有钢结构 |
| 数据 | 采集灵波样本 | 神识精度 ≥ 目标信号强度 |
| 数据 | 小真频谱分析 | 已采集样本 + 小真在线 |
| 回避 | 静默等待 | 消音屏障激活 |
| 回避 | 绕行 | 已知敌人位置 |

**林岳/孟炽行动基元库**：

| 类别 | 基元 | 前提条件 |
|------|------|---------|
| 搜索 | 神识扫描区域 | 神识半径 ≥ 区域半径 |
| 搜索 | 罗盘灵波追踪 | 目标在使用灵能装置 |
| 搜索 | 视觉搜索 | 能见度 > 0.3 |
| 移动 | 向信号方向移动 | 已锁定大致方向 |
| 移动 | 下令小队包抄 | 小队 ≥ 2 人可用 |
| 决策 | 继续观察（不行动） | 林岳的猎人模式 |
| 决策 | 下令捕获（要活的） | 林岳兴趣被触发 |
| 决策 | 下令清除 | 林岳判断威胁过高（极少触发） |
| 决策 | 呼叫增援 | 通讯可用 + 判断需要 |

### 步骤 2：约束过滤

将每个行动基元序列通过四层过滤器：

`
原始基元序列
  → 物理过滤：距离×时间、能量×功耗、战力×环境
    → 角色过滤：人格锚点匹配、方法约束匹配
      → 宪法过滤：7 公理硬检查
        → 情节评分：伏笔推进、节奏匹配（不剔除，只影响分数）
`

**过滤示例（ch82 状态）**：

- 陆之一正面攻击林岳 → 物理过滤剔除（战力 0 vs 3500×0.3=1050，赢面=FAIL）
- 林岳调取工厂监控录像 → 角色过滤剔除（林岳不用凡人科技）
- 陆之一使用未发明的灵能护盾 → 物理过滤剔除（科技树未到）
- 陆之一等待灵压回升 → 宪法过滤剔除（公理二：灵压单向衰退）

### 步骤 3：候选组装

将通过过滤的基元序列组装为**完整候选事件**。每个候选包含：

`
CandidateEvent {
    description:     "一句话事件描述"
    trigger:         "在什么条件下主角会选择这个路径"
    action_sequence: [基元1, 基元2, ...]
    result_state: {
        hero_position, hero_energy, hero_knowledge_added,
        enemy_position, enemy_knowledge_added,
        environment_changes,
        foreshadows_affected[],
    }
    cost: {
        energy_消耗息, time_消耗秒, risk_level,
        info_exposed[],      // 暴露给敌人的信息
        missed_opportunities[] // 此路径放弃的收益
    }
}
`

### 步骤 4：去重与聚类

相似候选合并（如"走管道 A 段"和"走管道 B 段"合并为"利用管道区结构周旋"），保留最具代表性的变体。

## 四、评分系统 · 三维加权

每个候选在三个维度上独立评分（0-10），然后加权合成。

### 4.1 逻辑分（Logic Score）

衡量"这条路径在物理上是否严丝合缝"。

| 子维度 | 权重 | 评分标准 |
|--------|------|---------|
| 物理可行性 | 40% | 距离/能量/战力是否在约束内？越充裕→越高 |
| 角色一致性 | 30% | 每个角色的行为是否 100% 匹配人格锚点？ |
| 因果链完整 | 20% | 前因→后果链条是否无跳跃？ |
| 宪法合规 | 10% | 不违反只是及格(6)，主动体现公理精神→加分 |

### 4.2 惊喜分（Surprise Score）

衡量"读者没想到但完全合理"的程度。这是引擎的核心价值——防止作者选"最安全但最无聊"的路径。

| 子维度 | 权重 | 评分标准 |
|--------|------|---------|
| 反直觉合理 | 40% | 初看意外，但用已铺垫的规则完全解释得通 |
| 信息差利用 | 30% | 是否利用了读者/敌人不知道的信息？ |
| 规则创造性使用 | 20% | 是否以非预期方式组合了已知规则？ |
| 不可预测性 | 10% | 在合理范围内，是否难以被读者猜到？ |

**惊喜分与逻辑分的关系**：
- 高逻辑 + 低惊喜 = "安全但无聊"（如"陆之一继续躲藏"）
- 低逻辑 + 高惊喜 = "不合理的神转折"（如"陆之一突然学会飞行"）——应被约束过滤剔除
- 高逻辑 + 高惊喜 = **最优候选**（如"利用变电站短路制造电磁干扰"——经典物理+灵场耦合的创造性应用）

### 4.3 主题分（Theme Score）

衡量"这条路径是否服务于核心主题"。

| 主题 | 关键词 | 评分标准 |
|------|--------|---------|
| 外物证道 | 经典物理→修真 | 是否展示了"用底层物理理解上层法术"？ |
| 文明碰撞 | 修真傲慢 vs 凡人智慧 | 是否体现了结构性盲区的对抗？ |
| 灵压衰退 | 不可逆的熵增 | 是否暗示了世界的悲观底色？ |
| 知识即力量 | 信息差 vs 力量差 | 是否体现了"认知差 × 信息差 > 力量差"？ |
| 代价意识 | 每次胜利有代价 | 是否有明确的代价（能量/时间/信息暴露）？ |
| 孤独的清醒者 | 唯一双重视角 | 是否体现了陆之一是唯一同时掌握两层物理的人？ |

### 4.4 综合公式

`
总分 = 逻辑分 × 0.40 + 惊喜分 × 0.35 + 主题分 × 0.25
`

惊喜分权重略低于逻辑分——保证"合理"永远优先于"意外"。但 0.35 的权重足够让高惊喜候选超越平庸但安全的候选。

**附加规则**：
- 逻辑分 < 5.0 → 候选标注 ⚠️ 逻辑存疑，不推荐
- 惊喜分 < 3.0 → 候选标注 📦 安全选项（可用但平庸）
- 主题分 < 3.0 → 候选标注 🔗 主题偏离（可能偏离核心表达）

## 六、实例 · 第 82 章结尾 → 第 83 章候选

### 快照摘要

`
ChapterSnapshot(ch82_end) {
    chapter: 82 "伏击"
    phase: "高潮" (第五阶段·动作高潮上)

    hero: {
        position: 废弃工厂·管道区深处
        physical: 未受伤，体力正常
        energy: 灵能电池 60% (约 24 分钟全功率)
        devices: 灵压消音屏障v2.0(激活中), 灵能电池v1.0, 灵压监测器, 石眼被动模块
        knowledge: 不知道敌人叫林岳; 知道是清洗司的人; 知道老猫已死
        emotional: 冷静/计算/高度警觉
    }

    enemies: [
        { id: "林岳", cultivation: "凝丹境(坎离交媾中期)", position: "工厂某处",
          action: "观察→判断→已下令'追，不要杀，要活的'",
          knowledge: 知道目标是凡人但有未知隐蔽技术,
          arrogance: 0.7 (修真者傲慢+猎人自信) },
        { id: "小队A", cultivation: "炼精化气", position: "管道区入口",
          action: "进入管道区搜索" },
        { id: "小队B", cultivation: "炼精化气", position: "南围墙",
          action: "封锁南侧出口" },
        { id: "孟炽", cultivation: "炼精化气中期", position: "管道区入口",
          action: "神识扫描→锁定大方向(未精确定位)" }
    ]

    environment: {
        ling_pressure: 负压(绝灵之地)
        visibility: 0.3 (黄昏→入夜)
        cover: 0.7 (管道/钢结构/厂房)
        spatial_constraint: 0.8 (管道区狭窄)
    }

    plot: {
        active_foreshadows: [F26(林岳介入→追捕)]
        pending_setups: [灵波频谱采集(为ch84大阵建模做准备)]
        pacing: 动作高潮中段——需要升级而非收尾
    }
}
`

### 物理边界计算

- **最大移动距离**：陆之一 S0 → 步行速度约 1.5m/s → 30 分钟可移动约 2700m
- **可用时间**：电池 60% → 全功率屏障约 24 分钟；省电模式可延长至约 40 分钟
- **工厂范围**：约 300m × 400m = 120,000m²
- **敌对力量差**：林岳 Z=3500（凝丹）→ 环境修正×0.3 → 实际 Z≈1050；陆之一 Z=0
  - 赢面检查（使用 combat.py）：
  - cognitive_gap=1.5（经典物理视角），info_gap=1.3（林岳不知道消音屏障原理），rrogance=0.7，system_flaw=0.65（管道+钢构+低能见度），nemy_power_raw=1050
  - 分数 ≈ 0.99 → BORDERLINE（偏紧，需叙事支撑）→ **直接战斗不可行，只能回避**

### 候选事件枚举

#### 候选 1：⭐ 物理陷阱周旋 + 频谱采集 — 总分 8.7

- **逻辑分**：9.0 — 每一步都有物理原理支撑（金属散射灵波、电磁干扰、蒸汽障碍），能量预算精确（40 分钟窗口内完成）
- **惊喜分**：8.5 — 读者预期"躲藏"，但没想到用变电站短路制造电磁干扰来欺骗罗盘；没想到蒸汽管可以作为"非致命物理障碍"
- **主题分**：8.5 — "经典物理对抗修真"的集中展示；每项技术都是公理七（三段式创新）的实例；体现了"认知差 × 信息差 > 力量差"
- **触发条件**：陆之一选择不直接逃跑（会被追上），而是在工厂内利用环境与三名追捕者周旋，同时让小真完成频谱采集
- **事件序列**：
  1. 管道区深处：小真完成林岳灵波频谱初步分析→发现特征频率
  2. 锅炉房：提前打开泄压阀→高温蒸汽填满通道→小队 A 绕行（争取 4 分钟）
  3. 变电站：触发短路→强电磁脉冲→两块罗盘误报"两个目标"→小队分流（争取时间 + 收集罗盘响应数据）
  4. 天台区：被小队 B 拦截→启动绝灵近身（距离 0.8m）→对方术法输出降低 55%→侧身绕过（4.5 秒接触）
  5. 南围墙：小真计算林岳到达时间→反相干扰阻挡一次神识扫描→翻墙逃脱（成功率 73%）
  6. 脱险后：灵波频谱入库，标记"L-01：林岳"
- **结果状态**：
  - 位置：工厂管道区 → 城南公路
  - 能量：60% → 28%
  - 知识获取：林岳灵波频谱特征（为 ch84 大阵拓扑建模提供关键数据层）
  - 敌人认知：林岳意识到"目标不用灵气思考"→标注一级事件
- **伏笔影响**：推进 F26（林岳→卷二反杀铺垫）；新设"林岳灵波频谱入库"
- **代价**：能量消耗 32% + 体力大幅消耗 + 暴露了消音屏障和绝灵近身的存在 + 林岳升级追踪优先级

#### 候选 2：📦 全程管道躲藏（最小接触） — 总分 6.4

- **逻辑分**：8.0 — 物理可行（管道区空间约束对陆之一有利），能量消耗低（静默等待而非主动干扰）
- **惊喜分**：3.0 — 读者完全能猜到；无意外元素
- **主题分**：7.0 — 体现了"回避优于战斗"，但未展示经典物理对抗修真
- **触发条件**：陆之一判断主动制造陷阱风险过高→选择纯被动躲藏
- **事件序列**：
  1. 在管道区深处静默等待（消音屏障持续激活）
  2. 随林岳扫描周期移动——每次神识扫描过后换位置
  3. 利用管道内金属结构自然散射灵波
  4. 等待林岳判断"目标已逃离"→收缩包围→从缺口离开
- **结果状态**：
  - 能量：60% → 45%（低功耗，但时间更长）
  - 知识获取：仅获得林岳部分灵波特征（无完整频谱——因为未主动触发其各种追踪手段）
- **伏笔影响**：推进 F26 但程度较浅
- **代价**：未获得完整频谱（ch84 大阵建模缺少清洗司行为模式数据层）；林岳不会升级为一级事件（缺少"震撼"）；节奏平缓（高潮章不匹配）

> 📦 安全选项——可用但平庸。适合作为"如果作者想快速过渡"的备选。

#### 候选 3：🔗 强行正面突破南围墙 — 总分 4.6

- **逻辑分**：4.0 — ⚠️ 边界存疑。小队 B 战力约 500（炼精化气），绝灵近身可压制但仅 5 秒窗口。翻越 2.4m 围墙需要约 6 秒 → 压制衰减后的时间缺口约 1-2 秒 → 可能被拦截
- **惊喜分**：5.0 — 读者可能没想到"凡人主动冲向修真者"
- **主题分**：5.0 — 体现了绝灵近身的实战价值，但缺少"经典物理创造性应用"的层次
- **触发条件**：陆之一判断拖延越久越危险→趁林岳未完成包围前强行突破
- **事件序列**：
  1. 从小真获取围墙守卫位置
  2. 直接冲向围墙→启动绝灵近身压制守卫
  3. 在压制窗口内翻墙→脱离
- **伏笔影响**：推进 F26（展示绝灵近身）
- **代价**：极高风险（赢面 BORDERLINE，缺少数秒窗口）；暴露了绝灵近身的全部能力（林岳获得关键情报）；未采集频谱

> ⚠️ 逻辑存疑——可在"侥幸逃脱"叙事中使用，但违反赢面公式精神。

#### 候选 4：⭐ 反客为主——主动制造假线索误导追踪方向 — 总分 7.8

- **逻辑分**：8.5 — 利用消音屏障的"可调节灵波泄漏"特性→故意在工厂东侧制造微弱灵波泄漏→诱导林岳向东追踪→陆之一从西侧离开。物理原理：灵压消音屏障不是完美的——它的泄漏率可被主动调节（通过改变反相灵波的发射功率）。
- **惊喜分**：8.0 — 读者预期"躲藏"，没想到"主动制造假线索"——这是从"猎物"到"猎人的猎物"的微妙转换
- **主题分**：7.0 — 体现了"信息差"的主动利用（林岳不知道消音屏障可以调节泄漏）；但缺少"物理原理展示"的层次
- **触发条件**：小真的威胁建模计算显示——纯粹躲藏会逐渐缩小包围圈→需要主动改变林岳的行为
- **事件序列**：
  1. 小真分析林岳搜索模式→发现他依赖罗盘灵波信号
  2. 陆之一移动到工厂东侧→短暂降低消音屏障功率（制造"信号泄漏"）
  3. 林岳罗盘捕捉到信号→判断目标在东侧→调动小队向东
  4. 陆之一恢复全功率屏障→从西侧离开
  5. 在离开前采集到林岳响应假信号的灵波特征（另一种频谱数据）
- **结果状态**：
  - 能量：60% → 35%
  - 知识获取：林岳对灵波信号的响应延迟、扫描优先级等行为数据
- **伏笔影响**：推进 F26；为卷二"利用林岳行为模式设陷阱"埋下伏笔
- **代价**：如果林岳识破假信号（概率约 20%）→包围圈在东侧反而更紧

#### 候选 5：⭐ 多源复合干扰——同时激活电磁+灵波+热辐射三重欺骗 — 总分 8.2

- **逻辑分**：8.0 — 每个干扰源都有物理原理，但三重同时操作的复杂性对陆之一的手动操作能力要求较高（他需要在不同位置设置三个触发点）
- **惊喜分**：9.0 — 最高惊喜。读者不会想到一次同时触发三种不同物理原理的干扰
- **主题分**：7.5 — 是"经典物理→修真"的极致展示，但操作过于复杂可能削弱叙事焦点
- **触发条件**：陆之一在工厂内快速移动，设置三个干扰点后再集中逃脱
- **事件序列**：
  1. 变电站设置电磁干扰（短路触发）→欺骗罗盘
  2. 锅炉房设置热辐射干扰（蒸汽+明火）→欺骗红外感知
  3. 管道区设置灵波反射干扰（移动金属板制造角反射器）→欺骗灵波追踪
  4. 三重触发后→林岳的感知系统同时出现三个"目标信号"→认知过载
  5. 陆之一从无信号的第四方向离开
- **结果状态**：林岳首次体验到"感知系统被系统性地欺骗"→不是技术故障，是有人理解了他的每一种感知手段并逐一干扰。这对林岳的冲击力远超单纯躲藏
- **代价**：设置时间约 15-20 分钟（电池消耗大）；需要提前踩点（可能与林岳搜索时间冲突）；如果某一干扰失败→会被发现意图

## 九、设计原则总结

1. **约束优先于生成**。先定义"不能做什么"，再在余下空间里找"可以做什么"。
2. **惊喜不能牺牲逻辑**。一个读者没想到的转折，必须能用已铺垫的规则解释——否则不是惊喜，是漏洞。
3. **代价是叙事的燃料**。没有代价的胜利是作弊。每个候选必须标注它消耗了什么。
4. **引擎服务故事，不是反过来**。评分是建议，不是判决。作者有权选低分候选——只要他们知道代价是什么。
5. **从底向上推导，不跳层**。每个候选的可追溯链：宪法公理 → 物理常数 → 协议转换 → 角色能力 → 具体行动。
