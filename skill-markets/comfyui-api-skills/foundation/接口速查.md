# ComfyUI 接口速查

> 快速参考卡片。完整说明见 [`skills/comfyui-api/SKILL.md`](../skills/comfyui-api/SKILL.md)。
> 占位符解析规则见 [`foundation/配置.md`](配置.md)。

## 服务地址

- **默认**：`{{COMFYUI_URL}}` → `http://127.0.0.1:8188`
- **远程**：在 `.env` 或 `projects/{名}/清单.yaml` 中覆盖
- **超时**：接口调用 `{{COMFYUI_API_TIMEOUT}}` 秒；轮询生成结果不限时

## 常用接口

| 操作 | 方法 | 端点 | 说明 |
|------|------|------|------|
| 系统状态 | GET | `/system_stats` | GPU、显存、ComfyUI 版本 |
| 节点清单 | GET | `/object_info` | 所有已注册节点类与参数 |
| 提交工作流 | POST | `/prompt` | 返回 `prompt_id` |
| 查询结果 | GET | `/history/{prompt_id}` | 每 `{{COMFYUI_POLL_INTERVAL}}` 秒轮询一次 |
| 取图片 | GET | `/view?filename=...` | 下载生成结果 |
| 上传图片 | POST | `/upload/image` | 上传参考图 |
| 中断生成 | POST | `/interrupt` | 取消当前任务 |
| 释放显存 | POST | `/free` | 卸载模型 |
| 检查点 | GET | `/models/checkpoints` | 列出 checkpoint |
| LoRA | GET | `/models/loras` | 列出 LoRA |
| VAE | GET | `/models/vae` | 列出 VAE |
| ControlNet | GET | `/models/controlnet` | 列出 ControlNet |
| 视频模型 | GET | `/models/diffusion_models` | 列出 diffusion 视频模型 |

## 工作流 JSON 结构

```json
{
  "1": {
    "class_type": "LoadCheckpoint",
    "inputs": { "ckpt_name": "flux1-dev.safetensors" }
  },
  "2": {
    "class_type": "CLIPTextEncode",
    "inputs": {
      "text": "photorealistic portrait...",
      "clip": ["1", 1]
    }
  }
}
```

- 节点用字符串 ID 索引
- 输入引用上游节点：`["{节点 ID}", {输出下标}]`

## 轮询策略

```
1. POST /prompt           → 获取 prompt_id
2. GET  {{COMFYUI_URL}}/history/{id}     → 每 {{COMFYUI_POLL_INTERVAL}} 秒一次
3. 响应为空对象 {}         → 仍在执行
4. 响应含 status.completed → 提取 outputs
5. status 含 error        → 转交 troubleshooter
```

**超时告警**：轮询 `{{COMFYUI_POLL_TIMEOUT}}` 秒无结果时提醒用户（Wan 14B 生成 15-30 分钟属正常）。

## 错误速查

| 错误 | 原因 | 处理 |
|------|------|------|
| 连接被拒 | ComfyUI 未启动 | 切离线模式，导出 JSON |
| 400 错误请求 | 工作流 JSON 非法 | 校验节点连线 |
| 500 内部错误 | ComfyUI 崩溃 | 建议重启并查日志 |
| 长时间无响应 | 服务过载 | 等待后重试一次 |
