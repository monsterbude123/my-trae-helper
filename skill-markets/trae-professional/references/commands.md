# 命令（斜杠命令）

> 命令是快捷方式，用于在对话中快速执行重复性任务。封装常用指令或操作 → 简化工作流程。

## 使用场景

- **复用常用 Prompt**：总结 PR 变更、生成文档摘要、整理会议记录
- **规范输出格式**：生成 Conventional Commits 规范的 commit message、PR 描述、Issue 模板
- **自动化常见开发流程**：代码审查、性能分析、安全检查

## 运行环境

| 环境 | 适用任务 | 适用客户端 |
|------|----------|------------|
| **本地** | 仅本地任务 | TRAE Work 桌面版 |
| **云端** | 仅云端任务 + GitHub 项目 | 网页版 + 桌面版 |

## 内置命令

| 命令 | 作用 |
|------|------|
| `/plan` | 调用计划模式 |
| `/spec` | 调用规范模式 |
| `/browser_use` | 使用 browser_use 工具操作内置浏览器并获取上下文，辅助智能体进行功能验证 |

详见 [spec-and-plan.md](spec-and-plan.md)。

## 创建自定义命令

### 进入命令管理面板

两种方式：
1. 头像 → **设置** → **命令**
2. 对话框左下方命令图标 → 菜单底部 **管理技能与命令**

### (仅桌面版) 选择运行环境
本地 / 云端

### 配置命令

| 字段 | 说明 | 示例 |
|------|------|------|
| **命令名称** | 唯一标识，触发命令用 | `summarize-pr-info`（**仅小写字母、数字、短横线**） |
| **描述** | 简要说明 | 总结 PR 信息 |
| **说明** | 触发后 AI 应执行的具体操作 | 见下方示例 |

### 示例配置

```
命令名称: summarize-pr-info
描述: 总结 PR 信息
说明: 查看当前 Pull Request 的代码变更内容，对比修改前后的代码，并总结本次 PR 的主要变更。
  1. 本次 PR 的核心改动点
  2. 主要修改的文件或模块
  3. 关键逻辑变化或新增功能
  4. 可能影响的功能或潜在风险
```

## 使用命令

对话框输入 `/` 或点击左下方命令图标 → 选命令 → 输入相关指令 → 发送
